## 各阶段提示词要点（内置于 core/workflow.py）

| 阶段 | 要点 |
|---|---|
| S1 思考 | 目标与约束 / 技术路线对比 / 边界与易错点 / 资源管理风险 / 本轮方案 |
| S2 计划 | summary/steps/files/tests/risks/acceptance 结构化 JSON |
| S3 计划审查 | high 仅限"无法实现目标/缺步骤/逻辑错误/泄漏设计/安全漏洞"；禁止企业级过度要求 |
| S4 开发 | 完整可运行代码；资源释放；附自测；重试时基于上一轮代码增量修复 |
| S5 代码审查 | 静态检查先行；LLM 只报确凿问题；不预测假想问题；html/css/md 不按代码审查 |
| 测试 | 子进程超时 + tracemalloc 泄漏检测 + 力扣内置判题 |
| S6 复盘 | 轮次/修复问题/测试结果归档 retrospective.md；错误模式入 memory |
| S7 退出 | 测试通过 + 无泄漏 + 无高危未修复 → 允许退出 |
