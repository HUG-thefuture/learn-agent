## 一、字典与集合

### 📌 复习要点
1. **键必须不可变且唯一**：`str`/`int`/`tuple` 可作键，`list` 不能；对同一个键重复赋值是**覆盖**，不是报错。
2. **取值两种方式**：`d[k]` 键不存在抛 `KeyError`；`d.get(k, 默认值)` 不存在返回默认值，更安全。
3. **遍历三板斧**：`d.keys()` / `d.values()` / `d.items()`，最常用 `for k, v in d.items():`。
4. **`{}` 是空字典，不是空集合**！空集合只能写 `set()`；集合元素唯一、不可变，天然去重。
5. **删除方法别混**：`del d[k]`、`d.pop(k)`；集合中 `s.remove(x)` 不存在会报错，`s.discard(x)` 不报错。
6. **集合运算**：`&` 交集、`|` 并集、`-` 差集、`^` 对称差。

### ⚠️ 易错点对照

**❌ 错误写法**
```python
# 错误 1：{} 创建的是空字典，不是集合
s = {}
s.add(1)            # 报错：AttributeError: 'dict' object has no attribute 'add'

# 错误 2：键不存在时直接用 [] 访问
d = {"a": 1}
print(d["b"])       # 报错：KeyError: 'b'
```

**✅ 正确写法**
```python
s = set()                  # 空集合必须用 set()
s.add(1)
d = {"a": 1}
print(type(s), s)          # <class 'set'> {1}
print(d.get("b", 0))       # 0：键不存在，返回默认值而不报错
print(d.get("a", 0))       # 1：键存在，返回对应的值
```

### ✏️ 综合小练习
统计字符串中每个字符的出现次数（字典），再找出所有重复出现的字符（集合）。

```python
text = "banana"

# 1. 用字典统计每个字符出现次数
counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1
print(counts)

# 2. 用集合推导式找出出现超过 1 次的字符，排序后输出
repeated = {ch for ch, n in counts.items() if n > 1}
print(sorted(repeated))

# 预期输出：
# {'b': 1, 'a': 3, 'n': 2}
# ['a', 'n']
```

## 二、字符串与格式化

### 📌 复习要点
1. **字符串不可变**：`replace`/`upper`/`strip` 等都返回**新字符串**，必须接住返回值：`s = s.strip()`。
2. **f-string 里可以放任意表达式**，包括三元：`f"{'及格' if s >= 60 else '不及格'}"`。
3. **格式控制**：`:.2f` 保留两位小数、`:>10` 右对齐宽 10、`:,` 千分位、`:.1%` 百分比。
4. **split 的区别**：`split()` 不带参数按任意空白切并丢弃空串；`split(",")` 严格按逗号切，**不会去掉空格**。
5. **join 是字符串的方法**：`"分隔符".join(字符串序列)`，数字必须先 `str()` 转换。
6. **切片** `s[起:止:步]` 含头不含尾；`s[::-1]` 反转；负索引从 `-1` 开始。

### ⚠️ 易错点对照

**❌ 错误写法**
```python
s = "hello world"
s.replace("world", "python")   # 返回了新字符串，但没人接住，s 不变
print(s)                       # 输出 hello world（不是 hello python！）

nums = [1, 2, 3]
print("-".join(nums))          # 报错：TypeError: sequence item 0: expected str instance, int found
```

**✅ 正确写法**
```python
s = "hello world"
s = s.replace("world", "python")       # 用变量接住返回的新字符串
print(s)                               # hello python

nums = [1, 2, 3]
print("-".join(str(n) for n in nums))  # 先把每个数字转成 str 再 join
```

### ✏️ 综合小练习
清洗用户名、格式化成绩，并把名字用 `-` 连成大写。

```python
name = "  xiao ming  "
score = 92.567

clean = name.strip().title()          # 去两端空格 + 每个单词首字母大写
print(f"姓名：{clean}，成绩：{score:.1f}，等级：{'及格' if score >= 60 else '不及格'}")

words = clean.split()
print("-".join(w.upper() for w in words))

# 预期输出：
# 姓名：Xiao Ming，成绩：92.6，等级：及格
# XIAO-MING
```

## 三、环境搭建与第一个程序

### 📌 复习要点
1. **两种运行方式**：交互式 REPL（输一行执行一行，适合试验）；保存为 `.py` 文件后用 `python 文件名.py` 运行（写完整程序）。
2. **自建文件不要与标准库同名**（如 `random.py`、`string.py`、`os.py` 等），否则 `import` 会优先导入你自己的文件而不是标准库，出现莫名其妙的 `AttributeError`。
3. **`print` 的两个隐藏参数**：`sep` 控制多个值之间的分隔符（默认空格），`end` 控制结尾（默认换行 `\n`）。
4. **缩进就是语法**：同一代码块必须缩进一致（约定 4 个空格），混用 Tab 和空格会报 `IndentationError`/`TabError`。
5. **`input()` 返回的一定是字符串**：即使输入 `18`，拿到的也是 `"18"`，参与运算前必须 `int()`/`float()` 转换。
6. **程序入口习惯**：主逻辑写在 `if __name__ == "__main__":` 下，既可以直接运行，也能被其他文件安全导入。

### ⚠️ 易错点对照

**❌ 错误写法**
```python
# 错误 1：把文件保存为 random.py，然后运行：
import random
print(random.randint(1, 6))
# 报错：AttributeError: module 'random' has no attribute 'randint'
# 原因：导入的是你自己写的 random.py，不是标准库

# 错误 2：input 的返回值直接参与运算
age = input("年龄：")   # 输入 18
print(age + 1)          # 报错：TypeError: can only concatenate str (not "int") to str
```

**✅ 正确写法**
```python
# 文件保存为 dice.py（避开标准库名）
import random
print(random.randint(1, 6))        # 输出 1~6 的随机整数，例如 4

age = int(input("年龄："))         # 先转成 int 再运算
print(f"明年 {age + 1} 岁")        # 输入 18 时输出：明年 19 岁
```

### ✏️ 综合小练习

## 四、变量与数据类型

### 📌 复习要点
1. **变量是贴在对象上的“名字标签”**：赋值即创建，无需声明类型；用 `type(x)` 查看类型，`isinstance(x, int)` 判断类型。
2. **动态类型**：同一变量可先后指向不同类型的对象（先 `x = 1` 再 `x = "a"` 合法），但别滥用，否则容易埋逻辑坑。
3. **可变 vs 不可变**：`int`/`float`/`str`/`bool`/`tuple` 不可变（“修改”其实是创建新对象）；`list`/`dict`/`set` 可变（原地修改）。
4. **`b = a` 不是复制**：只是让两个名字指向同一个对象，对可变对象一改俱改；要独立副本用 `a.copy()` 或 `list(a)`。
5. **类型转换的坑**：`int("12")` ✔；`int("3.5")` ✘（要先 `float`）；`int(3.9)` 直接**截断**为 `3`，不是四舍五入（四舍五入用 `round()`）。
6. **`==` 与 `is`**：`==` 比较值是否相等，`is` 比较是否为同一个对象；日常判断相等一律用 `==`。

### ⚠️ 易错点对照

**❌ 错误写法**
```python
a = [1, 2, 3]
b = a              # b 和 a 指向同一个列表，并没有复制
b.append(4)
print(a)           # [1, 2, 3, 4] —— a 也跟着变了！

age = "18"
print(age + 1)     # 报错：TypeError: can only concatenate str (not "int") to str
```

**✅ 正确写法**
```python
a = [1, 2, 3]
b = a.copy()                 # 浅拷贝，得到真正的新列表
b.append(4)
print(a, b)                  # [1, 2, 3] [1, 2, 3, 4]

age = "18"
print(int(age) + 1)          # 19：先转 int 再运算
print(float("3.5") + 0.5)    # 4.0：带小数点的字符串要用 float()
print(int(3.9))              # 3：int() 是截断，不是四舍五入
```

