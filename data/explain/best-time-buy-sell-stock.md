# 121. 买卖股票的最佳时机

## 0. 题目重述

给定数组 `prices`，`prices[i]` 表示第 `i` 天股票价格。你**只能选择某一天买入**，并在**未来的某一天卖出**（先买后卖，只能交易一次），求能获得的最大利润；若无法盈利，返回 `0`。

```
输入: [7,1,5,3,6,4]   输出: 5   (第 2 天买入 1，第 5 天卖出 6)
输入: [7,6,4,3,1]     输出: 0   (全程下跌，不交易)
```

---

## 1. 思路推导

### 1.1 暴力：先看最直白的想法

枚举所有 `(i, j)` 且 `i < j`，取 `prices[j] - prices[i]` 的最大值：

```python
ans = 0
for i in range(n):
    for j in range(i + 1, n):
        ans = max(ans, prices[j] - prices[i])
```

- 正确，但时间 **O(n²)**，`n = 1e5` 时会超时（10^10 次操作）。

### 1.2 关键观察：把「找一对」变成「找一个」

固定**卖出日** `j`：要让 `prices[j] - prices[i]` 最大，`i` 必须是 **`[0, j-1]` 区间内的最小值**。

于是问题变为：**从左往右扫一遍，边扫边维护「到目前为止的历史最低价」**。

> 一句话总结：`第 j 天的最优利润 = 今天的价格 − 之前见过的最低价`，取历史最大者。

这也是「**前缀最值 + 在线更新**」的经典套路，与 53 题最大子数组和的 Kadane 思路同源。

### 1.3 换个视角：差分数组的最大子段和

设 `diff[i] = prices[i] - prices[i-1]`，则 `prices[j] - prices[i] = diff[i+1] + ... + diff[j]`。

即：**在差分数组上求「最大子段和」，且答案与 0 取 max**。

```python
cur = 0
ans = 0
for i in range(1, n):
    cur = max(0, cur + prices[i] - prices[i-1])  # 子段和一旦为负就重启
    ans = max(ans, cur)
```

这解释了为什么 121 和「最大子数组和」是姊妹题，也是 152 题（最大乘积子数组）的联想入口。

### 1.4 状态机 DP 视角（通往 122/123/188/309/714 的钥匙）

定义 `dp0` = 第 `i` 天结束时**不持股**的最大利润，`dp1` = **持股**时的最大利润：

```
dp0[i] = max(dp0[i-1], dp1[i-1] + prices[i])   # 继续观望 / 今天卖出
dp1[i] = max(dp1[i-1], -prices[i])             # 继续持有 / 今天首次买入
```

注意 `dp1` 的转移写的是 **`-prices[i]`** 而非 `dp0[i-1] - prices[i]` —— 因为本题**只允许买入一次**，买入前利润必为 0。若改成 `dp0[i-1] - prices[i]`，就变成 122 题（可多次交易）了。这个差异是系列题的分水岭。

## 2. 推荐解法与代码（Python）

### 2.1 主推：一次遍历维护最低价

```python
from typing import List


def maxProfit(prices: List[int]) -> int:
    """121. 买卖股票的最佳时机：一次买入一次卖出，返回最大利润（无利润返回 0）。

    时间 O(n)，空间 O(1)。
    """
    min_price = float("inf")  # 此前出现过的最低价
    best = 0                  # 答案下限为 0：允许「不交易」
    for p in prices:
        if p < min_price:
            min_price = p          # 更新历史最低价
        else:
            profit = p - min_price  # 以今天为卖出日的最优利润
            if profit > best:
                best = profit
    return best
```

**易错点：**

- `best` 必须初始化为 `0`，不能初始化为 `-inf`；空数组或单调下跌时直接返回 `0`。
- `if / else` 不能合并成「先更新 min 再算 profit」以外的顺序错误：`else` 分支保证 `p >= min_price`，因此 `profit >= 0`（其实合并成顺序执行也正确，只是 `else` 更省一次减法）。
- **不要**用 `min_price = prices[0]` 后从 `i=1` 开始却没处理 `n == 0` 的情况；用 `inf` 哨兵可以天然兼容空数组与单元素数组。

### 2.2 状态机版本（推荐同时掌握，可无缝扩展到 122/309/714）

```python
def maxProfitDP(prices: List[int]) -> int:
    dp0 = 0                     # 不持股
    dp1 = float("-inf")         # 持股（初始不可达）
    for p in prices:
        dp0 = max(dp0, dp1 + p)  # 必须先算 dp0：用的是「昨天」的 dp1
        dp1 = max(dp1, -p)       # 只允许一次买入 → 买入前利润恒为 0
    return dp0
```

### 2.3 可测试性：边界用例清单

```python
def _tests():
    f = maxProfit
    assert f([]) == 0                      # 空数组
    assert f([5]) == 0                     # 单日无法交易
    assert f([7, 6, 4, 3, 1]) == 0         # 单调下跌 → 0
    assert f([1, 2, 3, 4, 5]) == 4         # 单调上涨
    assert f([7, 1, 5, 3, 6, 4]) == 5      # 常规样例
    assert f([2, 4, 1]) == 2               # 最优解在很靠前的位置
    assert f([3, 3, 3]) == 0               # 全相等 → 0
    assert f([1, 0, 1]) == 1               # 有负数级别的最小值参与
```

## 3. 复杂度分析

| 指标 | 值 | 说明 |
|---|---|---|
| 时间 | **O(n)** | 每个元素只访问一次，常数次比较/减法 |
| 空间 | **O(1)** | 仅 `min_price` 与 `best` 两个变量；DP 版仅 `dp0/dp1` |
| 输入输出 | 不修改原数组 | 无副作用，便于并发/复用 |

相比暴力的 O(n²)，在 `n = 10^5` 时是 10^10 → 10^5 的量级差距。

## 4. 其他解法对比

| # | 解法 | 时间 | 空间 | 适用性评价 |
|---|---|---|---|---|
| 1 | 双重循环暴力 | O(n²) | O(1) | 仅作对拍/教学，面试直接扣分 |
| 2 | **一次遍历（前缀最小值）** | **O(n)** | **O(1)** | ✅ **首选**，代码最短、常数最小 |
| 3 | 差分 + Kadane 最大子段和 | O(n) | O(1) | ✅ 等价，思想价值高（连通 53/152） |
| 4 | 状态机 DP（2 变量滚动） | O(n) | O(1) | ✅ 推荐，直接推广到 122/123/188/309/714 |
| 5 | 后缀最大值数组 / 前缀最小值数组 | O(n) | O(n) | 冗余但直观；真正用途是 123 题的**前后缀分解** |
| 6 | 分治（最大利润在左半 / 右半 / 跨中点） | O(n log n) | O(log n) | 不必要；可用于「带修改的区间查询」场景 |
| 7 | 单调栈 | O(n) | O(n) | 杀鸡用牛刀，本题无意义（栈类题是 84 / 739） |
| 8 | 线段树 / 树状数组 | O(n log n) | O(n) | 仅在需要动态修改价格时才有价值 |

**结论**：面试写 2，口述时补一句 3 或 4 的等价视角，能显著加分。

**追问延伸**：如果要求返回**买入和卖出的日期**，只需在更新 `min_price` 时同步记录 `min_index`，在更新 `best` 时记录 `(min_index, i)`；本题是订阅型场景，注意这类「只求极值」的题不要顺手存下标，保持 O(1) 空间。

## 5. 同类题拓展（一个系列，一条主线）

### 5.1 一条主线：状态机 DP 的通式

```
第 i 天，已交易 k 次，持股状态 s ∈ {0, 1}
dp[k][0] = max(dp[k][0], dp[k][1] + p)        # 卖出
dp[k][1] = max(dp[k][1], dp[k-1][0] - p)      # 买入（k 加在买入侧）
```

121 是 `k = 1` 的特例，此时 `dp[k-1][0] = dp[0][0] = 0`，所以买入项退化成 `-p`。

### 5.2 题目清单

| 题号 | 变化 | 关键点 |
|---|---|---|
| **121** | 只能交易 1 次 | 前缀最小值，本题 |
| **122** | 可交易任意次 | 贪心：所有 `prices[i] > prices[i-1]` 的差累加；或 `dp1 = max(dp1, dp0 - p)` |
| **123** | 最多 2 次 | 前后缀分解（左跑一遍 121，右跑一遍 121 取 max），或 4 状态 DP |
| **188** | 最多 k 次 | DP，`k` 较大时注意用滚动数组；`k >= n/2` 时退化为 122 的贪心 |
| **309** | 含冷冻期（卖出后隔一天才能买） | 3 状态：持股 / 冷冻 / 可买 |
| **714** | 含手续费 | 2 状态，卖出时减去 `fee` |
| **53** | 最大子数组和 | 与本题 Kadane 视角同源 |
| **152** | 最大乘积子数组 | 同时维护 max/min，思路同构 |
| **面试题 63** | 股票最大利润（同 121） | 纯换皮 |
| **901 / 239** | 单调栈类 | 与本题**不同族**，别硬凑 |

### 5.3 记忆口诀

> **一次买入找前缀最小，多次交易捡所有上坡，限定次数上状态机，冷冻手续费加维度。**

## 6. 面试加分小结

1. 先说暴力 O(n²)，再说优化到 O(n) 的**关键观察**（卖出日固定 → 买入点必须是前缀最小值）。
2. 主动指出**「不必担心内存泄漏/资源释放」**：全算法只用两个标量，无容器分配，无并发共享状态，天然线程安全（纯函数）。
3. 主动提**边界**：空数组、单元素、单调下跌（返回 0 而非负数）、价格全相等。
4. 主动提**推广**：改成可多次交易写 `dp1 = max(dp1, dp0 - p)` 一行即可，展示你掌握的是「模型」而非「背题」。
