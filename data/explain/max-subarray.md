## 力扣 53. 最大子数组和 题解

### 1) 思路推导

**问题本质**：在一个整数数组中，寻找一个**连续**子数组，使其元素之和最大。

**核心难点**：如何高效地处理“连续”这一约束，避免 O(n²) 的暴力枚举。

**关键观察**：
- 对于任意位置 `i`，以 `i` 结尾的最大子数组和，要么是**只包含 `nums[i]`**（即从 `i` 重新开始），要么是**`nums[i]` 加上以 `i-1` 结尾的最大子数组和**。
- 这形成了一个**最优子结构**，可以用动态规划或贪心思想解决。

**状态定义**：
- `dp[i]`：以 `nums[i]` 结尾的连续子数组的最大和。
- 转移方程：`dp[i] = max(nums[i], dp[i-1] + nums[i])`
- 最终答案：`max(dp[0], dp[1], ..., dp[n-1])`

**直观理解**：如果前面的累加和 `dp[i-1]` 是负数，加上它只会让当前值更小，不如从 `nums[i]` 重新开始。

---

### 2) 推荐解法与代码（Python）

**推荐解法：动态规划（空间优化版）**—— 只保留前一个状态，将空间复杂度从 O(n) 降到 O(1)。

```python
from typing import List

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        # 初始化：以第一个元素结尾的最大和就是它本身
        current_max = nums[0]   # 相当于 dp[i]
        global_max = nums[0]    # 记录全局最大值
        
        # 从第二个元素开始遍历
        for i in range(1, len(nums)):
            # 核心转移：要么从当前元素重新开始，要么累加前面的和
            current_max = max(nums[i], current_max + nums[i])
            # 更新全局最大值
            global_max = max(global_max, current_max)
        
        return global_max
```

**代码要点**：
- 使用 `current_max` 代替整个 `dp` 数组，因为转移只依赖前一个状态。
- 注意处理空数组的边界情况（虽然题目保证至少有一个元素，但防御性编程是好习惯）。

---

### 3) 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **O(n)** | 只需一次线性遍历 |
| 空间复杂度 | **O(1)** | 只使用两个变量，无额外数组 |

**为什么是最优**：任何算法至少需要读取每个元素一次，因此 O(n) 是下界，此解法已达到最优。

---

### 4) 其他解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 | 优缺点 |
|------|-----------|-----------|----------|--------|
| **暴力枚举** | O(n²) | O(1) | 枚举所有子数组 | 简单但不可行（n 大时超时） |
| **前缀和 + 最小前缀** | O(n) | O(1) | `sum[i] - min_prefix` | 思路巧妙，但需维护最小前缀，代码稍复杂 |
| **分治法** | O(n log n) | O(log n) | 递归分左右，跨中点合并 | 适合教学，但常数较大，非最优 |
| **动态规划（推荐）** | O(n) | O(1) | 状态转移 | 最简洁高效，易于理解 |

**分治法补充说明**：
- 将数组分为左右两半，最大子数组要么在左半、要么在右半、要么跨越中点。
- 跨中点的情况需要从中间向两边扩展求最大和。
- 时间复杂度 O(n log n)，但常数因子比 DP 大，实际性能略差。

### 5) 同类题拓展

| 题目 | 关联点 | 解题思路变化 |
|------|--------|-------------|
| **152. 乘积最大子数组** | 同样求连续子数组最值 | 需要同时维护最大和最小（因为负负得正） |
| **918. 环形子数组的最大和** | 数组首尾相连 | 分两种情况：不跨越边界（普通 DP）+ 跨越边界（总和 - 最小子数组和） |
| **121. 买卖股票的最佳时机** | 本质是求最大差值 | 可转化为最大子数组和（对价格差分） |
| **300. 最长递增子序列** | 子序列（非连续） | DP 状态变为 `dp[i]` 表示以 `i` 结尾的最长长度，转移需遍历前面所有元素 |
| **560. 和为 K 的子数组** | 子数组和计数 | 使用前缀和 + 哈希表，统计前缀和出现次数 |

**核心方法论**：
- 连续子数组问题 → 优先考虑**前缀和**或**动态规划**。
- 若要求“最大/最小和”，DP 通常是最优解。
- 若要求“和为某值的个数”，前缀和 + 哈希表是常用套路。

---

**总结**：最大子数组和是动态规划的经典入门题，核心在于理解“以 i 结尾”的状态定义和转移方程。掌握此题后，可以轻松迁移到乘积最大子数组、环形数组等变体问题。
