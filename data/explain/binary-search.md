## 704. 二分查找 题解

### 1. 思路推导

**问题本质**：在有序数组中快速定位目标值。由于数组已升序排列，可以利用**减治思想**——每次比较中间元素，将搜索范围缩小一半。

**关键决策点**：
- **区间定义**：左闭右闭 `[left, right]` 还是左闭右开 `[left, right)`？这直接影响循环条件和边界更新。
- **中间值计算**：使用 `mid = left + (right - left) // 2` 防止整数溢出（Python 中无此问题，但这是通用最佳实践）。
- **循环终止条件**：必须保证区间有效，否则会漏查或死循环。

**核心逻辑**：
```
初始化 left=0, right=n-1
while left <= right:
    mid = (left+right)//2
    if nums[mid] == target: return mid
    elif nums[mid] < target: left = mid+1  # 目标在右半区
    else: right = mid-1                    # 目标在左半区
return -1
```

---

### 2. 推荐解法与代码（Python）

```python
def search(nums: list[int], target: int) -> int:
    """
    标准二分查找（左闭右闭区间）
    :param nums: 升序整数数组
    :param target: 目标值
    :return: 目标下标，不存在返回 -1
    """
    left, right = 0, len(nums) - 1
    
    while left <= right:
        # 防止 left+right 溢出（Python 中无此问题，但保持习惯）
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1   # 目标在右半区，排除 mid
        else:
            right = mid - 1  # 目标在左半区，排除 mid
    
    return -1
```

**测试用例**：
```python
# 正常情况
print(search([-1,0,3,5,9,12], 9))   # 4
print(search([-1,0,3,5,9,12], 2))   # -1

# 边界情况
print(search([5], 5))               # 0
print(search([5], 4))               # -1
print(search([], 1))                # -1
print(search([1,2,3,4,5], 1))       # 0（最左）
print(search([1,2,3,4,5], 5))       # 4（最右）
```

### 3. 复杂度分析

| 维度 | 分析 |
|------|------|
| **时间复杂度** | O(log n)。每次迭代将搜索区间减半，最多执行 log₂(n) 次比较。 |
| **空间复杂度** | O(1)。仅使用常数个额外变量，无递归栈开销。 |
| **最坏情况** | 目标不存在或位于边界时，仍需 log₂(n) 次比较。 |

### 4. 其他解法对比

| 解法 | 思路 | 时间复杂度 | 空间复杂度 | 优缺点 |
|------|------|------------|------------|--------|
| **暴力遍历** | 线性扫描 | O(n) | O(1) | 简单但未利用有序性，大数据量下低效 |
| **递归二分** | 递归调用自身 | O(log n) | O(log n) 栈空间 | 代码简洁但栈开销大，可能栈溢出 |
| **左闭右开写法** | 区间 `[left, right)` | O(log n) | O(1) | 循环条件为 `left < right`，边界更新需注意，易错 |
| **Python bisect 模块** | `bisect_left` | O(log n) | O(1) | 一行代码，但需额外判断返回值是否越界 |

**推荐理由**：左闭右闭迭代版最直观、不易出错，且无递归栈风险，是面试和工程中的首选。
