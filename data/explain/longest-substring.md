# LeetCode 3. 无重复字符的最长子串 — 完整题解

> 给定字符串 `s`，找出其中不含重复字符的**连续子串**的最大长度。
> 约束：`0 <= s.length <= 5 * 10^4`，`s` 由英文字母、数字、符号和空格组成。

---

## 1. 思路推导

### 1.1 从暴力开始，找到瓶颈

最直白的做法：枚举左端点 `i`、右端点 `j`，再逐个扫描 `[i, j]` 判重。

- 枚举端点 `O(n²)` × 判重 `O(n)` = **`O(n³)`**，必然超时。
- 固定左端点 `i`，右端点 `j` 向右扩展，用一个 set 增量判重，遇到重复就停 → **`O(n²)`**（每个 `i` 内层最多扫 n 次）。

瓶颈在哪？**每个左端点都要重新把右指针从头扫一遍**，大量重复计算被浪费了。

### 1.2 关键观察：双指针的单调性

设 `f(l)` = 以 `l` 为左端点时，最长无重复子串的右端点。

> **引理（单调性）**：若 `[l, r]` 内无重复字符，则它的任意子区间 `[l', r]`（`l <= l' <= r`）也无重复字符。
> 因此 `f(l)` 随 `l` 增大而**不减** —— 左指针右移时，右指针**永远不需要回退**。

这一条就把 `O(n²)` 降到了 `O(n)`：

- `right` 单调右移，总共走 `n` 步；
- `left` 单调右移，总共最多走 `n` 步；
- 两个指针合计移动 `2n` 次，**均摊 O(n)**。

这就是滑动窗口（同向双指针）的适用性判定标准：**窗口性质对"收缩"具有单调性**。本题中"无重复"越短越容易成立，条件满足。

### 1.3 窗口内该维护什么？

窗口 `[left, right]` 始终保证"无重复"。当 `right` 右移遇到字符 `c` 时，有两种处理方式：

| 方案 | 做法 | 问题 |
|---|---|---|
| A. 用 `set` 存窗口字符 | `while c in set: set.remove(s[left]); left += 1` | 左指针只能**一格一格挪**，虽然均摊 O(n)，但常数偏大（同一字符被反复增删） |
| B. 用 `dict` 存"字符 → 最近出现下标" | 直接 `left = last[c] + 1` **跳跃** | 常数更小，且一次定位到位 ✅ |

**推荐方案 B**：用哈希表记住每个字符上一次出现的位置，遇到重复时直接把左边界跳到"上次出现位置 + 1"。

### 1.4 ⚠️ 最大的坑：`left` 不能回退

很多人的写法是 `left = last[ch] + 1`，这是**错的**。因为 `last[ch]` 记录的可能是窗口外的旧位置（早已被跳过），直接赋值会让 `left` 往回走，窗口重新包含重复字符，答案偏大。

正确写法必须取 `max`：

```python
left = max(left, last.get(ch, -1) + 1)
```

**反例 `"abba"`**（答案应为 2）：

| right | ch | last[ch] | 正确 left | 错误写法 left |
|---|---|---|---|---|
| 0 | a | -1 | 0 | 0 |
| 1 | b | -1 | 0 | 0 |
| 2 | b | 1 | **2** | 2 |
| 3 | a | 0 | **2**（不回退） | 1 ❌ → 窗口 `"bba"` 长度 3 |

## 2. 推荐解法与代码（Python）

### 2.1 主解：滑动窗口 + 哈希表跳跃

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        """滑动窗口：窗口 [left, right] 内始终无重复字符。

        时间 O(n)，空间 O(min(n, |Σ|))。
        """
        last: dict[str, int] = {}   # 字符 -> 最近一次出现的下标
        left = 0                    # 窗口左边界，单调不减
        best = 0                    # 记录历史最大窗口长度

        for right, ch in enumerate(s):
            prev = last.get(ch, -1)         # 上一次出现的位置，没出现过视为 -1
            if prev >= left:                # 上一次出现仍在窗口内 -> 必须收缩
                left = prev + 1             # 直接跳到重复字符的右侧（等价于 max(left, prev + 1)）
            last[ch] = right
            # 此时 [left, right] 一定无重复，可安全更新答案
            best = max(best, right - left + 1)

        return best
```

> **边界检查**：空串时循环不执行，直接返回 `0` ✅；单字符返回 `1` ✅；全相同串（`"bbbb"`）返回 `1` ✅。
> 这里没有 `while`，每个字符只被处理一次，**严格 O(n)**，不是均摊。

**示例 `"abcabcbb"` 轨迹：**

| right | ch | prev | left | 窗口 | best |
|---|---|---|---|---|---|
| 0 | a | -1 | 0 | `a` | 1 |
| 1 | b | -1 | 0 | `ab` | 2 |
| 2 | c | -1 | 0 | `abc` | 3 |
| 3 | a | 0 | 1 | `bca` | 3 |
| 4 | b | 1 | 2 | `cab` | 3 |
| 5 | c | 2 | 3 | `abc` | 3 |
| 6 | b | 4 | 5 | `b` | 3 |
| 7 | b | 6 | 7 | `b` | 3 |

### 2.2 工程优化版：定长数组（仅限 ASCII）

若明确输入字符集有限（本题为英文字母/数字/符号/空格，共 95 个可打印字符），用数组代替 dict 可再快一截 —— **前提是字符集确定**，否则请用 dict：

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = [-1] * 128            # 仅当字符均在 ASCII 范围内时可用
        left = best = 0
        for right, ch in enumerate(s):
            idx = ord(ch)
            if last[idx] >= left:
                left = last[idx] + 1
            last[idx] = right
            best = max(best, right - left + 1)
        return best
```

### 2.3 通用模板版（易迁移到同类题）

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        window = set()          # 窗口内字符集合
        left = best = 0
        for right, ch in enumerate(s):
            while ch in window:          # 不合法 -> 收缩到合法
                window.remove(s[left])
                left += 1
            window.add(ch)               # 合法 -> 扩张
            best = max(best, right - left + 1)
        return best
```

这个版本可读性最好，`while` 中 `left` 最多前进 n 次，**均摊 O(n)**。代价是常数略大，运行时间通常比 2.1 慢 10%~30%（字符串越长差距越明显）。

### 2.4 测试用例（建议覆盖）

```python
sol = Solution()
assert sol.lengthOfLongestSubstring("abcabcbb") == 3
assert sol.lengthOfLongestSubstring("bbbbb")    == 1
assert sol.lengthOfLongestSubstring("pwwkew")   == 3
assert sol.lengthOfLongestSubstring("")         == 0      # 边界
assert sol.lengthOfLongestSubstring(" ")        == 1      # 空格
assert sol.lengthOfLongestSubstring("abba")     == 2      # 陷阱用例
assert sol.lengthOfLongestSubstring("dvdf")     == 3
assert sol.lengthOfLongestSubstring("tmmzuxt")  == 5      # left 不回退
```

`"tmmzuxt"` 是验证 `left` 单调性的好例子：扫描到最后 `t` 时，`last['t'] = 0 < left = 2`，**不能**把 `left` 退回到 1。

## 3. 复杂度分析

| 维度 | 结论 | 说明 |
|---|---|---|
| **时间** | `O(n)` | `right` 遍历一次共 n 步；`left` 单调递增、总计最多 n 步。哈希表 `get/set` 均摊 O(1)。 |
| **空间** | `O(min(n, |Σ|))` | 哈希表最多存 n 个字符键；实际受字符集大小 `|Σ|` 限制（本题 ASCII 约 128）。数组版则为固定的 `O(|Σ|)` = `O(1)`。 |
| **额外开销** | — | 无递归，无额外数组拷贝；函数返回后 dict 由 GC 回收，无资源泄漏风险。 |

对比：暴力 `O(n³)`，暴力+set `O(n²)`，本解法已到**理论下界**（任何字符至少要被看一次）。

## 4. 其他解法对比

| 解法 | 时间 | 空间 | 评价 |
|---|---|---|---|
| 暴力三循环 | `O(n³)` | `O(1)`/`O(n)` | ❌ 必超时，仅用于讲清问题 |
| 暴力 + set 增量判重 | `O(n²)` | `O(Σ)` | ⚠️ 能过但慢，右指针重复回扫 |
| 滑动窗口 + set（模板版） | 均摊 `O(n)` | `O(Σ)` | ✅ 可读性最佳，常数略大 |
| **滑动窗口 + dict 跳跃（推荐）** | **`O(n)`** | `O(Σ)` | ✅✅ **最优，常数最小，通用（支持 Unicode）** |
| 滑动窗口 + 定长数组 | `O(n)` | `O(1)` | ✅ 最快，但依赖字符集假设，可移植性差 |
| 动态规划 | `O(n)` | `O(Σ)` | ✅ 正确但不优，分支多、可读性差 |
| 后缀自动机/后缀数组 | `O(n)` | `O(n)` | ❌ 严重过度设计，常数巨大 |

**DP 解法**（思维训练价值 > 工程价值）：设 `dp[i]` 为"以 `s[i]` 结尾"的最长无重复子串长度：

```
令 last[c] = c 上次出现的下标（不存在为 -1）
dp[i] = dp[i-1] + 1            若 last[s[i]] < i - dp[i-1]   （上次出现已在窗口外）
      = i - last[s[i]]         否则                        （窗口被迫截断）
```

它和滑动窗口在数学上**完全等价**（`dp[i]` 就是 `right - left + 1`），只是换了个表达角度。面试时先讲滑动窗口，若被追问"有没有别的角度"，再补 DP。

**面试口述版**（30 秒）：

> "枚举右端点，维护一个无重复的窗口。用哈希表记录每个字符最后出现的位置；遇到重复字符就把左边界跳到它上次出现位置的右边，同时保证左边界不回退。右端点扫一遍，答案取所有窗口长度的最大值，时间 O(n)，空间 O(字符集大小)。"

## 5. 同类题拓展

滑动窗口题可按"求最长 / 最短"与"判定条件"分四类，本题属于 **最长 + 计数类约束**。

| 题号 | 题目 | 与本题的差异 | 关键改动 |
|---|---|---|---|
| **159** | 至多包含两个不同字符的最长子串 | 约束从"无重复"变为"不同字符数 ≤ 2" | 窗口维护 `Counter`，`len(counter) > 2` 时收缩 |
| **340** | 至多包含 K 个不同字符的最长子串 | 同上，K 为参数 | 同上，判据换成 `> K` |
| **992** | K 个不同整数的子数组（困难） | 求"恰好 K 个"的**子数组个数** | "恰好"不单调，转成 `atMost(K) - atMost(K-1)`，答案累加 `right-left+1` |
| **76** | 最小覆盖子串（困难） | 求**最短**窗口，且是多字符集覆盖 | 改"最短模板"：先扩张到满足，再收缩记录答案 |
| **438 / 567** | 找字母异位词 / 字符串的排列 | **固定长度**窗口 | 窗口长度恒为 `len(p)`，比较计数向量是否相等 |
| **209** | 长度最小的子数组 | 最短窗口 + 正整数 | 和 ≥ target 时收缩 |
| **1004** | 最大连续 1 的个数 III | 最长窗口，约束是"0 的个数 ≤ K" | 可用"窗口只增不减"技巧（`if` 代替 `while`） |
| **424** | 替换后的最长重复字符 | 约束是"非众数字符数 ≤ K" | 维护窗口内字符最大频次 `maxFreq` |
| **1208** | 尽可能使字符串相等 | 约束是"代价和 ≤ maxCost" | 窗口维护 `abs(s[i]-t[i])` 前缀代价 |
| **395** | 至少有 K 个重复字符的最长子串 | 约束"每个字符出现次数 ≥ K" | ⚠️ 不满足单调性，需**枚举字符种数**（26 种）或分治 |
| **剑指 Offer 48** | 最长不含重复字符的子字符串 | 与本题**完全相同** | 直接复用 |

### 通用滑动窗口模板

```python
def longest_window(s):
    left, best = 0, 0
    window = {}                      # 或 Counter / set，按题型选
    for right, ch in enumerate(s):
        # 1) 扩张：把 s[right] 并入窗口
        window[ch] = window.get(ch, 0) + 1

        # 2) 收缩：while 窗口不合法，左边界右移
        while <窗口不合法>:
            window[s[left]] -= 1
            if window[s[left]] == 0:
                del window[s[left]]
            left += 1

        # 3) 此刻窗口合法，更新答案（最长类题目的标准位置）
        best = max(best, right - left + 1)
    return best
```

**选型口诀**：

- **求最长** → 先扩张，不合法就收缩，收缩后更新答案（本题）；
- **求最短** → 先扩张到合法，再尽力收缩并更新答案（76、209）；
- **求"恰好 K"的个数** → 拆成 `atMost(K) − atMost(K-1)`（992）；
- **约束破坏单调性**（如 395 的"每个字符至少 K 次"）→ 滑动窗口失效，需枚举维度或分治。

## 6. 小结

1. **核心是单调性**：`[l, r]` 合法 ⇒ `[l+1, r]` 合法，所以左指针不必回退，`O(n²)` 降到 `O(n)`。
2. **哈希表记录"最近位置"而非单纯判重**，才能一步跳到正确位置。
3. **`left = max(left, last[ch] + 1)`** —— 这行代码是本题的分水岭，用 `"abba"`、`"tmmzuxt"` 自测即可发现写错。
4. **边界**：空串、单字符、全重复串，一行 `best = 0` 的初值天然覆盖。
5. **通用性**：dict 版本支持任意 Unicode 输入，是生产环境的默认选择；数组版本是 ASCII 场景下的性能特化。
