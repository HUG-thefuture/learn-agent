## 🧠 概念讲解

### 1. 什么是条件语句？

> 📌 **条件语句就像一个“选择题”**，程序会根据条件是否成立，选择执行哪段代码。

- `if`：如果条件成立，就执行某段代码。
- `elif`：如果前面的条件不成立，再判断这个条件是否成立。
- `else`：如果前面的条件都不成立，就执行这段代码。

> 📌 **为什么需要条件语句？**  
因为现实世界中，很多情况是“根据不同的条件做不同的事情”，比如：
- 如果今天下雨，就带伞；
- 如果今天晴天，就去公园。

### 2. 什么是循环？

> 📌 **循环就像“重复做某件事”**，程序会重复执行某段代码，直到满足某个条件。

- `for`：用于遍历一个序列（如列表、字符串等）。
- `while`：只要条件为真，就一直执行循环体。

> 📌 **为什么需要循环？**  
因为很多任务需要重复执行，比如：
- 打印 1 到 10 的数字；
- 遍历一个列表，逐个处理每个元素。

## 📌 示例代码（由浅入深）

### 示例 1：判断数字大小（`if` 语句）

```python
# 示例：判断一个数字是正数、负数还是零
num = 5

if num > 0:
    print("这是一个正数")
elif num < 0:
    print("这是一个负数")
else:
    print("这是零")
```

> ✅ 输出：
```
这是一个正数
```

---

### 示例 2：遍历列表（`for` 循环）

```python
# 示例：遍历一个列表，输出每个元素
fruits = ["苹果", "香蕉", "橘子"]

for fruit in fruits:
    print(fruit)
```

> ✅ 输出：
```
苹果
香蕉
橘子
```

---

### 示例 3：使用 `while` 循环计算累加（直到达到某个值）

```python
# 示例：使用 while 循环计算 1 到 10 的和
total = 0
count = 1

while count <= 10:
    total += count
    count += 1

print("1 到 10 的和是:", total)
```

> ✅ 输出：
```
1 到 10 的和是: 55
```

## 📊 常用函数/调用速查表

| 函数 | 签名 | 用途 | 最小示例 |
|------|------|------|----------|
| `if` | `if 条件:` | 条件判断 | `if x > 0: print("正数")` |
| `elif` | `elif 条件:` | 多条件判断 | `elif x < 0: print("负数")` |
| `else` | `else:` | 默认情况 | `else: print("零")` |
| `for` | `for 变量 in 序列:` | 遍历序列 | `for i in range(5): print(i)` |
| `while` | `while 条件:` | 循环执行 | `while x < 10: x += 1` |

---

## ⚠️ 新手易错点

| 错误写法 | 正确写法 | 说明 |
|----------|----------|------|
| `if x = 5:` | `if x == 5:` | `=` 是赋值，`==` 是比较 |
| `for i in range(5): print(i)` | `for i in range(5): print(i)` | 语法正确，但注意缩进 |
| `while x < 10: x += 1` | `while x < 10: x += 1` | 语法正确，但注意循环条件 |
| `if x > 0: print("正数")` | `if x > 0: print("正数")` | 缩进错误会导致语法错误 |
| `for i in range(5): print(i)` | `for i in range(5): print(i)` | 语法正确，但注意缩进 |

## 🧪 本课小练习

### 题目 1：判断一个数是奇数还是偶数

```python
num = int(input("请输入一个数字："))
if num % 2 == 0:
    print("这是一个偶数")
else:
    print("这是一个奇数")
```

✅ **答案：**
- 如果输入是 `4`，输出是 `这是一个偶数`
- 如果输入是 `7`，输出是 `这是一个奇数`

### 题目 2：使用 `for` 循环打印 1 到 5 的数字

```python
for i in range(1, 6):
    print(i)
```

✅ **答案：**
```
1
2
3
4
5
```
