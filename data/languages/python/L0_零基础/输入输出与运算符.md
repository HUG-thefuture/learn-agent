## 🧠 概念讲解

### 1. `input()`：程序的"耳朵"

> 📌 **`input()` 就像餐厅的收银员问你："您要点什么？"**
> 程序运行到这里会**停下来等你打字**，你按下回车后，它才继续往下走。

```python
name = input("你叫什么名字？")
```

- 括号里的 `"你叫什么名字？"` 是**提示语**，会先显示在屏幕上。
- 你输入的内容会被存进变量 `name`。

> ⚠️ **重要**：`input()` 拿到的**永远是字符串（str）**，哪怕你输入的是数字 `18`，它也是 `"18"`（带引号的文本），不能直接做数学计算！

### 2. 为什么需要类型转换？

想象你告诉收银员"我要 3 杯奶茶"，收银员记下来的是**文字"3"**，不是**数字 3**。要算账，必须先把文字变成数字：

```python
age = input("你几岁？")      # age 是字符串，比如 "18"
age = int(age)               # 用 int() 把字符串转成整数
print(age + 1)               # 现在可以计算了：19
```

也可以合并成一行（新手常用写法）：

```python
age = int(input("你几岁？"))
```

### 3. `print()` 的更多本领

`print()` 可以一次输出多个东西，用逗号隔开，中间会自动加空格：

```python
name = "小明"
age = 18
print("我叫", name, "，今年", age, "岁")
# 输出：我叫 小明 ，今年 18 岁
```

还可以用 **f-string**（推荐！）把变量"嵌"进字符串里，更整齐：

```python
print(f"我叫{name}，今年{age}岁")
# 输出：我叫小明，今年18岁
```

> 📌 f-string 就像**填空题**：在字符串前加 `f`，用 `{}` 标出要填的位置。

### 4. 运算符：让计算机做计算

运算符就是"计算的符号"，分几大类：

**算术运算符**（做数学运算）：

| 符号 | 含义 | 例子 | 结果 |
|------|------|------|------|
| `+` | 加 | `3 + 2` | `5` |
| `-` | 减 | `3 - 2` | `1` |
| `*` | 乘 | `3 * 2` | `6` |
| `/` | 除（结果是小数） | `7 / 2` | `3.5` |
| `//` | 整除（只要整数部分） | `7 // 2` | `3` |
| `%` | 取余（余数） | `7 % 2` | `1` |
| `**` | 乘方 | `2 ** 3` | `8` |

> 📌 `%` 取余很好理解：**7 个苹果分给 2 个人，每人 3 个，还剩 1 个**——这个"1"就是 `7 % 2` 的结果。判断奇偶数全靠它！

**比较运算符**（结果是 `True` 或 `False`）：

| 符号 | 含义 | 例子 | 结果 |
|------|------|------|------|
| `==` | 等于 | `3 == 3` | `True` |
| `!=` | 不等于 | `3 != 3` | `False` |
| `>` | 大于 | `5 > 3` | `True` |
| `<` | 小于 | `5 < 3` | `False` |
| `>=` | 大于等于 | `5 >= 5` | `True` |
| `<=` | 小于等于 | `4 <= 5` | `True` |

> ⚠️ 注意：**判断相等用 `==`（两个等号）**，一个 `=` 是赋值（把东西装进盒子），别搞混！

## 💻 示例代码

### 示例 1：最简单的对话程序

```python
# 程序问你的名字，然后打招呼
name = input("你叫什么名字？")
print("你好，" + name + "！欢迎学习 Python！")
```

运行效果：

```text
你叫什么名字？小明
你好，小明！欢迎学习 Python！
```

### 示例 2：年龄计算器（输入 + 类型转换 + 运算）

```python
# 输入年龄，算出 10 年后的年龄
age_text = input("请输入你的年龄：")   # 拿到的是字符串，比如 "18"
age = int(age_text)                    # 转成整数才能计算

future_age = age + 10
print(f"你今年 {age} 岁，10 年后你就 {future_age} 岁啦！")
```

运行效果：

```text
请输入你的年龄：18
你今年 18 岁，10 年后你就 28 岁啦！
```

### 示例 3：分苹果小助手（综合运用）

```python
# 输入苹果总数和人数，计算每人分几个、剩几个
apples = int(input("一共有多少个苹果？"))
people = int(input("一共有几个人？"))

each = apples // people      # 整除：每人分到几个
left = apples % people       # 取余：还剩几个

print(f"每人分到 {each} 个苹果，还剩 {left} 个。")

# 顺便判断一下：苹果够不够每人至少 1 个？
enough = each >= 1
print("每人都能分到至少 1 个吗？", enough)
```

运行效果：

```text
一共有多少个苹果？7
一共有几个人？2
每人分到 3 个苹果，还剩 1 个。
每人都能分到至少 1 个吗？ True
```

## 📋 常用函数/运算符速查表

| 函数/符号 | 签名 | 用途 | 最小示例 |
|-----------|------|------|----------|
| `input()` | `input(提示语)` | 接收用户输入（返回字符串） | `name = input("名字？")` |
| `print()` | `print(值1, 值2, ...)` | 输出内容到屏幕 | `print("你好", name)` |
| `int()` | `int(值)` | 转成整数 | `int("18")` → `18` |
| `float()` | `float(值)` | 转成小数 | `float("3.5")` → `3.5` |
| `str()` | `str(值)` | 转成字符串 | `str(18)` → `"18"` |
| `+ - * /` | 算术运算 | 加减乘除 | `7 / 2` → `3.5` |
| `//` | `a // b` | 整除（取商） | `7 // 2` → `3` |
| `%` | `a % b` | 取余数 | `7 % 2` → `1` |
| `**` | `a ** b` | 乘方 | `2 ** 3` → `8` |
| `==` | `a == b` | 判断是否相等 | `3 == 3` → `True` |

## ⚠️ 5 个新手易错点

### 1. 忘记把 `input()` 的结果转成数字

```python
# ❌ 错误：字符串相加是"拼接"，不是数学加法
age = input("年龄：")     # 输入 18
print(age + 1)            # 报错！字符串不能加数字

# ✅ 正确：先用 int() 转换
age = int(input("年龄："))
print(age + 1)            # 输出 19
```

### 2. 把 `=` 和 `==` 搞混

```python
# ❌ 错误：想比较却用了赋值
if age = 18:      # 报错！

# ✅ 正确：比较用两个等号
if age == 18:
    print("成年啦")
```

### 3. 以为 `/` 的结果是整数

```python
# ❌ 错误预期
print(10 / 2)     # 新手以为输出 5

# ✅ 实际：/ 的结果一定是小数
print(10 / 2)     # 输出 5.0
print(10 // 2)    # 想要整数用 //，输出 5
```

### 4. 字符串和数字直接拼接

```python
# ❌ 错误：字符串 + 数字会报错
age = 18
print("我" + age + "岁")

# ✅ 正确：用 f-string，或先把数字转成字符串
print(f"我{age}岁")
print("我" + str(age) + "岁")
```

### 5. 除数为 0

```python
# ❌ 错误：数学上不能除以 0，程序会崩溃
people = 0
print(10 / people)    # ZeroDivisionError！

# ✅ 正确：先检查再计算
people = int(input("几个人？"))
if people != 0:
    print(10 / people)
else:
    print("人数不能是 0！")
```

### 练习 2：判断奇偶数

编写程序：让用户输入一个整数，判断它是**奇数还是偶数**并输出结果。
（提示：偶数除以 2 的余数是 0）

<details>
<summary>👉 点击查看答案</summary>

```python
num = int(input("请输入一个整数："))

if num % 2 == 0:
    print(f"{num} 是偶数。")
else:
    print(f"{num} 是奇数。")
```

> 思路：`num % 2` 算出余数，余数为 0 就是偶数，否则是奇数。
</details>

## 🎉 本课小结

- `input()` 让程序能接收输入，但**拿到的永远是字符串**，要计算先 `int()` 转换。
- `print()` 配合 **f-string** 可以漂亮地输出内容。
- 算术运算符（`+ - * / // % **`）负责计算，比较运算符（`== != > <`）负责判断。
- 记住两大天坑：**`=` 是赋值，`==` 是比较**；**`/ 的结果是小数**。
