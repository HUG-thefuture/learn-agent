## 🧠 概念讲解

### 1. 什么是变量？

> 📌 **变量就像一个贴了标签的盒子。**  
> 你把数据放进盒子里，然后给盒子贴一个名字。以后只要叫这个名字，就能找到里面的数据。

例如：

```python
name = "小明"
```

这行代码的意思是：

> 把字符串 `"小明"` 放进一个盒子里，并给这个盒子贴上标签 `name`。

以后你可以这样使用它：

```python
print(name)
```

输出：

```text
小明
```

---

### 2. 赋值符号 `=` 不是数学里的“等于”

很多新手会误解：

```python
age = 18
```

它不是数学里的“age 等于 18”。

在 Python 里，它应该读作：

> **把右边的值赋给左边的变量。**

也就是：

```python
age = 18
```

意思是：

> 把 `18` 放进名为 `age` 的变量里。

---

### 3. 什么是数据类型？

> 📌 **数据类型就像盒子里装的东西的种类。**

同样是盒子里的东西：

- 装数字，可以加减乘除。
- 装文字，可以拼接、查找。
- 装“真/假”，可以做判断。

Python 常见基础数据类型有：

| 类型 | 英文 | 例子 | 说明 |
|---|---|---|---|
| 整数 | `int` | `18`, `0`, `-5` | 没有小数点的数字 |
| 浮点数 | `float` | `1.75`, `3.14`, `-0.5` | 有小数点的数字 |
| 字符串 | `str` | `"小明"`, `"Python"` | 文字内容，需要用引号包起来 |
| 布尔值 | `bool` | `True`, `False` | 表示真或假 |
| 空值 | `None` | `None` | 表示“没有值” |

---

### 4. 为什么需要数据类型？

因为 Python 需要知道：

> 这个数据能做什么操作？

例如：

```python
1 + 2
```

得到：

```text
3
```

因为 `1` 和 `2` 是数字，可以相加。

但是：

```python
"1" + "2"
```

得到：

```text
12
```

因为 `"1"` 和 `"2"` 是字符串，`+` 在这里表示拼接。

所以数据类型很重要。

---

### 5. Python 是动态类型语言

在 Python 里，变量不需要提前声明类型。

例如：

```python
x = 10
x = "hello"
```

这是允许的。

第一次：

```python
x = 10
```

`x` 里面是整数。

第二次：

```python
x = "hello"
```

`x` 里面变成了字符串。

> 📌 Python 会根据你赋的值，自动判断变量当前的数据类型。

这叫 **动态类型**。

---

### 6. 变量命名规则

变量名要遵守一些规则：

✅ 可以使用：

- 字母
- 数字
- 下划线 `_`

✅ 推荐：

```python
name = "小明"
age = 18
user_name = "Alice"
is_student = True
```

❌ 不能这样：

```python
2name = "小明"
my name = "小明"
```

原因：

- 变量名不能以数字开头。
- 变量名中间不能有空格。

另外，Python 区分大小写：

```python
Name = "小明"
name = "小红"
```

这是两个不同的变量。

## 💻 示例 1：认识变量和常见数据类型

这个示例帮助你认识：

- 如何创建变量
- 如何查看变量类型
- 常见数据类型有哪些

```python
# 示例 1：认识变量和常见数据类型

# 1. 定义一个字符串变量
# 字符串需要用引号包起来，单引号或双引号都可以
name = "小明"

# 2. 定义一个整数变量
# 整数是没有小数点的数字
age = 18

# 3. 定义一个浮点数变量
# 浮点数就是小数
height = 1.75

# 4. 定义一个布尔值变量
# 布尔值只有两个：True 和 False，注意首字母大写
is_student = True

# 5. 定义一个空值变量
# None 表示“没有值”，不是 0，也不是空字符串
score = None

# 6. 输出变量的值
print("姓名：", name)
print("年龄：", age)
print("身高：", height)
print("是否学生：", is_student)
print("成绩：", score)

print("-" * 20)

# 7. 查看变量的数据类型
# type() 函数可以查看一个数据属于什么类型
print("name 的类型：", type(name))
print("age 的类型：", type(age))
print("height 的类型：", type(height))
print("is_student 的类型：", type(is_student))
print("score 的类型：", type(score))
```

运行结果类似：

```text
姓名： 小明
年龄： 18
身高： 1.75
是否学生： True
成绩： None
--------------------
name 的类型： <class 'str'>
age 的类型： <class 'int'>
height 的类型： <class 'float'>
is_student 的类型： <class 'bool'>
score 的类型： <class 'NoneType'>
```

## 💻 示例 2：用户输入与类型转换

这个示例帮助你理解：

- `input()` 获取用户输入
- `input()` 得到的结果默认是字符串
- 需要用 `int()` 或 `float()` 转换成数字

```python
# 示例 2：用户输入与类型转换

# 1. 获取用户输入
# 注意：input() 返回的结果默认是字符串 str
price_text = input("请输入商品价格：")
quantity_text = input("请输入购买数量：")

# 2. 查看输入结果的类型
print("price_text 的类型：", type(price_text))
print("quantity_text 的类型：", type(quantity_text))

# 3. 把字符串转换成数字
# 价格可能有小数，所以用 float()
# 数量一般是整数，所以用 int()
price = float(price_text)
quantity = int(quantity_text)

# 4. 计算总价
total = price * quantity

# 5. 输出结果
print("商品总价：", total)
print("total 的类型：", type(total))
```

运行示例：

```text
请输入商品价格：9.9
请输入购买数量：3
price_text 的类型： <class 'str'>
quantity_text 的类型： <class 'str'>
商品总价： 29.7
total 的类型： <class 'float'>
```

> ⚠️ 注意：如果用户输入的不是数字，例如输入了 `"abc"`，程序会报错。  
> 这是正常现象，后面学习条件判断和异常处理后可以避免。

## 💻 示例 3：保存变量内容到文件并读取

这个示例帮助你理解：

- 变量可以保存数据
- 数据可以写入文件
- 文件读取后也可以赋值给变量
- 使用 `with open(...)` 可以自动释放文件资源

```python
# 示例 3：保存变量内容到文件并读取
# 这个示例会创建一个临时文件，读取后再删除，避免留下垃圾文件

import os

# 1. 定义要保存的数据
name = "小明"
age = 18
height = 1.75
is_student = True

# 2. 把数据转换成字符串，方便写入文件
# 文件里保存的是文本内容，所以通常需要先变成字符串
content = f"姓名：{name}\n年龄：{age}\n身高：{height}\n是否学生：{is_student}\n"

# 3. 定义文件名
filename = "student_info.txt"

# 4. 写入文件
# with open(...) 会自动关闭文件，即使中间出错也会关闭
# 这就是资源释放的一种常见方式
with open(filename, "w", encoding="utf-8") as file:
    file.write(content)

print("数据已保存到文件：", filename)

# 5. 读取文件
with open(filename, "r", encoding="utf-8") as file:
    read_content = file.read()

# 6. 输出读取到的内容
print("-" * 20)
print("从文件读取到的内容：")
print(read_content)
print("-" * 20)

# 7. 删除临时文件，释放磁盘空间
# 这里是为了让示例运行后不留下多余文件
os.remove(filename)
print("临时文件已删除。")
```

运行结果类似：

```text
数据已保存到文件： student_info.txt
--------------------
从文件读取到的内容：
姓名：小明
年龄：18
身高：1.75
是否学生：True

--------------------
临时文件已删除。
```

> 📌 资源释放小知识：  
> 文件、网络连接、数据库连接等资源，使用后最好关闭。  
> Python 里常用 `with open(...)`，它会自动帮你关闭文件。

## ⚠️ 5 个新手易错点

### 易错点 1：把 `=` 当成数学等于

❌ 错误写法：

```python
age = 18
if age = 18:
    print("成年了")
```

✅ 正确写法：

```python
age = 18
if age == 18:
    print("成年了")
```

解释：

- `=` 是赋值。
- `==` 才是判断是否相等。

---

### 易错点 2：变量名以数字开头

❌ 错误写法：

```python
2name = "小明"
```

✅ 正确写法：

```python
name2 = "小明"
```

解释：

变量名不能以数字开头。

---

### 易错点 3：字符串忘记加引号

❌ 错误写法：

```python
name = 小明
```

✅ 正确写法：

```python
name = "小明"
```

解释：

文字内容必须用引号包起来，例如：

```python
name = "小明"
name = '小明'
```

---

### 易错点 4：把 `input()` 的结果直接当数字计算

❌ 错误写法：

```python
age = input("请输入年龄：")
next_year_age = age + 1
```

✅ 正确写法：

```python
age = int(input("请输入年龄："))
next_year_age = age + 1
```

解释：

`input()` 返回的是字符串，例如 `"18"`。  
字符串不能直接和数字相加，需要先转换成整数。

---

### 易错点 5：变量名大小写不一致

❌ 错误写法：

```python
Name = "小明"
print(name)
```

✅ 正确写法：

```python
name = "小明"
print(name)
```

解释：

Python 区分大小写。  
`Name` 和 `name` 是两个不同的变量。
