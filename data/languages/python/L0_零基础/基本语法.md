## 一、核心概念讲解

Python 是一种**动态类型**、**解释型**、**高级语言**，具有简洁的语法和强大的功能，广泛应用于数据科学、Web开发、自动化脚本等领域。

### 1. 数据类型

Python 中的数据类型包括：

- **基本类型**：`int`（整数）、`float`（浮点数）、`str`（字符串）、`bool`（布尔值）、`None`（空值）
- **容器类型**：`list`（列表）、`tuple`（元组）、`dict`（字典）、`set`（集合）
- **其他类型**：`bytes`（字节）、`range`（范围）、`complex`（复数）

> **注意**：Python 的变量不需要声明类型，类型在运行时自动推断。

### 2. 变量与赋值

Python 使用 `=` 进行赋值，变量名需符合命名规则（如不能以数字开头，不能使用关键字等）。

> **内存注意点**：Python 使用引用计数和垃圾回收机制管理内存，避免内存泄漏。

### 3. 控制结构

- **条件语句**：`if`、`elif`、`else`
- **循环语句**：`for`、`while`
- **异常处理**：`try`、`except`、`finally`

> **性能注意点**：避免在循环中频繁调用函数或进行复杂计算，尽量使用列表推导式或生成器。

### 4. 函数与模块

- **函数定义**：使用 `def` 关键字
- **模块导入**：使用 `import` 或 `from ... import ...`

> **性能注意点**：避免重复导入模块，使用 `__init__.py` 管理包结构。

## 三、常用函数/调用速查表

| 函数 | 签名 | 说明 | 示例 |
|------|------|------|------|
| `print()` | `print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)` | 输出内容到控制台 | `print("Hello, World!")` |
| `len()` | `len(obj)` | 返回对象的长度（如字符串、列表等） | `len([1, 2, 3])` → 3 |
| `type()` | `type(obj)` | 返回对象的类型 | `type(10)` → `<class 'int'>` |
| `range()` | `range(start, stop, step)` | 生成一个整数序列 | `list(range(0, 10, 2))` → [0, 2, 4, 6, 8] |
| `input()` | `input(prompt='')` | 从用户输入中读取字符串 | `name = input("请输入你的名字：")` |
| `open()` | `open(file, mode='r', encoding=None)` | 打开文件 | `with open("test.txt", "r") as f: print(f.read())` |
| `str()` | `str(obj)` | 将对象转换为字符串 | `str(100)` → "100" |
| `int()` | `int(obj)` | 将对象转换为整数 | `int("123")` → 123 |
| `float()` | `float(obj)` | 将对象转换为浮点数 | `float("3.14")` → 3.14 |
| `list()` | `list(iterable)` | 将可迭代对象转换为列表 | `list("abc")` → ['a', 'b', 'c'] |
| `dict()` | `dict(**kwargs)` | 创建字典 | `dict(name="Alice", age=25)` → {'name': 'Alice', 'age': 25} |

## 四、5个易错点

### 1. **变量作用域问题**

**错误示例**：
```python
def func():
    x = 10
print(x)  # 报错：NameError: name 'x' is not defined
```

**正确写法**：
```python
def func():
    x = 10
    print(x)

func()
```

---

### 2. **忘记缩进**

**错误示例**：
```python
if True:
print("Hello")  # 报错：IndentationError
```

**正确写法**：
```python
if True:
    print("Hello")
```

---

### 3. **使用 `==` 而不是 `is` 判断身份**

**错误示例**：
```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True
print(a is b)  # False
```

**说明**：`==` 比较值，`is` 比较对象身份（内存地址）。

---

### 4. **忘记关闭文件**

**错误示例**：
```python
f = open("test.txt", "r")
data = f.read()
# 忘记关闭文件
```

**正确写法**：
```python
with open("test.txt", "r") as f:
    data = f.read()
```

---

### 5. **在循环中修改列表**

**错误示例**：
```python
nums = [1, 2, 3, 4, 5]
for num in nums:
    if num % 2 == 0:
        nums.remove(num)
print(nums)  # 输出: [1, 3, 5]
```

**说明**：在循环中修改列表可能导致跳过元素或逻辑错误。

**正确写法**：
```python
nums = [1, 2, 3, 4, 5]
new_nums = [num for num in nums if num % 2 != 0]
print(new_nums)  # 输出: [1, 3, 5]
```
