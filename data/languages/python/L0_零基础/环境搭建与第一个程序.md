## 🧠 概念讲解

### 1. 什么是 Python 环境？

> 📌 **Python 环境**就像你写作文时的“笔和纸”，它提供了一个运行 Python 代码的地方。你可以把它想象成一个“编程工具箱”。

- **Python 解释器**：就像一个“翻译官”，把你的 Python 代码翻译成计算机能理解的指令。
- **开发工具**：比如 IDLE、VS Code、PyCharm 等，它们是“写字板”和“排版工具”，帮助你编写、调试和运行代码。

### 2. 什么是 Python 程序？

> 📌 **Python 程序**就是你写的一段 Python 代码，它告诉计算机“你要做什么”。

- 程序通常由多个语句组成，每行代码执行一个操作。
- 程序可以输出信息（比如“Hello, World!”）、处理数据、控制流程等。

### 3. 什么是变量和数据类型？

> 📌 **变量**就像一个“盒子”，你可以把不同的东西放进这个盒子里。**数据类型**就是这个盒子里装的是什么。

- **整数（int）**：像 1, 2, 3 这样的数字。
- **浮点数（float）**：像 1.5, 3.14 这样的小数。
- **字符串（str）**：像 "Hello, World!" 这样的文字。
- **布尔值（bool）**：只有 True 和 False 两种值。

## 🧪 示例代码（可运行）

### 示例 1：安装 Python 并运行第一个程序

```python
# 这是第一个 Python 程序，输出“Hello, World!”
print("Hello, World!")
```

> ✅ **运行方式**：
> 1. 打开命令行（Windows：`Win + R` → 输入 `cmd`；Mac：`Terminal`）。
> 2. 输入 `python`，如果看到 Python 提示符（如 `>>>`），说明安装成功。
> 3. 输入上面的代码并按回车，你会看到输出 `Hello, World!`。

---

### 示例 2：变量与数据类型

```python
# 定义变量并赋值
name = "Alice"      # 字符串
age = 25            # 整数
is_student = True   # 布尔值
height = 1.68       # 浮点数

# 输出变量
print("姓名:", name)
print("年龄:", age)
print("是否是学生:", is_student)
print("身高:", height)
```

> ✅ **运行结果**：
```
姓名: Alice
年龄: 25
是否是学生: True
身高: 1.68
```

---

### 示例 3：使用列表和字典

```python
# 使用列表存储多个数据
fruits = ["apple", "banana", "cherry"]
print("水果列表:", fruits)

# 使用字典存储键值对
student = {
    "name": "Bob",
    "age": 20,
    "is_enrolled": True
}
print("学生信息:", student)
```

> ✅ **运行结果**：
```
水果列表: ['apple', 'banana', 'cherry']
学生信息: {'name': 'Bob', 'age': 20, 'is_enrolled': True}
```

## 📋 常用函数/调用速查表

| 函数 | 签名 | 用途 | 最小示例 |
|------|------|------|----------|
| `print()` | `print("内容")` | 输出内容到控制台 | `print("Hello!")` |
| `input()` | `input("提示信息")` | 从用户获取输入 | `name = input("请输入你的名字：")` |
| `type()` | `type(变量)` | 查看变量类型 | `print(type(25))` |
| `len()` | `len(序列)` | 获取序列长度 | `print(len("Hello"))` |
| `str()` | `str(值)` | 将值转换为字符串 | `print(str(123))` |

## ⚠️ 新手易错点

| 错误写法 | 正确写法 | 说明 |
|----------|----------|------|
| `print "Hello"` | `print("Hello")` | Python 3 中 `print` 是函数，必须用括号 |
| `x = 10`<br>`x = "hello"` | `x = 10`<br>`x = "hello"` | Python 是动态类型语言，但频繁更改类型会影响代码可读性 |
| `print(Hello)` | `print("Hello")` | 变量名不能是关键字，且字符串必须用引号 |
| `print(1 + 2)` | `print(1 + 2)` | 语法正确，但注意运算符优先级 |
| `x = input("请输入：")` | `x = input("请输入：")` | `input()` 返回的是字符串，需转换为其他类型 |
