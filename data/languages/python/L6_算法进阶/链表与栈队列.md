# L6 算法进阶：链表与栈队列

## 1. 本课目标

- 能亲手用 `Node` 搭出单链表，并安全完成遍历、尾插、按值删除。
- 能说清“栈是后进先出、队列是先进先出”，会用 `list` 写栈、用 `deque` 写队列。
- 能避开空链表、空栈、错误连接 `next`、队列 API 误用等常见坑。

---

## 2. 概念讲解

### 2.1 单链表：像“寻宝线索”一样串起来

数组像一排连续座位，知道下标就能 `arr[2]` 直接跳过去。  
链表不一样：它像一张张“藏宝图”，每张图只告诉你：

1. 当前值是什么；
2. 下一张图在哪里。

单链表里的每一张“图”就是一个节点 `Node`：

- `node.val`：存当前值；
- `node.next`：存“下一个节点”的引用，不是下一个值；
- 最后一个节点的 `next` 是 `None`，表示结束。

假设链表是：

`head -> [1] -> [2] -> [3] -> None`

- `head` 是头节点，也就是入口；
- 想找 `3`，必须从 `head` 开始，一步一步走 `cur = cur.next`；
- 所以链表“按位置查找”是 `O(n)`；
- 如果要在头部插入，只需改一两个 `next`，是 `O(1)`；
- 如果要在尾部追加，若没有保存尾指针，通常要走一遍，是 `O(n)`。

**哑节点 `dummy` 是什么？**  
它像一个“假头节点”，固定站在真正头节点前面。  
删除头节点、处理空链表、尾插时，用 `dummy` 可以少写很多“如果它是头节点怎么办”的判断。

遍历链表最重要的安全带是：

> 先判断 `cur is not None`，再访问 `cur.val` 或 `cur.next`。

### 2.2 栈：一摞盘子，后进先出

栈 `Stack` 像一摞盘子：

- 放盘子叫 `push`，我们一般用 `list.append(x)`；
- 拿盘子叫 `pop`，我们一般用 `list.pop()`；
- 最后放上去的盘子，最先被拿走，这叫 **LIFO**，Last In First Out。

Python 里用列表当栈：

- 入栈：`stack.append(x)`
- 出栈：`stack.pop()`
- 看栈顶但不删除：`stack[-1]`
- 判断空：`if not stack:`

常见用途：括号匹配、撤销操作、函数调用栈、深度优先搜索 DFS。

### 2.3 队列：排队买奶茶，先进先出

队列 `Queue` 像排队：

- 从队尾进入叫入队，`enqueue`；
- 从队首离开叫出队，`dequeue`；
- 先来的人先被服务，这叫 **FIFO**，First In First Out。

Python 里推荐用 `collections.deque`：

- 入队：`q.append(x)`
- 出队：`q.popleft()`
- 看队首但不删除：`q[0]`，要保证非空
- 判断空：`if not q:`

为什么不直接用 `list.pop(0)` 当队列？  
因为 `list.pop(0)` 删除第一个元素后，后面的元素都要往前挪，复杂度是 `O(n)`。  
`deque.popleft()` 从左边弹出，常见情况下是 `O(1)`，更适合队列。

常见用途：任务调度、客服排队、广度优先搜索 BFS。

## 3. 由浅入深：3 个完整示例

### 示例 1：单链表创建、遍历、尾插

```python
class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next


def build_from_list(values):
    # 用“哑节点”让尾插更简单：dummy.next 就是真正头节点
    dummy = Node(0)
    tail = dummy
    for value in values:
        tail.next = Node(value)
        tail = tail.next
    return dummy.next


def append(head, value):
    new_node = Node(value)
    if head is None:
        return new_node

    cur = head
    while cur.next is not None:
        cur = cur.next
    cur.next = new_node
    return head


def to_list(head):
    result = []
    cur = head
    while cur is not None:
        result.append(cur.val)
        cur = cur.next
    return result


head = build_from_list([10, 20, 30])
print("初始链表：", to_list(head))

head = append(head, 40)
print("尾插 40 后：", to_list(head))

print("头两个节点：", head.val, head.next.val)

# 预期输出：
# 初始链表： [10, 20, 30]
# 尾插 40 后： [10, 20, 30, 40]
# 头两个节点： 10 20
```

### 示例 2：用栈判断括号是否匹配

```python
def is_valid(text):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []

    for ch in text:
        if ch in "([{":
            stack.append(ch)           # 左括号入栈
        elif ch in ")]}":
            if not stack:              # 右括号来了，但栈空：一定不匹配
                return False
            top = stack.pop()          # 弹出最近的左括号
            if top != pairs[ch]:
                return False
        # 其他字符（空格、字母等）本示例直接忽略

    return not stack                    # 最后栈空才完全匹配


for s in ["([]{})", "([)]", "(( ))", "())"]:
    print(f"{s!r} -> {is_valid(s)}")

# 预期输出：
# '([]{})' -> True
# '([)]' -> False
# '(( ))' -> True
# '())' -> False
```

### 示例 3：用队列模拟排队叫号

```python
from collections import deque


def serve_customers(customers, served_count):
    q = deque(customers)
    served = []
    for _ in range(served_count):
        if not q:
            break
        served.append(q.popleft())     # 队首出队
    return served, list(q)


queue = deque(["小明", "小红", "小刚"])
print("开始排队：", list(queue))

first = queue.popleft()
print("第一位被服务：", first)
print("当前队首：", queue[0])

queue.append("小美")                    # 新顾客从队尾进入
print("小美加入后：", list(queue))

served, remaining = serve_customers(["A", "B", "C", "D"], 3)
print("服务了：", served)
print("还剩：", remaining)

# 预期输出：
# 开始排队： ['小明', '小红', '小刚']
# 第一位被服务： 小明
# 当前队首： 小红
# 小美加入后： ['小红', '小刚', '小美']
# 服务了： ['A', 'B', 'C']
# 还剩： ['D']
```

## 5. 五个新手易错点

### 易错点1：空链表直接访问 `cur.next` 或 `cur.val`

❌ **错误写法**

```python
class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next


def print_list(head):
    cur = head
    while cur.next is not None:  # 空链表时 cur 是 None，这里马上出错
        print(cur.val)
        cur = cur.next
    print(cur.val)


print_list(None)

# 运行报错：AttributeError: 'NoneType' object has no attribute 'next'
```

✅ **正确写法**

```python
class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next


def print_list(head):
    cur = head
    while cur is not None:
        print(cur.val)
        cur = cur.next


print("空链表开始")
print_list(None)
print("有值链表开始")
print_list(Node(1, Node(2)))

# 预期输出：
# 空链表开始
# 有值链表开始
# 1
# 2
```

**纠正要点**：`head` 完全可能是 `None`，遍历前必须先判断 `cur is not None`，不能直接写 `cur.next` 或 `cur.val`。

---

### 易错点2：把“值”塞进 `next`，而不是塞“节点”

❌ **错误写法**

```python
class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next


head = Node(1)
head.next = 2  # 错误：next 里放的是数字，不是节点

cur = head
while cur is not None:
    print(cur.val)
    cur = cur.next

# 运行时会先打印 1，然后报错：
# 运行报错：AttributeError: 'int' object has no attribute 'val'
```

✅ **正确写法**

```python
class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next


head = Node(1)
head.next = Node(2)  # 正确：next 指向“节点”
head.next.next = Node(3)

cur = head
while cur is not None:
    print(cur.val)
    cur = cur.next

# 预期输出：
# 1
# 2
# 3
```

**纠正要点**：`next` 保存的是下一个 `Node` 对象的引用；如果放进整数，后面再访问 `cur.val` 就会报错。

### 易错点3：删除头节点时直接把 `prev.next = ...`

❌ **错误写法**

```python
class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next


def delete_first(head, target):
    cur = head
    prev = None

    while cur is not None and cur.val != target:
        prev = cur
        cur = cur.next

    if cur is None:
        return head

    prev.next = cur.next   # 当 target 在头节点时，prev 还是 None
    return head


head = Node(1, Node(2, Node(3)))
head = delete_first(head, 1)
print(head.val)

# 运行报错：AttributeError: 'NoneType' object has no attribute 'next'
```

✅ **正确写法**

```python
class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next


def delete_first(head, target):
    dummy = Node(0, head)   # 哑节点：让删除头节点和删除中间节点统一
    prev = dummy
    cur = head

    while cur is not None:
        if cur.val == target:
            prev.next = cur.next
            break
        prev = cur
        cur = cur.next

    return dummy.next


def print_list(head):
    values = []
    cur = head
    while cur is not None:
        values.append(cur.val)
        cur = cur.next
    print(values)


head = Node(1, Node(2, Node(3)))
head = delete_first(head, 1)
print_list(head)

# 预期输出：
# [2, 3]
```

**纠正要点**：删除头节点时 `prev` 可能是 `None`；用 `dummy` 虚拟头节点，或者单独判断 `prev is None`，可以统一处理。

### 易错点4：空栈还继续 `pop`

❌ **错误写法**

```python
stack = []
stack.append("任务A")
print(stack.pop())          # 正常取出 任务A
print(stack.pop())          # 栈已经空了，再弹出就出错

# 运行输出：
# 任务A
# 运行报错：IndexError: pop from empty list
```

✅ **正确写法**

```python
stack = []
stack.append("任务A")

if stack:
    print(stack.pop())
else:
    print("空栈，不能 pop")

if stack:
    print(stack.pop())
else:
    print("空栈，不能继续 pop")

# 预期输出：
# 任务A
# 空栈，不能继续 pop
```

**纠正要点**：`pop()` 前要检查容器是否为空，常用 `if stack:` 或 `if not stack: ...`，避免空栈弹出触发 `IndexError`。

---

### 易错点5：队列出队时错用 `deque.pop(0)`

❌ **错误写法**

```python
from collections import deque

q = deque([101, 102, 103])
first = q.pop(0)  # 错误：deque 的 pop 不接收下标参数
print(first)

# 运行报错：TypeError: pop() takes no arguments (1 given)
# 不同 Python 小版本的错误措辞可能略有差异
```

✅ **正确写法**

```python
from collections import deque

q = deque([101, 102, 103])
print(q.popleft())
print(q.popleft())
print(list(q))

# 预期输出：
# 101
# 102
# [103]
```

**纠正要点**：队列是先进先出，`deque` 从队首出队要用 `popleft()`；`deque.pop()` 是从右端弹出且不接受下标。

## 7. 本课小结

- 链表的核心是 `Node`：`val` 存值，`next` 指向下一个节点；遍历时永远先判断 `cur is not None`。
- 修改头节点容易出错，`dummy` 哑节点可以让“删头节点”和“删中间节点”统一处理。
- 栈是后进先出，用 `list.append()` 入栈、`list.pop()` 出栈；`pop` 前要检查空栈。
- 队列是先进先出，用 `deque.append()` 入队、`deque.popleft()` 出队；不要用 `deque.pop(0)`。
- 链表查找通常是 `O(n)`，头插/头删是 `O(1)`；栈和队列的常用操作通常按 `O(1)` 理解。

> 下一课建议：学习“树与二叉树遍历”，你会看到栈天然适合做深度优先 DFS，而队列天然适合做广度优先 BFS。
