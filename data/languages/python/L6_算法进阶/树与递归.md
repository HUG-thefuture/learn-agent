## 2. 概念讲解

### 2.1 二叉树长什么样？

二叉树由一个个“节点”组成。每个节点至少有：

- `val`：存的值；
- `left`：左孩子，没有就是 `None`；
- `right`：右孩子，没有就是 `None`。

例如：

```text
        1
       / \
      2   3
     / \
    4   5
```

节点 `1` 是根节点；`2` 是 `1` 的左孩子；`3` 是 `1` 的右孩子；`4`、`5`、`3` 都叫叶子节点，因为它们的左右孩子都是空。

空树不需要特殊对象，用 `None` 表示即可。

### 2.2 为什么树和递归是天生一对？

因为一棵二叉树可以看成：

> 根节点 + 左子树 + 右子树

而“左子树”本身还是一棵二叉树，“右子树”本身也还是一棵二叉树。  
所以我们可以对整棵树写一个函数，然后让这个函数自己再去处理左子树和右子树。

打个比方：老师问班长“全班多少人？”  
班长不需要自己一个个数，可以问左组长和右组长：  
“你那边多少人？”  
左组长、右组长又可以用同样办法问更小的组。最后把人数汇总即可。

这就是递归：**把大树拆成小树，小树再用同样方法继续拆，直到遇到空树或叶子。**

### 2.3 树递归三要素

写树递归时，先想清楚三件事：

1. **终止条件**：当前节点是 `None` 时怎么办？
   - 数节点：返回 `0`
   - 求深度：返回 `0`
   - 收集路径：直接返回
   - 判断是否存在：返回 `False`

2. **拆成子问题**：左子树调用一次，右子树调用一次。
   - `left_answer = solve(node.left)`
   - `right_answer = solve(node.right)`

3. **合并答案 / 返回值**：当前节点和左右答案怎么合？
   - 节点总数：`1 + 左数量 + 右数量`
   - 最大深度：`1 + max(左深度, 右深度)`
   - 是否存在路径：`左边存在 or 右边存在`
   - 收集路径：先把当前值放进路径，再递归，最后“回退”。

### 2.4 三种深度优先遍历

只改“处理当前节点”的位置，就能得到三种顺序：

- **前序**：根 → 左 → 右
- **中序**：左 → 根 → 右
- **后序**：左 → 右 → 根

对二叉搜索树来说，中序遍历会得到从小到大的有序结果，这个规律以后会经常用。

### 2.5 两种很常见的递归题型

1. **返回答案型**：函数把子树的答案返回给父节点。  
   例如：节点总数、最大深度、路径和是否存在。

2. **收集答案型**：外面准备一个 `result` 列表，递归函数负责往里放答案。  
   例如：收集所有根到叶子的路径。这时要特别小心：保存路径时要复制一份，不能一直保存同一个列表对象。

### 2.6 复杂度直觉

- 每个节点通常只访问一次：时间复杂度 `O(n)`。
- 递归会占用调用栈，栈的深度取决于树高 `h`：空间复杂度 `O(h)`。
- 如果树接近平衡，`h` 约等于 `log n`；如果树退化成一条链，`h = n`。

## 3. 三个由浅入深的完整示例

### 示例 1：递归数一数二叉树有多少个节点

思路：空树有 `0` 个节点；否则就是“当前这 1 个 + 左子树节点数 + 右子树节点数”。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def count_nodes(node):
    # 终止条件：空树没有节点
    if node is None:
        return 0

    # 当前节点算 1 个，再加上左右子树的节点数
    return 1 + count_nodes(node.left) + count_nodes(node.right)


#        1
#       / \
#      2   3
#     / \
#    4   5
root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.left = TreeNode(4)
root.left.right = TreeNode(5)

print(count_nodes(root))  # 预期输出：5
```

### 示例 2：递归实现前序、中序、后序遍历

同一个树结构，只改变 `ans.append(cur.val)` 的位置，就能得到不同顺序。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def preorder(node):
    ans = []

    def dfs(cur):
        if cur is None:
            return
        ans.append(cur.val)   # 根
        dfs(cur.left)         # 左
        dfs(cur.right)        # 右

    dfs(node)
    return ans


def inorder(node):
    ans = []

    def dfs(cur):
        if cur is None:
            return
        dfs(cur.left)         # 左
        ans.append(cur.val)   # 根
        dfs(cur.right)        # 右

    dfs(node)
    return ans


def postorder(node):
    ans = []

    def dfs(cur):
        if cur is None:
            return
        dfs(cur.left)         # 左
        dfs(cur.right)        # 右
        ans.append(cur.val)   # 根

    dfs(node)
    return ans


#        4
#       / \
#      2   6
#     / \ / \
#    1  3 5  7
root = TreeNode(4)
root.left = TreeNode(2)
root.right = TreeNode(6)
root.left.left = TreeNode(1)
root.left.right = TreeNode(3)
root.right.left = TreeNode(5)
root.right.right = TreeNode(7)

print("前序:", preorder(root))
print("中序:", inorder(root))
print("后序:", postorder(root))

# 预期输出：
# 前序: [4, 2, 1, 3, 6, 5, 7]
# 中序: [1, 2, 3, 4, 5, 6, 7]
# 后序: [1, 3, 2, 5, 7, 6, 4]
```

### 示例 3：判断是否存在一条“根到叶子”的路径，使路径和等于目标值

这题的关键：往下走时，把目标值减去当前节点值，看看到叶子时是不是刚好减成 `0`。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def has_path_sum(node, target):
    if node is None:
        return False

    # 走过当前节点后，还剩多少目标值
    target = target - node.val

    # 必须是叶子节点才能结算路径
    if node.left is None and node.right is None:
        return target == 0

    # 左右任意一边找到即可
    return has_path_sum(node.left, target) or has_path_sum(node.right, target)


#        5
#       / \
#      4   8
#     /   / \
#    11  13  4
#   /  \      \
#  7    2      1
root = TreeNode(5)
root.left = TreeNode(4)
root.right = TreeNode(8)
root.left.left = TreeNode(11)
root.left.left.left = TreeNode(7)
root.left.left.right = TreeNode(2)
root.right.left = TreeNode(13)
root.right.right = TreeNode(4)
root.right.right.right = TreeNode(1)

print(has_path_sum(root, 22))   # 5 + 4 + 11 + 2 = 22
print(has_path_sum(root, 100))

# 预期输出：
# True
# False
```

## 4. 常用函数 / 调用速查表

| 函数或写法 | 签名 / 形式 | 用途 | 最小示例 |
|---|---|---|---|
| `TreeNode` | `TreeNode(val=0, left=None, right=None)` | 创建二叉树节点 | `root = TreeNode(1)` |
| 空节点判断 | `if node is None:` | 最常用的递归终止条件 | `if root is None: return 0` |
| 左孩子 | `node.left` | 进入左子树 | `left = depth(root.left)` |
| 右孩子 | `node.right` | 进入右子树 | `right = depth(root.right)` |
| 叶子判断 | `node.left is None and node.right is None` | 判断是否没有孩子 | `if node.left is None and node.right is None:` |
| 最大值 | `max(a, b)` | 合并左右子树答案 | `return 1 + max(left, right)` |
| 路径快照 | `path.copy()` | 保存当前路径副本 | `result.append(path.copy())` |
| 层序遍历 | `from collections import deque` | 用队列做 BFS | `q = deque([root])` |

## 5. 五个新手易错点

### 易错点1：没有先判断 `None`，就直接访问 `.left`

❌ **错误写法**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def depth(node):
    # 错误：没有先处理 node is None
    left_depth = depth(node.left)
    right_depth = depth(node.right)
    return 1 + max(left_depth, right_depth)


root = TreeNode(1)
print(depth(root.left))  # root.left 是 None

# 运行报错：AttributeError: 'NoneType' object has no attribute 'left'
```

✅ **正确写法**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def depth(node):
    if node is None:
        return 0
    return 1 + max(depth(node.left), depth(node.right))


root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.left = TreeNode(4)

print(depth(root))  # 预期输出：3
```

**纠正要点：** 空树 `None` 没有 `.left`、`.right`、`.val`，递归函数第一件事通常先写 `if node is None:`。

### 易错点3：嵌套函数修改外层变量，却忘记 `nonlocal`

❌ **错误写法**


✅ **正确写法**

```python
class TreeNode:

        self.left = left
        self.right = right


def count_nodes(root):
```

### 易错点4：收集路径时直接保存 `path`，没有复制快照

❌ **错误写法**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def all_paths(root):
    result = []
    path = []

    def dfs(node):
        if node is None:
            return

        path.append(node.val)

        if node.left is None and node.right is None:
            result.append(path)  # 错误：保存的是同一个 path 对象的引用
        else:
            dfs(node.left)
            dfs(node.right)

        path.pop()

    dfs(root)
    return result


root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)

got = all_paths(root)
print(got)
assert got == [[1, 2], [1, 3]], "路径结果不对"

# 运行输出：[[], []]
# 运行报错：AssertionError: 路径结果不对
```

✅ **正确写法**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def all_paths(root):
    result = []
    path = []

    def dfs(node):
        if node is None:
            return

        path.append(node.val)

        if node.left is None and node.right is None:
            result.append(path.copy())  # 保存当前路径的快照
        else:
            dfs(node.left)
            dfs(node.right)

        path.pop()  # 回溯：离开当前节点前撤销它

    dfs(root)
    return result


root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)

print(all_paths(root))  # 预期输出：[[1, 2], [1, 3]]
```

**纠正要点：** `path` 是可变列表，后面还会被 `append/pop` 修改；要保存当时的样子，必须用 `path.copy()` 复制一份。

### 易错点5：求最大深度时，把左右深度相加，而不是取 `max`

❌ **错误写法**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def max_depth(node):
    if node is None:
        return 0
    # 错误：最大深度不是左右深度相加
    return 1 + max_depth(node.left) + max_depth(node.right)


root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)

got = max_depth(root)
print(got)
assert got == 2, "最大深度应为2"

# 运行输出：3
# 运行报错：AssertionError: 最大深度应为2
```

✅ **正确写法**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def max_depth(node):
    if node is None:
        return 0
    return 1 + max(max_depth(node.left), max_depth(node.right))


root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)

print(max_depth(root))  # 预期输出：2
```

**纠正要点：** 求深度是“选择更深的那一边”，用 `max`；求和、数节点才可能把左右结果相加。

### 练习3：收集所有“根到叶子”的路径

- **目标**：掌握“进入节点前加入路径，离开节点前撤销路径”，并学会用 `path.copy()` 保存快照。
- **引导步骤**：
  1. 进入 `dfs(node)` 后，把当前节点值加入 `path`。
  2. 如果当前节点是叶子，就把 `path.copy()` 加入 `result`。
  3. 如果不是叶子，递归左孩子和右孩子。
  4. 离开当前节点前执行 `path.pop()`，撤销当前节点。
- **起步代码**：

```python
class TreeNode:
```

```python
def all_paths(root):
    result = []
    path = []

    def dfs(node):
        if node is None:
            return

        path.append(node.val)

        if node.left is None and node.right is None:
            result.append(path.copy())
        else:
            dfs(node.left)
            dfs(node.right)

        path.pop()

    dfs(root)
    return result
```

## 7. 本课小结

- 一棵二叉树 = 根节点 + 左子树 + 右子树；子树仍然是一棵树，所以特别适合递归。
- 树递归先想三件事：空节点返回什么、左右子树怎么递归、当前答案怎么合并。
- 前序、中序、后序的区别，本质是“处理当前节点”的代码放在递归左右孩子的哪个位置。
- 返回答案型递归要认真写 `return`；收集答案型递归要注意 `path.copy()` 和回溯 `pop()`。
