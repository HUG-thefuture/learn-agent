# L6 算法进阶：数组哈希与双指针

## 1. 本课目标

- 会用 `set` / `dict` 记录“见过的值、下标、次数”，把很多嵌套查找优化到平均 O(n)。
- 会写两类“两数之和”：无序数组返回原下标用哈希表；有序数组用相向双指针。
- 会用同向双指针在原数组上完成“移动零 / 删除元素”，并说清为什么每个指针只移动一次，总复杂度是 O(n)。

## 2. 概念讲解

### 2.1 数组哈希：给数组配一本“登记簿”

“数组哈希”不是把数组本身变成哈希，而是：**一边遍历数组，一边用 `set` 或 `dict` 记录已经见过的信息**。

你可以把它想成进教室签到：

- `set`：只关心“这个人来过没有”。
- `dict`：还能记“这个人的座位号”或“这个人来了几次”。

常见用途：

- **是否出现过**：重复元素检测，用 `set`。
- **值对应下标**：两数之和，用 `dict[值] = 下标`。
- **出现次数**：统计频率，用 `dict[值] = 次数`。

为什么快？因为哈希表查询“有没有某个 key”平均是 O(1)。如果对每个数都再扫一遍数组找答案，会接近 O(n²)；用哈希表只扫一遍，通常就是 O(n)，代价是多用 O(n) 空间。

做两数之和时有一个关键顺序：

> **先查“补数以前有没有出现”，再把当前数登记进去。**

这样哈希表里只有“当前元素之前”的数，不会把当前元素自己拿来用两次。

### 2.2 双指针：让两个下标有规则地移动

双指针就是用两个下标 `left`、`right` 或 `slow`、`fast` 表示当前位置。它不是魔法，关键是：**根据题目单调性，确定该移动哪一个指针**。

本课重点看两种：

1. **相向双指针**：`left` 从左往右，`right` 从右往左。
   - 适合有序数组的两数之和、回文判断、夹逼查找。
   - 有序数组中，若 `nums[left] + nums[right] < target`，说明左边的数太小，应该 `left += 1`；若和太大，说明右边太大，应该 `right -= 1`。
   - 常写 `while left < right`，保证两个下标指向不同元素。

2. **同向双指针**：`fast` 负责读，`slow` 负责写。
   - 适合原地移动零、删除重复项、删除指定元素。
   - `fast` 扫过整个数组，遇到要保留的元素就写到 `slow` 的位置，然后 `slow += 1`。
   - 这样可以避免在列表中反复 `pop` 或插入导致元素整体移动。

选择策略：

- 需要**原始下标**，数组又没排序：优先哈希表。
- 数组已经有序，或只关心“值是否存在”：优先双指针，额外空间 O(1)。
- 如果先排序再双指针，原下标会被打乱；除非你额外保存 `(值, 原下标)`。

## 3. 由浅入深的完整示例

### 示例 1：用集合判断数组中是否有重复元素

思路：用一个 `seen` 集合当登记簿。遇到一个数，先问“以前见过吗”；见过就返回 `True`，没见过就登记。

```python
def has_duplicate(nums):
    """如果数组中有重复元素，返回 True；否则返回 False。"""
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False


print(has_duplicate([1, 2, 3, 2]))
print(has_duplicate([1, 2, 3, 4]))
print(has_duplicate([]))

# 预期输出：
# True
# False
# False
```

时间复杂度 O(n)，空间复杂度 O(n)。这是最基础的“用哈希记住见过什么”。

### 示例 2：哈希表一次遍历——两数之和（返回原下标）

思路：遍历到 `x` 时，希望找到之前的 `target - x`。字典里存“值 -> 下标”。先检查补数，再把当前数存进去。

```python
def two_sum_indices(nums, target):
    """返回和为 target 的两个不同元素的下标；若不存在返回 None。"""
    value_to_index = {}
    for i, x in enumerate(nums):
        complement = target - x
        if complement in value_to_index:
            return [value_to_index[complement], i]
        value_to_index[x] = i
    return None


print(two_sum_indices([2, 7, 11, 15], 9))
print(two_sum_indices([3, 2, 4], 6))
print(two_sum_indices([1, 2], 7))

# 预期输出：
# [0, 1]
# [1, 2]
# None
```

注意顺序：如果先把 `x` 存进字典，再查补数，就可能把同一个下标用两次。时间复杂度 O(n)，空间复杂度 O(n)。

### 示例 3：有序数组的相向双指针——两数之和

思路：输入已经升序排序。`left` 指向最小端，`right` 指向最大端。当前和太小，就让 `left` 右移找更大的数；当前和太大，就让 `right` 左移找更小的数。

```python
def two_sum_sorted_indices(nums, target):
    """nums 必须已经升序排序；返回两个下标的列表，找不到返回 None。"""
    left = 0
    right = len(nums) - 1

    while left < right:  # 不用 <=，避免同一个元素被使用两次
        total = nums[left] + nums[right]
        if total == target:
            return [left, right]
        if total < target:
            left += 1       # 和太小，左指针向右，数会变大
        else:
            right -= 1      # 和太大，右指针向左，数会变小

    return None


print(two_sum_sorted_indices([1, 2, 4, 7, 11], 9))
print(two_sum_sorted_indices([1, 2, 3, 4], 7))
print(two_sum_sorted_indices([1, 2], 5))

# 预期输出：
# [1, 3]
# [2, 3]
# None
```

每个指针最多移动 n 次，总时间复杂度 O(n)；只用了几个变量，额外空间 O(1)。如果数组未排序且需要原下标，不要直接 `sort`，应回到示例 2 的哈希表写法。

## 4. 常用函数 / 调用速查表

| 函数 | 签名 | 用途 | 最小示例 |
|---|---|---|---|
| `len` | `len(seq)` | 取长度；双指针右边界常写 `len(seq) - 1` | `len([10, 20])` 得到 `2` |
| `enumerate` | `enumerate(iterable, start=0)` | 同时拿下标和值 | `list(enumerate(["a", "b"]))` 得到 `[(0, "a"), (1, "b")]` |
| `in` | `x in container` | 判断元素是否在列表、集合或字典 key 中 | `3 in {1, 3}` 得到 `True` |
| `set` | `set(iterable)` | 创建集合，自动去重、快速判断存在 | `set([1, 2, 2])` 得到 `{1, 2}` |
| `set.add` | `seen.add(x)` | 把一个元素加入集合 | `s = set()`；`s.add(5)` 后 `5 in s` 为 `True` |
| `dict.get` | `d.get(key, default=None)` | 安全取字典值，没有 key 时返回默认值 | `{"a": 1}.get("b", 0)` 得到 `0` |
| `dict[key] = value` | `d[k] = v` | 写入 / 更新字典 key | `d = {}`；`d[7] = 2` 后 `d[7]` 为 `2` |
| `tuple` | `tuple(iterable)` | 转成不可变元组，适合作为字典 key | `tuple([1, 2])` 得到 `(1, 2)` |
| `sorted` | `sorted(iterable)` | 返回排序后的新列表，不改原列表 | `sorted([3, 1, 2])` 得到 `[1, 2, 3]` |
| `range` | `range(stop)` | 生成遍历下标 | `list(range(3))` 得到 `[0, 1, 2]` |

> 记忆：查“在不在”用 `in`；计数用 `dict.get(x, 0) + 1`；要原下标别用 `sorted` 打乱。

## 5. 新手易错点

下面错误代码会故意触发异常，点运行后看到报错是正常的；重点看为什么会错，以及正确写法如何规避。

### 易错点1：统计次数时忘记给字典初始化

❌ **错误写法**
```python
def count_numbers(nums):
    counts = {}
    for x in nums:
        counts[x] += 1  # 运行报错：KeyError: 1，第一次遇到 1 时字典里还没有这个 key
    return counts


print(count_numbers([1, 2, 1]))
# 运行报错：KeyError: 1
```

✅ **正确写法**
```python
def count_numbers(nums):
    counts = {}
    for x in nums:
        counts[x] = counts.get(x, 0) + 1
    return counts


print(count_numbers([1, 2, 1]))
# 预期输出：{1: 2, 2: 1}
```

纠错要点：`counts[x] += 1` 会先尝试读取 `counts[x]`，key 不存在就报 `KeyError`；计数常用 `counts.get(x, 0) + 1`。

### 易错点2：两数之和直接访问不存在的补数下标

❌ **错误写法**
```python
def two_sum_bad(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        complement = target - x
        # 错误：没有判断 complement 是否存在，直接把补数当 key 访问
        return [seen[complement], i]  # 运行报错：KeyError: 7
    return None


print(two_sum_bad([2, 7], 9))
# 运行报错：KeyError: 7
```

✅ **正确写法**
```python
def two_sum_good(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        complement = target - x
        if complement in seen:
            return [seen[complement], i]
        seen[x] = i
    return None


print(two_sum_good([2, 7], 9))
# 预期输出：[0, 1]
```

纠错要点：查字典前先 `in` 判断，或用 `get`；并且要“先查补数，再登记当前数”，避免同一个元素被使用两次。

### 易错点3：把列表当作字典的 key

❌ **错误写法**
```python
position = [1, 2]
memo = {}
memo[position] = "到达过"  # 运行报错：TypeError: unhashable type: 'list'
print(memo)
# 运行报错：TypeError: unhashable type: 'list'
```

✅ **正确写法**
```python
position = (1, 2)  # 元组不可变，可以作为字典 key
memo = {}
memo[position] = "到达过"
print(memo)
# 预期输出：{(1, 2): '到达过'}
```

纠错要点：字典的 key 必须可哈希，列表可变所以不行；坐标、路径等可以转成 `tuple` 再作为 key。

### 易错点4：双指针右边界写成 `len(nums)`

❌ **错误写法**
```python
def two_sum_sorted_bad(nums, target):
    left = 0
    right = len(nums)  # 错误：合法下标最大是 len(nums) - 1
    while left < right:
        total = nums[left] + nums[right]  # 运行报错：IndexError: list index out of range
        if total == target:
            return [left, right]
        elif total < target:
            left += 1
        else:
            right -= 1
    return None


print(two_sum_sorted_bad([1, 2, 3], 4))
# 运行报错：IndexError: list index out of range
```

✅ **正确写法**
```python
def two_sum_sorted_good(nums, target):
    left = 0
    right = len(nums) - 1
    while left < right:
        total = nums[left] + nums[right]
        if total == target:
            return [left, right]
        elif total < target:
            left += 1
        else:
            right -= 1
    return None


print(two_sum_sorted_good([1, 2, 3], 4))
# 预期输出：[0, 2]
```

纠错要点：长度为 n 的列表下标范围是 `0` 到 `n - 1`；右边界初始化为 `len(nums) - 1`，两数之和通常写 `while left < right`。

### 易错点5：遍历列表时 `pop`，下标会滑动

❌ **错误写法**
```python
nums = [0, 1, 0, 2]
for i in range(len(nums)):
    if nums[i] == 0:
        nums.pop(i)  # 删除元素会改变后面所有元素的下标
print(nums)
# 运行报错：IndexError: list index out of range（列表变短，i 仍继续增大）
```

✅ **正确写法**
```python
def remove_zeros(nums):
    slow = 0  # 下一个要保留元素写入的位置
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow] = nums[fast]
            slow += 1
    return nums[:slow]


nums = [0, 1, 0, 2]
print(remove_zeros(nums))
# 预期输出：[1, 2]
```

纠错要点：边遍历边 `pop` 会让后面的元素前移，容易跳过元素甚至下标越界；用同向双指针把要保留的元素写到前缀，最后切片或补零。

## 7. 本课小结

- 数组哈希的核心是“边遍历边登记”：`set` 记录是否见过，`dict` 记录下标或次数。
- 无序数组求两数之和并返回原下标，优先用哈希表，先查补数，再存当前数。
- 有序数组求两数之和，优先用相向双指针；和太小移 `left`，和太大移 `right`。
- 同向双指针适合原地处理数组：`fast` 读，`slow` 写，避免边遍历边删除。
- 双指针边界要牢记：长度为 n 的列表最后一个下标是 `n - 1`，两数之和常写 `while left < right`。

下一课建议：练习“三数之和（排序 + 固定一个数 + 双指针 + 去重）”，它会同时训练排序、双指针移动和去重边界。
