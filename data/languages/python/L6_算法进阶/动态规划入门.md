## 2. 概念讲解

### 2.1 为什么需要动态规划？

看爬楼梯：到第 5 阶的方法数，等于：

- 先到第 4 阶，再走 1 阶；
- 先到第 3 阶，再走 2 阶。

所以：

```text
到第5阶的方法数 = 到第4阶的方法数 + 到第3阶的方法数
```

如果直接递归，计算第 5 阶时算第 4、第 3；计算第 4 阶时又算第 3、第 2……很多子问题会被重复计算。

DP 的做法是：把“到第 i 阶有几种方法”存进数组 `dp[i]`。以后要用，直接查表。

### 2.2 DP 的五步口诀

以爬楼梯为例：

1. **定义状态**：`dp[i]` 表示“到达第 i 阶的方法数”。
2. **写转移方程**：最后一次可以走 1 阶或 2 阶，所以  
   `dp[i] = dp[i - 1] + dp[i - 2]`。
3. **初始化边界**：`dp[1] = 1`，`dp[2] = 2`。
4. **确定遍历顺序**：`i` 从小到大，因为 `dp[i]` 依赖更小的 `i`。
5. **空间优化**：`dp[i]` 只依赖前两个状态，所以可以用两个变量 `prev2, prev1` 滚动保存。

### 2.3 两种常见思路

- **自底向上递推**：从 `dp[1]`、`dp[2]` 开始，一路填到 `dp[n]`。本课主要用这种。
- **自顶向下记忆化搜索**：写递归，但把结果缓存起来。它本质也是 DP，常配合 `functools.lru_cache`。

### 2.4 复杂度怎么看？

DP 常见复杂度公式：

```text
时间复杂度 = 状态数 × 每个状态的转移代价
```

例如爬楼梯：

- 有 `n` 个状态；
- 每个状态只做一次加法，转移代价 O(1)；
- 所以时间 O(n)。

空间上：

- 开 `dp` 数组通常是 O(n)；
- 只保留前一项或前两项时，可以优化成 O(1)；
- 背包开一维数组 `dp[capacity + 1]` 时，空间是 O(capacity)。

下面开始用三个由浅入深的例子熟悉它。

## 3. 三个完整示例

### 示例 1：爬楼梯——理解状态和转移

题目：每次可以爬 1 阶或 2 阶，问到达第 `n` 阶共有多少种方法。这里约定 `n >= 1`。

```python
def climb_stairs(n):
    """
    dp[i] 表示到达第 i 阶的方法数。
    dp[i] = dp[i - 1] + dp[i - 2]
    因为最后一步要么走 1 阶，要么走 2 阶。
    """
    if n <= 2:
        return n  # n=1 ->1，n=2 ->2

    # prev2 表示 dp[i-2]，prev1 表示 dp[i-1]
    prev2, prev1 = 1, 2

    for i in range(3, n + 1):
        cur = prev1 + prev2
        # 同时更新两个滚动变量
        prev2, prev1 = prev1, cur

    return prev1


print(climb_stairs(6))

# 预期输出：
# 13
```

思路对应：

- `dp[1] = 1`
- `dp[2] = 2`
- `dp[3] = 3`
- `dp[4] = 5`
- `dp[5] = 8`
- `dp[6] = 13`

注意：这里只用了两个变量，所以空间复杂度从 O(n) 降到 O(1)。

### 示例 2：最大子数组和——状态要解释清楚“以谁结尾”

题目：给定一个非空整数数组，找到和最大的连续子数组，返回这个最大和。

例如：

```text
[-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

最大连续子数组是 `[4, -1, 2, 1]`，和为 `6`。

```python
def max_subarray(nums):
    """
    current 表示：以当前位置结尾的最大连续子数组和。
    best 表示：遍历到目前为止见过的最大答案。

    转移：
    current = max(x, current + x)
    意思是：要么从 x 重新开始，要么把 x 接到前面的子数组后面。
    """
    current = nums[0]
    best = nums[0]

    for x in nums[1:]:
        current = max(x, current + x)
        best = max(best, current)

    return best


nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
print(max_subarray(nums))

# 预期输出：
# 6
```

核心提醒：

- `current` 不是“全局最大”，而是“**必须以当前位置结尾**的最大和”。
- 真正的答案要单独用 `best` 记录历史最大值。
- 这里也只依赖前一个状态，所以空间可以做到 O(1)。

### 示例 3：0-1 背包——每件物品最多选一次

题目：有若干物品，每件物品有重量 `w` 和价值 `v`。背包容量为 `capacity`，每件物品最多选一次，求能装下的最大价值。

例如：

```text
weights = [2, 3, 4]
values  = [5, 9, 10]
capacity = 5
```

最优选择是重量 `2 + 3 = 5` 的两件物品，价值 `5 + 9 = 14`。

```python
def knapsack_01(weights, values, capacity):
    """
    dp[j] 表示：容量不超过 j 时，能获得的最大价值。
    对每件物品，只在容量 j 从大到小时更新。
    倒序是为了保证 j-w 使用的是“上一轮、没选当前物品”的状态，
    从而让每件物品最多被选一次。
    """
    dp = [0] * (capacity + 1)

    for w, v in zip(weights, values):
        # 如果容量 j 小于 w，当前物品放不进去，不需要尝试
        for j in range(capacity, w - 1, -1):
            dp[j] = max(
                dp[j],          # 不选当前物品
                dp[j - w] + v   # 选当前物品
            )

    return dp[capacity]


weights = [2, 3, 4]
values = [5, 9, 10]
capacity = 5
print(f"最大价值：{knapsack_01(weights, values, capacity)}")

# 预期输出：
# 最大价值：14
```

为什么是倒序？

- 更新到 `dp[j]` 时会用到 `dp[j - w]`。
- 倒序遍历时，`dp[j - w]` 还停留在“当前物品还没被考虑”的状态。
- 如果正序遍历，同一个物品可能被重复放入，就变成“完全背包”了。

## 4. 常用函数 / 调用速查表

| 函数或写法 | 签名 | 用途 | 最小示例 |
|---|---|---|---|
| `max` | `max(a, b)` | 在两个选择里取较大值 | `max(3, 7)  # 7` |
| `range` | `range(start, stop, step)` | 控制填表顺序；倒序常用 `-1` | `list(range(3, 0, -1))  # [3, 2, 1]` |
| 一维 DP 初始化 | `[0] * (n + 1)` | 创建 n+1 个状态，下标 0 到 n | `dp = [0] * 4  # [0, 0, 0, 0]` |
| 滚动变量 | `prev2, prev1 = prev1, cur` | 只保留前两个状态，空间 O(1) | `a, b = b, a + b` |
| 记忆化装饰器 | `@lru_cache(maxsize=None)` | 递归 + 缓存重复子问题 | `from functools import lru_cache` |
| 0-1 背包倒序 | `for j in range(capacity, w - 1, -1):` | 保证每件物品最多选一次 | `dp[j] = max(dp[j], dp[j - w] + v)` |
| 子数组答案模式 | `best = max(best, current)` | 记录历史最优值 | `best = max(best, current)` |

## 5. 五个新手易错点

### 易错点1：边界初始化不完整

❌ **错误写法**

```python
def climb_stairs_bug(n):
    dp = [0] * (n + 1)
    dp[1] = 1  # 当 n=0 时，dp 长度为 1，这里会越界
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]


print(climb_stairs_bug(0))

# 运行报错：
# IndexError: list assignment index out of range
```

✅ **正确写法**

```python
def climb_stairs_ok(n):
    if n <= 0:
        return 0
    if n == 1:
        return 1

    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]


print(climb_stairs_ok(1))  # 预期输出：1
print(climb_stairs_ok(6))  # 预期输出：13
```

为什么会错：先处理 `n=0`、`n=1`、`n=2` 等边界，再创建并访问 `dp[2]`；不要默认 `n` 一定大于等于 2。

### 易错点2：0-1 背包容量写成正序

❌ **错误写法**

```python
def knapsack_bug(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for w, v in zip(weights, values):
        for j in range(w, capacity + 1):  # 正序：同一个物品可能被反复使用
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[capacity]


answer = knapsack_bug([2, 3], [3, 4], 4)
print(answer)
assert answer == 4, "0-1 背包每件物品最多选一次，期望 4，不是 6"

# 运行报错：
# AssertionError: 0-1 背包每件物品最多选一次，期望 4，不是 6
```

✅ **正确写法**

```python
def knapsack_ok(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for w, v in zip(weights, values):
        for j in range(capacity, w - 1, -1):  # 倒序：保证当前物品只用一次
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[capacity]


print(knapsack_ok([2, 3], [3, 4], 4))  # 预期输出：4
```

为什么会错：0-1 背包中每件物品最多选一次，一维数组更新容量时必须倒序遍历，避免同一轮里把当前物品重复放进去。

### 易错点3：记忆化递归的状态参数不可哈希

❌ **错误写法**

```python
from functools import lru_cache


@lru_cache(maxsize=None)
def sum_from(start, nums):
    if start == len(nums):
        return 0
    return nums[start] + sum_from(start + 1, nums)


print(sum_from(0, [1, 2, 3]))

# 运行报错：
# TypeError: unhashable type: 'list'
```

✅ **正确写法**

```python
from functools import lru_cache


@lru_cache(maxsize=None)
def sum_from(start, nums):
    if start == len(nums):
        return 0
    return nums[start] + sum_from(start + 1, nums)


print(sum_from(0, (1, 2, 3)))  # 预期输出：6
```

为什么会错：`lru_cache` 会把参数当作缓存键，列表不可哈希；应把列表转成元组，或让状态只包含可哈希的下标等参数。

### 易错点4：最大子数组只返回“最后一个位置结尾”的值

❌ **错误写法**

```python
def max_subarray_bug(nums):
    current = nums[0]
    for x in nums[1:]:
        current = max(x, current + x)
    return current  # 只返回了以最后一个元素结尾的最大和


answer = max_subarray_bug([-2, 1, -3, 4, -1, 2, 1, -5, 4])
print(answer)
assert answer == 6, "最大子数组和需要记录历史最大值，不能只返回最后位置结尾的值"

# 运行报错：
# AssertionError: 最大子数组和需要记录历史最大值，不能只返回最后位置结尾的值
```

✅ **正确写法**

```python
def max_subarray_ok(nums):
    current = nums[0]
    best = nums[0]
    for x in nums[1:]:
        current = max(x, current + x)
        best = max(best, current)
    return best


print(max_subarray_ok([-2, 1, -3, 4, -1, 2, 1, -5, 4]))  # 预期输出：6
```

为什么会错：当 `dp[i]` 表示“以 i 结尾”的最大子数组和时，最终答案不是 `dp[-1]`，而是所有 `dp[i]` 中的最大值。

### 易错点5：滚动变量更新顺序写错

❌ **错误写法**

```python
def fibonacci_bug(n):
    a, b = 0, 1
    for _ in range(n):
        a = b
        b = a + b  # 此时 a 已经被改成新的 b，计算错误
    return a


answer = fibonacci_bug(6)
print(answer)
assert answer == 8, "滚动变量更新顺序错了，fib(6) 应该是 8"

# 运行报错：
# AssertionError: 滚动变量更新顺序错了，fib(6) 应该是 8
```

✅ **正确写法**

```python
def fibonacci_ok(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b  # 右侧先一起计算，再赋值给左侧
    return a


print(fibonacci_ok(6))  # 预期输出：8
```

为什么会错：多个滚动变量互相依赖时，要先保存旧值，或使用 Python 的同时赋值 `a, b = b, a + b`，不能先改掉后面还要用的变量。

## 7. 本课小结

1. **DP 的第一关键是定义清楚 `dp[i]` 的含义**：是“到达第 i 阶”，还是“以 i 结尾”，还是“前 i 个物品/容量为 j”，含义不同，转移和答案位置就不同。
2. **写转移时问自己：最后一步/当前元素有什么选择？**  
   爬楼梯是最后走 1 阶还是 2 阶；最大子数组是接上前面还是重新开始；背包是选当前物品还是不选。
3. **初始化边界和遍历顺序同样重要**：0-1 背包一维数组必须倒序遍历容量，否则会重复使用物品。
4. **只依赖前一个或前两个状态时，可以用滚动变量优化空间**；`dp[i - 1]`、`dp[i - 2]` 这类模式很常见。
5. **复杂度按“状态数 × 每个状态转移代价”估计**：爬楼梯 O(n)，最大子数组 O(n)，0-1 背包 O(物品数 × capacity)。

**下一课建议**：学习二维 DP 的代表题，例如“最长公共子序列”或“编辑距离”，重点练习画 DP 表格、写二维转移，再尝试压缩成一维数组。
