# L1 核心基础 · 函数与参数传递

> 学到现在，你已经能写出有判断、有循环、有数据容器的脚本了。但代码越写越长，你会发现：很多逻辑反复出现，调试时改一个错要改十几个地方。这节课学完，你就能把代码"打包"成可复用的小盒子——**函数**。

---

## 一、本课目标

学完本课，你将能够：

1. **定义和调用函数**，把一段可复用的逻辑封装成"一个名字 + 一对括号"，通过 `return` 拿到结果。
2. **灵活使用五种参数**（位置参数、关键字参数、默认参数、`*args`、`**kwargs`），让一个函数适应多种调用场景。
3. **理解 Python 的参数传递机制**——"不可变对象按值传，可变对象按引用传"，避免被函数"意外改坏"外部数据。

## 二、概念讲解

### 1. 为什么要函数？打个比方

想象你做菜：每次炒鸡蛋都要重复"打蛋 → 搅拌 → 热油 → 翻炒"这一整套流程。如果有人问你"今天午饭咋办？"，你不会念流水账，只会说一句——"做个炒鸡蛋"。

**函数 = 给一段代码起个名字**。需要用的时候喊一声名字，整段逻辑就跑起来。

好处有四点：
- **复用**：写一次，用无数次。
- **清晰**：给逻辑命名，主流程读起来像看说明书。
- **隔离**：函数内部的变量不会污染外面，调试更简单。
- **可维护**：改一处逻辑，所有调用都跟着更新。

### 2. 定义函数的语法

```python
def 函数名(参数1, 参数2, ...):   # def = define 定义
    """文档字符串（可选，解释这个函数干嘛的）"""
    函数体                        # 缩进 4 个空格
    return 结果                   # 可选：把结果送回调用处
```

- `def` 是关键字，告诉 Python："我要定义一个函数了"。
- 函数名遵守蛇形命名（小写 + 下划线），如 `calculate_bmi`。
- 参数（也叫**形参**）是占位符，相当于"菜谱上写的'鸡蛋'"；调用时传入的具体值叫**实参**，相当于"你实际拿出的那枚鸡蛋"。
- `return` 把结果送出去；如果不写，函数默认返回 `None`。

### 3. 五种参数，逐步升级

| 参数类型 | 长什么样 | 像什么 |
|---|---|---|
| 位置参数 | `def f(a, b)` | 排队取餐：按顺序对应 |
| 关键字参数（调用时） | `f(a=1, b=2)` | 点名取餐：叫到谁给谁 |
| 默认参数 | `def f(a, b=10)` | 不点就上默认菜 |
| `*args` | `def f(*args)` | 不限量的自助餐 |
| `**kwargs` | `def f(**kwargs)` | 写着名字的礼品袋 |

**为什么要有这么多形式？** 因为现实需求五花八门：有时候你不知道用户会传几个数（求任意个数最大值），有时候你想给常用情况一个省心默认值（单位默认用米），有时候你想让调用者用"名字"指定某些高级选项（是否开启调试模式）。

### 4. 参数传递机制（重点 + 难点）

Python 的参数传递用一句话概括：

> **传的是"对象的引用"，但不可变对象改不了，可变对象改得动。**

- **不可变对象**（`int`、`float`、`str`、`tuple`、`bool`）：函数内部重新赋值 = 在函数里"另起炉灶"，外面的变量不受影响。
- **可变对象**（`list`、`dict`、`set`）：函数内部 `.append()`、`.pop()` 这种操作 = 直接动原对象，外面看得见变化。

打个比方：不可变对象像一张**纸条**，你写了新内容等于换了一张纸条，原来的还在原地；可变对象像一个**白板**，你在原板上擦写，大家看到的就是改后的内容。

### 5. 关于 return 的"为什么"

很多新手分不清 `print` 和 `return`：
- `print` 是"把话说出来"——给**人**看，说完就完了，函数本身没拿到东西。
- `return` 是"把东西递出去"——给**程序**用，递出去之后才能继续参与后续计算。

没有 `return` 的函数就像"光说不练"——你叫它做事，它告诉你做了，但什么也没交出来。

## 三、三个由浅入深的完整示例

### 示例 1：定义与调用——问候机器人

最基础的函数：位置参数 + 返回值。

```python
# 1. 定义函数：接收一个名字，返回一句问候语
def greet(name):
    """根据名字生成问候语"""
    return f"你好，{name}！欢迎来学 Python。"

# 2. 调用函数，把结果存到变量
msg1 = greet("小明")
print(msg1)                     # 你好，小明！欢迎来学 Python。

# 3. 也可以直接打印函数返回值
print(greet("小红"))            # 你好，小红！欢迎来学 Python。

# 4. 函数内不修改外部变量：传进来的只是值的副本
who = "小刚"
result = greet(who)
who = "改了名字"               # 外部修改不影响函数已经返回的结果
print(result)                  # 仍是"你好，小刚！..."
```

**关键点**：函数像一个"黑盒"，你给它输入，它给你输出，外面变量和函数内部互不干扰。

### 示例 2：默认参数 + 关键字参数——咖啡机

```python
def make_coffee(coffee, sugar=2, milk=True):
    """
    制作一杯咖啡
    :param coffee: 咖啡种类（必填，无默认值）
    :param sugar:  糖块数（默认 2）
    :param milk:   是否加奶（默认 True）
    :return: 描述这杯咖啡的字符串
    """
    desc = f"一杯{coffee}"
    if milk:
        desc += "，加牛奶"
    else:
        desc += "，不加奶"
    desc += f"，糖{sugar}块"
    return desc

# 1. 只传必填项，其余用默认值
print(make_coffee("拿铁"))
# 一杯拿铁，加牛奶，糖2块

# 2. 用关键字参数只改其中一个，其余仍用默认值
print(make_coffee("美式", milk=False))
# 一杯美式，不加奶，糖2块

# 3. 全部用关键字参数（顺序可变）
print(make_coffee(sugar=0, coffee="浓缩", milk=False))
# 一杯浓缩，不加奶，糖0块

# 4. 错误示范：位置参数不能放在关键字参数后面
# print(make_coffee(coffee="卡布", 3))  # ❌ SyntaxError
print(make_coffee("卡布", 3, milk=True))  # ✅ 位置参数在前
```

**关键点**：默认参数让"常用情况"一行就能调用；关键字参数让"高级设置"按需调整。位置参数必须在关键字参数**之前**。

### 示例 3：可变参数 + 资源释放——成绩记录器

```python
def log_scores(name, *scores, **extra_info):
    """
    记录一名学生的成绩到文件，并返回平均分。
    :param name: 学生姓名（必填）
    :param scores: 任意数量的分数（*args 收集为元组）
    :param extra_info: 其他补充信息（**kwargs 收集为字典）
    """
    # 计算平均分：scores 此时是元组，如 (80, 90, 85)
    if not scores:
        avg = 0.0
    else:
        avg = sum(scores) / len(scores)

    # 把补充信息拼成字符串：班级=三年二班, 班主任=张老师
    extra_str = "，".join(f"{k}={v}" for k, v in extra_info.items())

    # 写入文件：用 with 语句确保文件句柄自动关闭，避免资源泄漏
    line = f"{name}: 平均分={avg:.2f}, {extra_str}\n"
    with open("scores_log.txt", "a", encoding="utf-8") as f:
        f.write(line)
    # 离开 with 块，文件自动关闭 ✅

    return avg

# 调用 1：只传名字和分数
avg1 = log_scores("小明", 80, 90, 85)
print(f"小明的平均分：{avg1:.2f}")

# 调用 2：附带班级和班主任信息
avg2 = log_scores("小红", 75, 88, 92, 95, 班级="三年二班", 班主任="张老师")
print(f"小红的平均分：{avg2:.2f}")

# 调用 3：先收集再展开
raw_scores = [60, 70, 65]
avg3 = log_scores("小刚", *raw_scores, 备注="需要补考")
print(f"小刚的平均分：{avg3:.2f}")
```

**关键点**：
- `*scores` 把所有位置参数打包成元组，`**extra_info` 把所有关键字参数打包成字典。
- `with open(...) as f:` 是处理文件的标准姿势——即使中间报错，文件也会被自动关闭，不会泄漏资源。
- 调用时也可以用 `*raw_scores` 把列表"展开"成位置参数（解包）。

## 四、常用函数/调用速查表

| 用法 | 签名 | 用途 | 最小示例 |
|---|---|---|---|
| 定义函数 | `def name(params):` | 创建一个可复用代码块 | `def hi(): print("hi")` |
| 返回值 | `return value` | 把结果送出函数 | `def add(a,b): return a+b` |
| 默认参数 | `def f(a, b=10):` | 不传则用默认值 | `def pow(x, n=2): return x**n` |
| 关键字调用 | `f(a=1, b=2)` | 按名字传，顺序随意 | `pow(n=3, x=2)` |
| 可变位置参数 | `def f(*args):` | 收集任意位置参数为元组 | `def max_(*n): return max(n)` |
| 可变关键字参数 | `def f(**kw):` | 收集任意关键字参数为字典 | `def info(**d): print(d)` |
| 解包列表调用 | `f(*lst)` | 把列表元素依次作为位置参数传入 | `add(*[1,2])` |
| 解包字典调用 | `f(**dct)` | 把字典键值作为关键字参数传入 | `info(**{"a":1})` |
| 匿名函数 | `lambda 参数: 表达式` | 一行小函数，无需 def | `sq = lambda x: x*x` |
| 函数注解（可选） | `def f(x: int) -> int:` | 类型提示，不影响运行 | `def f(x: int) -> int: return x*2` |

## 五、5 个新手易错点

### ❌ 易错 1：函数定义后忘记调用

```python
# 错误：定义了却不喊它，啥也不发生
def hello():
    print("Hello!")

# 正确：定义后要调用
def hello():
    print("Hello!")
hello()          # ✅ 加上这一行才有输出
```

### ❌ 易错 2：默认参数用了可变对象

```python
# 错误：默认列表在函数定义时只创建一次，后续调用共用同一个对象！
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2]  ❌ 不是预期的 [2]

# 正确：用 None 作哨兵，在函数内部再初始化
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [2]  ✅
```

### ❌ 易错 3：把 return 写成 print

```python
# 错误：函数没有 return，返回 None，无法参与后续计算
def add(a, b):
    print(a + b)
result = add(3, 5) * 2   # ❌ TypeError: NoneType 不能乘

# 正确：用 return 把结果送出去
def add(a, b):
    return a + b
result = add(3, 5) * 2   # ✅ 16
```

### ❌ 易错 4：位置参数放在关键字参数后面

```python
# 错误：位置参数 a=1 在前，但 2 是位置参数，顺序混乱
def f(a, b):
    return a + b
f(a=1, 2)              # ❌ SyntaxError

# 正确：位置参数先，关键字参数后
f(2, b=1)              # ✅
```

### ❌ 易错 5：函数内部偷偷改了外部可变对象

```python
# 错误（隐式副作用）：在函数内对列表做 .append()，会改到原列表
def add_zero(lst):
    lst.append(0)
    return lst

original = [1, 2]
result = add_zero(original)
print(original)   # [1, 2, 0]  ❌ 原列表被改了！

# 正确方式 1：返回新列表，不污染原数据
def add_zero_safe(lst):
    return lst + [0]       # 用 + 生成新列表

original = [1, 2]
result = add_zero_safe(original)
print(original)   # [1, 2]  ✅ 不变

# 正确方式 2：明确告知会修改原对象（如果就是想原地改）
def add_zero_inplace(lst):
    lst.append(0)   # 文档里说明：原地修改
    return lst
```

### 练习 1：圆面积计算器

编写一个函数 `circle_area(r, pi=3.14)`，返回半径为 `r` 的圆面积。要求：
- `pi` 有默认值 `3.14`；
- 调用 `circle_area(2)` 时应返回 `12.56`；
- 高精度场景下可用关键字调用 `circle_area(2, pi=3.14159)`，返回 `12.56636`。

**参考答案：**

```python
def circle_area(r, pi=3.14):
    """返回圆面积 = pi * r * r"""
    return pi * r * r

# 验证
print(circle_area(2))                  # 12.56
print(circle_area(2, pi=3.14159))      # 12.56636
```

### 练习 2：任意个数求最大值（不能用内置 `max`）

编写一个函数 `max_of_all(*nums)`，接收任意多个数字，返回最大值。要求：
- 至少要能处理 `max_of_all(3, 7, 2, 9)` 返回 `9`；
- 如果没传任何参数，返回 `None`；
- 不能用 Python 自带的 `max()`。

**参考答案：**

```python
def max_of_all(*nums):
    """从任意多个数中找出最大值"""
    if not nums:              # 没传参数
        return None
    biggest = nums[0]         # 先拿第一个当最大
    for n in nums[1:]:        # 从第二个开始比
        if n > biggest:
            biggest = n
    return biggest

# 验证
print(max_of_all(3, 7, 2, 9))           # 9
print(max_of_all(100))                  # 100
print(max_of_all())                     # None

# 进阶：可以传入一个列表并用 * 解包
data = [4, 8, 1, 15, 6]
print(max_of_all(*data))                # 15
```
