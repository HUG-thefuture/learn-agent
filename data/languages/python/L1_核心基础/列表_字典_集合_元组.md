## 二、概念讲解

### 1. 为什么需要容器？

之前我们学的变量一次只能存**一个**值：

```python
score1 = 90
score2 = 85
score3 = 77
```

如果班里有 50 个学生呢？写 50 个变量显然不现实。**容器就是"一个变量装多个值"的盒子**。Python 给了四种盒子，各有脾气：

| 容器 | 生活比喻 | 特点 |
|---|---|---|
| 列表 `list` | 购物清单 | 有顺序、可增删改、允许重复 |
| 元组 `tuple` | 身份证号 | 有顺序、**一旦写好不能改** |
| 字典 `dict` | 通讯录 | 按"名字→电话"查找，键不能重复 |
| 集合 `set` | 抽奖箱里的号码 | 自动去重、无顺序、查"在不在"特别快 |

### 2. 列表 list —— 最常用的盒子

```python
fruits = ["苹果", "香蕉", "橙子"]
```

- 用**方括号** `[]`，元素用逗号隔开。
- 用**下标**取元素，**从 0 开始数**：`fruits[0]` 是 `"苹果"`。
- 可以随时改：`fruits.append("西瓜")` 往末尾加一个。

### 3. 元组 tuple —— 上了锁的列表

```python
point = (3, 5)   # 一个坐标点，x 和 y 不该被单独改动
```

- 用**圆括号** `()`。
- **不能增删改**，试图 `point[0] = 10` 会报错。
- 为什么需要它？——有些数据天生不该变（坐标、日期、函数返回多个值），用元组能防止误改，也更省内存。

### 4. 字典 dict —— 键值对

```python
student = {"name": "小明", "age": 18, "score": 92}
```

- 用**花括号** `{}`，每项是 `键: 值`。
- 不靠位置找数据，靠**键**：`student["name"]` 得到 `"小明"`。
- 为什么不用列表存？——列表里你得记住"第 0 个是名字、第 1 个是年龄"，字典直接用名字取，可读性好得多。

### 5. 集合 set —— 自动去重的袋子

```python
tags = {"Python", "编程", "Python"}   # 实际只剩 {"Python", "编程"}
```

- 也用花括号，但**没有键值对**，只有孤零零的值。
- 重复元素自动消失；**没有顺序**，不能用下标取。
- 典型用途：去重、判断"在不在里面"（`"Python" in tags`）。

### 6. 一张图记住区别

```
要顺序、要改 → list
要顺序、不改 → tuple
按键查找     → dict
去重/查存在  → set
```

## 三、三个由浅入深的示例

### 示例 1：列表的增删改查（入门）

```python
# 购物清单：体会列表的增、删、改、查
shopping = ["牛奶", "鸡蛋", "面包"]

# 增：末尾追加
shopping.append("苹果")
print("追加后：", shopping)        # ['牛奶', '鸡蛋', '面包', '苹果']

# 改：通过下标修改
shopping[0] = "酸奶"
print("修改后：", shopping)        # ['酸奶', '鸡蛋', '面包', '苹果']

# 删：按值删除
shopping.remove("面包")
print("删除后：", shopping)        # ['酸奶', '鸡蛋', '苹果']

# 查：遍历 + 长度
print("清单共", len(shopping), "项：")
for item in shopping:
    print(" -", item)
```

### 示例 2：字典统计成绩（进阶）

```python
# 用字典记录学生成绩，并找出最高分
scores = {"小明": 85, "小红": 92, "小刚": 78}

# 新增 / 修改（同一个操作：对键赋值）
scores["小丽"] = 88      # 键不存在 → 新增
scores["小明"] = 90      # 键已存在 → 修改

# 安全取值：get 在键不存在时返回默认值，不会报错
print(scores.get("小强", "查无此人"))   # 查无此人

# 遍历键值对
best_name, best_score = "", 0
for name, score in scores.items():
    print(f"{name}: {score} 分")
    if score > best_score:
        best_name, best_score = name, score

print(f"最高分是 {best_name}，{best_score} 分")   # 最高分是 小红，92 分
```

### 示例 3：综合实战——投票统计（提高）

```python
# 场景：收集投票，去重后统计每位候选人得票
votes = ["张三", "李四", "张三", "王五", "李四", "张三"]

# 第一步：用集合看看都有哪些人参与过投票（去重）
candidates = set(votes)
print("参与投票的候选人：", candidates)

# 第二步：用字典统计每人票数
count = {}
for name in votes:
    # get(name, 0)：没出现过就从 0 开始
    count[name] = count.get(name, 0) + 1
print("得票统计：", count)          # {'张三': 3, '李四': 2, '王五': 1}

# 第三步：用元组接收"冠军"信息（max 搭配 key）
winner = max(count.items(), key=lambda kv: kv[1])  # 返回 ('张三', 3) 元组
name, num = winner                # 元组解包：一次拆成两个变量
print(f"冠军是 {name}，获得 {num} 票")
```

> 说明：本课示例均为内存中的小型数据，不涉及文件/网络资源，无需额外释放；后续学习文件操作时我们会讲 `with` 语句。

## 四、常用函数 / 方法速查表

| 函数/方法 | 签名 | 用途 | 最小示例 |
|---|---|---|---|
| `len()` | `len(容器)` | 元素个数 | `len([1,2,3])` → `3` |
| `list.append()` | `lst.append(x)` | 列表末尾加元素 | `a=[1]; a.append(2)` → `[1,2]` |
| `list.remove()` | `lst.remove(x)` | 删除第一个匹配值 | `[1,2,2].remove(2)` → `[1,2]` |
| `list.sort()` | `lst.sort()` | 原地排序 | `a=[3,1]; a.sort()` → `[1,3]` |
| `dict.get()` | `d.get(key, 默认)` | 安全取值 | `{"a":1}.get("b",0)` → `0` |
| `dict.items()` | `d.items()` | 遍历键值对 | `for k,v in d.items():` |
| `dict.keys()/values()` | `d.keys()` | 取所有键/值 | `list({"a":1}.keys())` → `['a']` |
| `set.add()` | `s.add(x)` | 集合加元素 | `s={1}; s.add(2)` → `{1,2}` |
| `in` | `x in 容器` | 判断是否存在 | `"a" in {"a":1}` → `True` |
| `sorted()` | `sorted(可迭代)` | 返回新排序列表 | `sorted({3,1})` → `[1,3]` |
| 类型转换 | `list()/tuple()/set()/dict()` | 容器互转 | `set([1,1,2])` → `{1,2}` |

## 五、5 个新手易错点

**1. 下标从 0 开始，越界会报错**

```python
a = [10, 20, 30]
print(a[3])     # ❌ IndexError：最大下标是 2
print(a[2])     # ✅ 30；最后一个也可以用 a[-1]
```

**2. 修改元组**

```python
t = (1, 2, 3)
t[0] = 99       # ❌ TypeError：元组不可变
t = (99, 2, 3)  # ✅ 只能整体重新赋值
```

**3. 用不存在的键直接取字典**

```python
d = {"name": "小明"}
print(d["age"])            # ❌ KeyError
print(d.get("age", "未知")) # ✅ 用 get 给默认值
```

**4. 创建空集合写错**

```python
s = {}        # ❌ 这是空【字典】，不是集合！
s = set()     # ✅ 空集合必须这样写
```

**5. 遍历时边循环边删列表元素**

```python
nums = [1, 2, 3, 4]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)   # ❌ 边遍历边删会跳过元素，结果出错

nums = [n for n in nums if n % 2 != 0]  # ✅ 用推导式生成新列表
```
