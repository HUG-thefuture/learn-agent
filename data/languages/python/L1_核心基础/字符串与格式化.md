## 🧠 概念讲解

### 1. 为什么需要字符串格式化？

> 📌 **字符串格式化就像"填空模板"。**  
> 想象你有一张贺卡模板：`"亲爱的___，祝你___快乐！"`  
> 你只需要填上名字和节日，就能生成不同的贺卡。格式化就是干这个的。

**不用格式化**的笨办法：

```python
name = "小明"
age = 12
print("我叫" + name + "，今年" + str(age) + "岁。")
```

**用格式化**的聪明办法：

```python
name = "小明"
age = 12
print(f"我叫{name}，今年{age}岁。")
```

> 💡 **为什么推荐格式化？**  
> - 不用手动把数字转成字符串（`str(age)`）  
> - 代码更短、更清晰  
> - 支持对齐、补零、小数位数等高级控制

---

### 2. 三种格式化方式对比

| 方式 | 语法 | 特点 |
|------|------|------|
| `%` 格式化（老式） | `"%s %d" % (name, age)` | 古老，不推荐新手用 |
| `format()` 方法 | `"{} {}".format(name, age)` | 灵活，支持位置/关键字参数 |
| **f-string（推荐）** | `f"{name} {age}"` | **最简洁、最快**，Python 3.6+ |

> ⚠️ **注意**：f-string 是 Python 3.6 之后才有的，如果你用的是老版本（3.5 及以下），需要用 `format()`。

---

### 3. 格式控制：对齐、宽度、小数位

> 📌 **格式控制就像"排版工具"。**  
> 你可以指定：占多宽、靠左/靠右/居中、小数保留几位、要不要补零。

**f-string 格式控制语法**：

```python
f"{变量:填充字符 对齐符号 宽度 .精度 类型}"
```

常用组合：

| 写法 | 含义 | 示例 |
|------|------|------|
| `{x:>10}` | 右对齐，占10位 | `"       hello"` |
| `{x:<10}` | 左对齐，占10位 | `"hello      "` |
| `{x:^10}` | 居中，占10位 | `"  hello   "` |
| `{x:.2f}` | 保留2位小数 | `3.14` |
| `{x:05d}` | 整数补零到5位 | `00042` |
| `{x:,}` | 千位分隔符 | `1,234,567` |

---

### 4. 字符串拼接的多种方式

| 方式 | 语法 | 适用场景 |
|------|------|----------|
| `+` 运算符 | `"a" + "b"` | 少量字符串拼接 |
| `join()` 方法 | `", ".join(list)` | 列表元素拼接成字符串 |
| 乘号 `*` | `"-" * 10` | 重复字符串 |

> ⚠️ **注意**：`+` 拼接大量字符串时效率低（每次创建新字符串），用 `join()` 更高效。

## 💻 完整示例

### 示例 1：基础拼接与格式化（入门）

```python
"""
示例1：用三种方式输出个人信息
目标：理解 + 拼接、f-string、format() 的区别
"""

name = "小明"
age = 12
height = 1.456  # 身高，单位：米

# 方式1：+ 拼接（需要手动转字符串）
print("我叫" + name + "，今年" + str(age) + "岁。")

# 方式2：f-string（推荐）
print(f"我叫{name}，今年{age}岁。")

# 方式3：format() 方法
print("我叫{}，今年{}岁。".format(name, age))

# 进阶：控制小数位数
print(f"我的身高是{height:.2f}米")  # 输出：我的身高是1.46米

# 输出：
# 我叫小明，今年12岁。
# 我叫小明，今年12岁。
# 我叫小明，今年12岁。
# 我的身高是1.46米
```

### 示例 2：对齐与表格输出（进阶）

```python
"""
示例2：用格式化制作一个简单的成绩表
目标：掌握对齐、宽度、填充字符
"""

# 学生成绩数据（列表套字典）
students = [
    {"name": "小明", "score": 95.5},
    {"name": "小红", "score": 88},
    {"name": "小刚", "score": 76.25},
]

# 打印表头（居中，占20位）
print(f"{'姓名':^10}{'成绩':^10}")
print("-" * 20)  # 分隔线

# 打印每一行数据
for student in students:
    name = student["name"]
    score = student["score"]
    # 左对齐占10位，成绩右对齐占10位并保留1位小数
    print(f"{name:<10}{score:>10.1f}")

# 输出：
#     姓名        成绩    
# --------------------
# 小明               95.5
# 小红               88.0
# 小刚               76.2
```

### 示例 3：综合应用——购物小票（实战）

```python
"""
示例3：模拟打印购物小票
目标：综合运用格式化、拼接、循环
"""

# 购物车数据（商品名，单价，数量）
cart = [
    ("苹果", 5.5, 3),
    ("牛奶", 12.0, 2),
    ("面包", 8.5, 1),
]

total = 0.0

print("=" * 30)
print(f"{'商品':<8}{'单价':>6}{'数量':>4}{'小计':>8}")
print("=" * 30)

# 遍历购物车，计算每个商品的小计
for item in cart:
    name, price, quantity = item
    subtotal = price * quantity
    total += subtotal
    # 单价保留2位小数，小计保留2位小数
    print(f"{name:<8}{price:>6.2f}{quantity:>4}{subtotal:>8.2f}")

print("-" * 30)
print(f"{'总计':<18}{total:>8.2f}")
print("=" * 30)

# 输出：
# ==============================
# 商品        单价  数量    小计
# ==============================
# 苹果        5.50    3   16.50
# 牛奶       12.00    2   24.00
# 面包        8.50    1    8.50
# ------------------------------
# 总计                    49.00
# ==============================
```

## 📋 常用函数/调用速查表

| 函数/语法 | 签名/写法 | 用途 | 最小示例 |
|-----------|-----------|------|----------|
| `+` 拼接 | `str1 + str2` | 连接两个字符串 | `"a" + "b"` → `"ab"` |
| `join()` | `"分隔符".join(列表)` | 用分隔符连接列表元素 | `"-".join(["a","b"])` → `"a-b"` |
| `*` 重复 | `str * n` | 重复字符串n次 | `"-" * 3` → `"---"` |
| f-string | `f"{变量}"` | 在字符串中嵌入变量 | `f"年龄{age}"` |
| `format()` | `"{}".format(值)` | 格式化字符串 | `"{}岁".format(12)` |
| 宽度控制 | `{x:>10}` | 右对齐占10位 | `f"{'hi':>5}"` → `"   hi"` |
| 小数控制 | `{x:.2f}` | 保留2位小数 | `f"{3.14159:.2f}"` → `"3.14"` |
| 补零 | `{x:05d}` | 整数补零到5位 | `f"{42:05d}"` → `"00042"` |
| 千位分隔 | `{x:,}` | 数字加千位逗号 | `f"{1234567:,}"` → `"1,234,567"` |

## ⚠️ 新手易错点

### 错误1：忘记把数字转字符串

```python
# ❌ 错误写法
age = 12
print("我今年" + age + "岁")  # TypeError: can only concatenate str

# ✅ 正确写法（用f-string）
age = 12
print(f"我今年{age}岁")

# ✅ 或者用 str() 转换
print("我今年" + str(age) + "岁")
```

---

### 错误2：f-string 里的大括号写错

```python
# ❌ 错误写法：左大括号没闭合
name = "小明"
print(f"你好，{name")  # SyntaxError: f-string: expecting '}'

# ✅ 正确写法
name = "小明"
print(f"你好，{name}")
```

---

### 错误3：对齐符号方向搞反

```python
# ❌ 错误写法（想右对齐却用了<）
print(f"{'hi':<5}")  # 输出 "hi   "（左对齐）

# ✅ 正确写法（右对齐用>）
print(f"{'hi':>5}")  # 输出 "   hi"
```

---

### 错误4：小数位数格式写错

```python
# ❌ 错误写法
pi = 3.14159
print(f"{pi:.2}")  # 输出 "3.1"（这是有效数字，不是小数位！）

# ✅ 正确写法（要加f表示浮点数）
pi = 3.14159
print(f"{pi:.2f}")  # 输出 "3.14"
```

---

### 错误5：`format()` 参数数量不匹配

```python
# ❌ 错误写法
print("{}和{}".format("苹果"))  # IndexError: Replacement index 1 out of range

# ✅ 正确写法
print("{}和{}".format("苹果", "香蕉"))

# ✅ 或者用关键字参数
print("{a}和{b}".format(a="苹果", b="香蕉"))
```
