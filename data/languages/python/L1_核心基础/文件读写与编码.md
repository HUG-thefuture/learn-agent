## 🧠 概念讲解

### 1. 文件是什么？打个比方

想象你有一个**笔记本**：

- **读文件** = 翻开笔记本看内容
- **写文件** = 在笔记本上写字
- **追加** = 在笔记本最后面继续写

在 Python 中，`open()` 函数就是"打开笔记本"的动作，你需要告诉它：
- **打开哪本笔记本**（文件路径）
- **做什么操作**（读、写、还是追加）

### 2. 为什么需要 `with` 语句？

> 📌 **`with` 就像"用完自动合上笔记本"**。

如果你用 `open()` 打开文件后忘记关闭，文件会一直被占用，其他程序可能无法访问它。`with` 语句会在代码块结束后**自动关闭文件**，就像出门自动锁门一样安全。

```python
# 不推荐：容易忘记关闭
f = open('data.txt', 'r')
content = f.read()
f.close()  # 容易忘记！

# 推荐：自动关闭
with open('data.txt', 'r') as f:
    content = f.read()
# 到这里文件已经自动关闭了
```

### 3. 为什么会有"乱码"？

> 📌 **编码 = 文字和数字的翻译规则**。

计算机只认识 0 和 1，所以每个文字都需要一个数字编号。不同国家有不同的编号规则：

- **UTF-8**：国际通用，支持所有语言，**Python 3 默认使用**
- **GBK**：中国常用，只支持中文和英文

如果**写入时用 UTF-8，读取时用 GBK**，就像用中文翻译规则去读英文书——全是乱码！

**解决方案**：读写时都明确指定 `encoding='utf-8'`。

## 💻 三个完整示例

### 示例 1：写入文件（基础版）

```python
# 目标：把一句话写入文件
# 知识点：'w' 模式会清空原内容，'a' 模式会追加

# 写入模式 'w'：如果文件不存在会创建，存在则清空重写
with open('note.txt', 'w', encoding='utf-8') as f:
    f.write('你好，Python！\n')  # \n 是换行符
    f.write('这是第二行。\n')

print('写入完成！')

# 验证：读取看看
with open('note.txt', 'r', encoding='utf-8') as f:
    content = f.read()
print('文件内容：')
print(content)
```

**运行结果**：
```
写入完成！
文件内容：
你好，Python！
这是第二行。
```

---

### 示例 2：追加和读取（进阶版）

```python
# 目标：在已有文件末尾追加内容，然后逐行读取
# 知识点：'a' 模式追加，readlines() 按行读取

# 追加模式 'a'：不会清空原内容，在末尾继续写
with open('note.txt', 'a', encoding='utf-8') as f:
    f.write('这是追加的第三行。\n')

print('追加完成！')

# 逐行读取
with open('note.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()  # 返回一个列表，每行是一个元素

print('逐行显示：')
for i, line in enumerate(lines, 1):  # enumerate 可以带起始编号
    print(f'第{i}行：{line.strip()}')  # strip() 去掉末尾换行符
```

**运行结果**：
```
追加完成！
逐行显示：
第1行：你好，Python！
第2行：这是第二行。
第3行：这是追加的第三行。
```

### 示例 3：处理中文数据（实战版）

```python
# 目标：把学生成绩写入文件，再读取并计算平均分
# 知识点：字典 + 文件读写 + 编码处理

# 学生成绩数据
students = {
    '小明': 85,
    '小红': 92,
    '小刚': 78
}

# 1. 写入文件
with open('scores.txt', 'w', encoding='utf-8') as f:
    for name, score in students.items():
        f.write(f'{name}:{score}\n')  # 格式：名字:分数

print('成绩已保存！')

# 2. 读取并计算平均分
total = 0
count = 0

with open('scores.txt', 'r', encoding='utf-8') as f:
    for line in f:  # 直接遍历文件对象，逐行读取
        line = line.strip()  # 去掉换行符
        if line:  # 跳过空行
            name, score_str = line.split(':')  # 按冒号分割
            score = int(score_str)  # 字符串转整数
            total += score
            count += 1
            print(f'{name} 的成绩是 {score} 分')

average = total / count
print(f'\n平均分：{average:.1f} 分')
```

**运行结果**：
```
成绩已保存！
小明 的成绩是 85 分
小红 的成绩是 92 分
小刚 的成绩是 78 分

平均分：85.0 分
```

## 📋 常用函数/调用速查表

| 函数 | 签名 | 用途 | 最小示例 |
|------|------|------|----------|
| `open()` | `open(file, mode='r', encoding=None)` | 打开文件 | `f = open('a.txt', 'r')` |
| `read()` | `f.read()` | 读取全部内容为字符串 | `content = f.read()` |
| `readline()` | `f.readline()` | 读取一行 | `line = f.readline()` |
| `readlines()` | `f.readlines()` | 读取所有行，返回列表 | `lines = f.readlines()` |
| `write()` | `f.write(string)` | 写入字符串 | `f.write('hello')` |
| `writelines()` | `f.writelines(list)` | 写入字符串列表 | `f.writelines(['a\n', 'b\n'])` |
| `close()` | `f.close()` | 关闭文件 | `f.close()` |
| `strip()` | `str.strip()` | 去掉字符串首尾空白/换行 | `line.strip()` |
| `split()` | `str.split(sep)` | 按分隔符分割字符串 | `line.split(':')` |

## ⚠️ 5个新手易错点

### ❌ 错误 1：忘记指定编码，导致中文乱码
```python
# 错误写法
with open('data.txt', 'w') as f:
    f.write('你好')  # 可能报错或乱码

# 正确写法
with open('data.txt', 'w', encoding='utf-8') as f:
    f.write('你好')
```

### ❌ 错误 2：用 'w' 模式误清空文件
```python
# 错误写法：只想读取，却用了 'w'
with open('important.txt', 'w') as f:
    content = f.read()  # 文件已被清空！

# 正确写法：读取用 'r'
with open('important.txt', 'r') as f:
    content = f.read()
```

### ❌ 错误 3：忘记关闭文件
```python
# 错误写法：打开后不关闭
f = open('data.txt', 'r')
content = f.read()
# 忘记 f.close()

# 正确写法：用 with 自动管理
with open('data.txt', 'r') as f:
    content = f.read()
```

### ❌ 错误 4：路径写错，报 FileNotFoundError
```python
# 错误写法：假设文件在脚本同目录
with open('data.txt', 'r') as f:  # 实际在别的目录
    pass

# 正确写法：先确认当前工作目录
import os
print(os.getcwd())  # 查看当前目录

# 或者用绝对路径
with open('C:/Users/me/project/data.txt', 'r') as f:
    pass
```

### ❌ 错误 5：读取后忘记处理换行符
```python
# 错误写法：直接打印，出现多余空行
with open('data.txt', 'r') as f:
    for line in f:
        print(line)  # 每行后面多一个空行

# 正确写法：用 strip() 去掉换行符
with open('data.txt', 'r') as f:
    for line in f:
        print(line.strip())
```

### 练习 2：成绩统计

文件 `grades.txt` 内容如下（每行一个成绩）：
```
85
92
78
88
```

读取文件，计算并输出：总成绩、平均分、最高分、最低分。

**提示**：使用 `readlines()` 读取所有行，用 `int()` 转换，用 `sum()`、`max()`、`min()` 函数。

<details>
<summary>参考答案（点击展开）</summary>

```python
with open('grades.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()

# 把每行转成整数
scores = []
for line in lines:
    line = line.strip()
    if line:  # 跳过空行
        scores.append(int(line))

total = sum(scores)
average = total / len(scores)
highest = max(scores)
lowest = min(scores)

print(f'总成绩：{total}')
print(f'平均分：{average:.1f}')
print(f'最高分：{highest}')
print(f'最低分：{lowest}')
```
