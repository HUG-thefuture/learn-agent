## 🧠 概念讲解

### 1. 什么是标准库？

想象你买了一套**精装房**（Python 本身），里面已经配好了：

- **工具箱**（`os`、`shutil`）→ 操作文件和文件夹
- **日历和时钟**（`datetime`）→ 处理日期时间
- **骰子**（`random`）→ 生成随机数
- **计算器**（`math`）→ 数学运算

这些工具**不用额外安装**，直接 `import` 就能用，这就是**标准库**。

> 📌 **为什么需要标准库？**  
> 因为"读写文件""获取当前时间"这些需求**几乎每个程序都会遇到**，Python 把它们提前做好，你直接拿来用就行，不用自己造轮子。

### 2. 怎么用标准库？

三步走：

```python
# 第一步：导入（import）
import os

# 第二步：调用（用 . 点出功能）
current_dir = os.getcwd()   # 获取当前目录

# 第三步：使用结果
print(current_dir)
```

### 3. 三个最常用的模块

| 模块 | 比喻 | 主要用途 |
|------|------|----------|
| `os` / `pathlib` | 文件管家 | 创建文件夹、判断文件是否存在、拼接路径 |
| `datetime` | 日历时钟 | 获取当前时间、格式化日期、计算时间差 |
| `random` | 骰子 | 随机选一个、打乱顺序、生成随机数 |

## 💻 三个完整示例

### 示例 1：用 `os` 和 `pathlib` 管理文件

```python
# 文件管家：创建文件夹、检查文件、拼接路径
import os
from pathlib import Path

# 1. 获取当前工作目录
current_dir = os.getcwd()
print(f"当前目录：{current_dir}")

# 2. 拼接路径（不要手动加斜杠！）
folder_path = os.path.join(current_dir, "my_data")
print(f"目标文件夹：{folder_path}")

# 3. 创建文件夹（如果不存在）
if not os.path.exists(folder_path):
    os.makedirs(folder_path)
    print(f"✅ 已创建文件夹：{folder_path}")
else:
    print(f"ℹ️ 文件夹已存在：{folder_path}")

# 4. 用 pathlib 更优雅地操作（推荐！）
data_file = Path(folder_path) / "data.txt"   # 直接用 / 拼接
print(f"数据文件路径：{data_file}")

# 5. 写入一个文件
with open(data_file, "w", encoding="utf-8") as f:
    f.write("hello, 标准库！")

# 6. 检查文件是否存在
print(f"文件存在吗？{data_file.exists()}")

# 预期输出（路径部分会因你的电脑而异）：
# 当前目录：/Users/yourname/project
# 目标文件夹：/Users/yourname/project/my_data
# ✅ 已创建文件夹：/Users/yourname/project/my_data
# 数据文件路径：/Users/yourname/project/my_data/data.txt
# 文件存在吗？True
```

### 示例 2：用 `datetime` 处理日期时间

```python
# 日历时钟：获取时间、格式化、计算时间差
from datetime import datetime, timedelta

# 1. 获取当前时间
now = datetime.now()
print(f"当前时间：{now}")

# 2. 格式化输出（strftime = string format time）
formatted = now.strftime("%Y年%m月%d日 %H:%M:%S")
print(f"格式化时间：{formatted}")

# 3. 只取日期部分
today = now.date()
print(f"今天日期：{today}")

# 4. 计算时间差（timedelta = 时间增量）
three_days_later = now + timedelta(days=3)
print(f"三天后：{three_days_later.strftime('%Y-%m-%d')}")

# 5. 计算两个时间点之间的差
start = datetime(2024, 1, 1, 9, 0, 0)
end = datetime(2024, 1, 1, 12, 30, 0)
duration = end - start
print(f"时间差：{duration}（共 {duration.total_seconds() / 3600:.1f} 小时）")

# 预期输出：
# 当前时间：2024-06-15 14:30:25.123456
# 格式化时间：2024年06月15日 14:30:25
# 今天日期：2024-06-15
# 三天后：2024-06-18
# 时间差：3:30:00（共 3.5 小时）
```

### 示例 3：用 `random` 生成随机数

```python
# 骰子：随机选、打乱、生成随机数
import random

# 1. 随机选一个元素
fruits = ["苹果", "香蕉", "橙子", "葡萄"]
lucky_fruit = random.choice(fruits)
print(f"随机选的水果：{lucky_fruit}")

# 2. 打乱顺序（注意：会直接修改原列表！）
cards = list(range(1, 11))   # [1, 2, 3, ..., 10]
random.shuffle(cards)
print(f"打乱后的牌：{cards}")

# 3. 生成随机整数（包含两端）
dice = random.randint(1, 6)
print(f"掷骰子结果：{dice}")

# 4. 生成随机浮点数（0到1之间）
ratio = random.random()
print(f"随机比例：{ratio:.2f}")

# 5. 从列表中随机取多个（不重复）
team = random.sample(fruits, 2)
print(f"随机选2个水果：{team}")

# 预期输出（每次运行都不同）：
# 随机选的水果：橙子
# 打乱后的牌：[7, 3, 9, 1, 5, 2, 10, 6, 4, 8]
# 掷骰子结果：4
# 随机比例：0.67
# 随机选2个水果：['苹果', '葡萄']
```

## 📋 常用函数速查表

| 函数 | 签名 | 用途 | 最小示例 |
|------|------|------|----------|
| `os.getcwd()` | `() -> str` | 获取当前工作目录 | `os.getcwd()` |
| `os.path.join()` | `(*paths) -> str` | 拼接路径（自动加分隔符） | `os.path.join("a", "b")` → `"a/b"` |
| `os.path.exists()` | `(path) -> bool` | 判断路径是否存在 | `os.path.exists("data.txt")` |
| `os.makedirs()` | `(path, exist_ok=False)` | 创建文件夹（可多级） | `os.makedirs("a/b/c", exist_ok=True)` |
| `Path / str` | `(Path, str) -> Path` | pathlib 拼接路径 | `Path("a") / "b"` → `Path("a/b")` |
| `datetime.now()` | `() -> datetime` | 获取当前时间 | `datetime.now()` |
| `strftime()` | `(format) -> str` | 格式化时间 | `now.strftime("%Y-%m-%d")` |
| `timedelta()` | `(days=0, hours=0, ...)` | 时间增量 | `now + timedelta(days=1)` |
| `random.choice()` | `(seq) -> element` | 随机选一个 | `random.choice([1, 2, 3])` |
| `random.shuffle()` | `(list) -> None` | 打乱列表（原地） | `random.shuffle(my_list)` |
| `random.randint()` | `(a, b) -> int` | 随机整数 [a, b] | `random.randint(1, 6)` |
| `random.sample()` | `(seq, k) -> list` | 随机取 k 个不重复 | `random.sample(range(10), 3)` |

## ⚠️ 新手易错点

### 易错点1：忘记导入模块就使用

❌ **错误写法**：

```python
# 忘记 import，直接使用
current_dir = os.getcwd()   # 运行报错：NameError: name 'os' is not defined
print(current_dir)

# 运行报错：NameError: name 'os' is not defined
```

✅ **正确写法**：

```python
import os

current_dir = os.getcwd()
print(current_dir)

# 输出：/Users/yourname/project（你的实际路径）
```

**为什么错**：Python 不会自动加载所有模块，**用之前必须先 `import`**，就像用工具前要先从工具箱拿出来。

---

### 易错点2：`random.shuffle()` 会修改原列表，且返回 `None`

❌ **错误写法**：

```python
import random

cards = [1, 2, 3, 4, 5]
shuffled = random.shuffle(cards)   # shuffle 返回 None！
print(f"shuffled 的值：{shuffled}")   # 输出 None
print(f"原列表已被修改：{cards}")      # 原列表确实被打乱了

# 输出：
# shuffled 的值：None
# 原列表已被修改：[3, 1, 5, 2, 4]
```

✅ **正确写法**：

```python
import random

cards = [1, 2, 3, 4, 5]
random.shuffle(cards)   # 直接修改原列表，不需要接收返回值
print(f"打乱后的牌：{cards}")

# 输出：打乱后的牌：[4, 2, 5, 1, 3]（每次不同）
```

**为什么错**：`shuffle()` 是**原地操作**（in-place），它直接修改传入的列表，返回 `None`。如果你把返回值赋给变量，得到的只会是 `None`。

---

### 易错点3：路径拼接手动加斜杠

❌ **错误写法**：

```python
import os

folder = "my_data"
filename = "data.txt"

# 手动加斜杠，在 Windows 上会出错！
path = folder + "/" + filename
print(f"路径：{path}")

# 输出：路径：my_data/data.txt（在 Windows 上会变成 my_data\data.txt 才对）
```

✅ **正确写法**：

```python
import os
from pathlib import Path

folder = "my_data"
filename = "data.txt"

# 方法1：用 os.path.join（跨平台安全）
path1 = os.path.join(folder, filename)
print(f"os 方式：{path1}")

# 方法2：用 pathlib（更现代）
path2 = Path(folder) / filename
print(f"pathlib 方式：{path2}")

# 输出：
# os 方式：my_data/data.txt
# pathlib 方式：my_data/data.txt
```

**为什么错**：不同操作系统用不同的路径分隔符（Windows 用 `\`，Mac/Linux 用 `/`）。手动加斜杠在另一个系统上会出错，应该用 `os.path.join()` 或 `pathlib` 的 `/` 运算符。

---

### 易错点4：`strftime` 格式符记错

❌ **错误写法**：

```python
from datetime import datetime

now = datetime.now()

# %M 是分钟，%m 才是月份！这里写反了
formatted = now.strftime("%Y-%M-%d")   # 月份位置会显示分钟
print(f"时间：{formatted}")

# 输出：时间：2024-30-15（30 是分钟，不是月份！）
```

✅ **正确写法**：

```python
from datetime import datetime

now = datetime.now()

# %Y=年(4位), %m=月(2位), %d=日, %H=时(24h), %M=分, %S=秒
formatted = now.strftime("%Y-%m-%d %H:%M:%S")
print(f"时间：{formatted}")

# 输出：时间：2024-06-15 14:30:25
```

**为什么错**：`%m` 是月份（month），`%M` 是分钟（minute），大小写不同含义完全不同。记不住就查表，别靠猜。

---

### 易错点5：`datetime` 相减得到的是 `timedelta`，不是数字

❌ **错误写法**：

```python
from datetime import datetime

start = datetime(2024, 1, 1, 9, 0, 0)
end = datetime(2024, 1, 1, 12, 0, 0)

diff = end - start
print(f"时间差：{diff + 1}")   # 直接加数字会报错！

# 运行报错：TypeError: unsupported operand type(s) for +: 'timedelta' and 'int'
```

✅ **正确写法**：

```python
from datetime import datetime

start = datetime(2024, 1, 1, 9, 0, 0)
end = datetime(2024, 1, 1, 12, 0, 0)

diff = end - start
print(f"时间差：{diff}")                    # 3:00:00
print(f"总秒数：{diff.total_seconds()}")    # 10800.0
print(f"总小时：{diff.total_seconds() / 3600}")  # 3.0

# 输出：
# 时间差：3:00:00
# 总秒数：10800.0
# 总小时：3.0
```

**为什么错**：两个 `datetime` 相减得到的是 `timedelta` 对象，它有自己的属性和方法（如 `.total_seconds()`），不能直接和数字做运算。

### 练习3：计算程序运行时间

- **目标**：用 `datetime` 计算代码执行耗时
- **引导步骤**：
  1. 在代码开始前记录时间 `start`


```

⏱️ 耗时：0.045 秒

```

## 📝 本课小结

1. **标准库 = Python 自带的工具箱**，`import` 就能用，不用额外安装
2. **`os` / `pathlib` 管文件**：创建文件夹用 `os.makedirs()`，拼接路径用 `os.path.join()` 或 `Path /`
3. **`datetime` 管时间**：`now()` 获取当前时间，`strftime()` 格式化，相减得到 `timedelta`
4. **`random` 管随机**：`choice()` 选一个，`sample()` 选多个不重复，`shuffle()` 打乱顺序
5. **三个易错点**：记得 `import`、`shuffle()` 返回 `None`、路径拼接别手动加斜杠
