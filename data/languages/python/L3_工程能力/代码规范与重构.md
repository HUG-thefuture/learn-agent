- **能** 在实际项目中快速定位并改进不规范代码。

## 2. 概念讲解  

> **为什么要规范？**  
> 代码是人写的，机器执行的。若代码风格杂乱，后期维护时就像在雾里摸索，容易出现错误、重复劳动。  
> 规范化让团队成员在阅读代码时能“一眼看懂”，也让自动化工具（如 `flake8`、`black`）能更好地帮你检查。

### 2.1 PEP8 基础  
| 规范 | 说明 | 例子 |
|------|------|------|
| 行宽 ≤ 79 | 方便阅读 | `print("Hello, world!")` |
| 空格 | `a = b + c` | 避免 `a=b+c` |
| 函数名 | 小写，必要时下划线 | `def calculate_total():` |
| 类名 | 大驼峰 | `class UserProfile:` |
| 常量 | 全大写 | `MAX_RETRIES = 5` |
| 文档字符串 | triple‑quote | `"""This function does X."""` |

> **命名规范**  
> - 变量、函数、方法：`snake_case`。  
> - 类：`CamelCase`。  
> - 常量：`UPPER_SNAKE_CASE`。  
> - 模块名：全小写，必要时下划线。  

### 2.2 重构（Refactoring）  
> **重构** 是在不改变外部行为的前提下，改善代码内部结构。  
> 常见手法：  
> - **提取函数**：把重复或复杂逻辑拆成小函数。  
> - **重命名**：让名字更能表达意图。  
> - **消除魔法数**：用常量替代。  
> - **使用上下文管理器**：`with open(...)`。  
> - **使用列表推导**：简化循环。  

> **为什么重构？**  
> - 提高可读性。  
> - 降低错误率。  
> - 方便单元测试。

## 3. 3 个完整示例（由浅入深）

### 示例 1：函数命名与注释

```python
# ❌ 不规范的代码
def calc(a,b):
    return a+b

print(calc(2,3))  # 预期输出: 5
```

```python
# ✅ 规范化后的代码
def calculate_sum(a: int, b: int) -> int:
    """
    计算两个整数之和。

    参数:
        a (int): 第一个加数
        b (int): 第二个加数

    返回:
        int: 两数之和
    """
    return a + b

print(calculate_sum(2, 3))  # 预期输出: 5
```

> **改进点**  
> - 函数名更具描述性。  
> - 添加类型注解与 docstring。

### 示例 2：类的规范与属性封装

```python
# ❌ 不规范的类
class user:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print("Hi, I'm " + self.name)

u = user("Alice", 30)
u.greet()  # 预期输出: Hi, I'm Alice
```

```python
# ✅ 规范化后的类
class User:
    """用户信息类"""

    def __init__(self, name: str, age: int):
        self._name = name  # 私有属性
        self._age = age

    @property
    def name(self) -> str:
        """获取用户名"""
        return self._name

    @property
    def age(self) -> int:
        """获取用户年龄"""
        return self._age

    def greet(self) -> None:
        """打印问候语"""
        print(f"Hi, I'm {self._name}")

u = User("Alice", 30)
u.greet()  # 预期输出: Hi, I'm Alice
```

> **改进点**  
> - 类名使用 `CamelCase`。  
> - 私有属性 `_name`、`_age`。  
> - 通过 `@property` 提供只读访问。

### 示例 3：提取函数与列表推导

```python
# ❌ 长函数，难以阅读
def process_numbers(nums):
    result = []
    for n in nums:
        if n % 2 == 0:
            result.append(n * 2)
        else:
            result.append(n * 3)
    total = sum(result)
    print(f"Total: {total}")
    return result

print(process_numbers([1, 2, 3, 4]))  # 预期输出: Total: 22
```

```python
# ✅ 重构后的代码
def transform(n: int) -> int:
    """根据奇偶性转换数字"""
    return n * 2 if n % 2 == 0 else n * 3

def process_numbers(nums: list[int]) -> list[int]:
    """处理数字列表并打印总和"""
    transformed = [transform(n) for n in nums]  # 列表推导
    total = sum(transformed)
    print(f"Total: {total}")
    return transformed

print(process_numbers([1, 2, 3, 4]))  # 预期输出: Total: 22
```

> **改进点**  
> - 把转换逻辑拆成 `transform`。  
> - 用列表推导简化循环。  
> - 代码更易测试与复用。

## 4. 常用函数/调用速查表

| 函数 | 签名 | 用途 | 最小示例 |
|------|------|------|----------|
| `print()` | `print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)` | 输出文本 | `print("Hello")` |
| `len()` | `len(s)` | 返回长度 | `len([1,2,3])` |
| `sum()` | `sum(iterable, start=0)` | 求和 | `sum([1,2,3])` |
| `sorted()` | `sorted(iterable, key=None, reverse=False)` | 排序 | `sorted([3,1,2])` |
| `enumerate()` | `enumerate(iterable, start=0)` | 生成索引 | `for i, v in enumerate(['a','b']): print(i,v)` |
| `zip()` | `zip(*iterables)` | 并行遍历 | `list(zip([1,2],[3,4]))` |
| `map()` | `map(function, iterable, ...)` | 一致转换 | `list(map(str, [1,2,3]))` |
| `filter()` | `filter(function, iterable)` | 过滤 | `list(filter(lambda x: x>1, [0,1,2]))` |
| `re.compile()` | `re.compile(pattern, flags=0)` | 正则编译 | `re.compile(r'\d+')` |
| `open()` | `open(file, mode='r', buffering=-1, encoding=None, errors=None, newline=None, closefd=True, opener=None)` | 文件 I/O | `with open('data.txt') as f: print(f.read())` |

> **小技巧**  
> - `print()` 的 `sep` 与 `end` 可自定义分隔符与行尾。  
> - `sorted()` 与 `list.sort()` 区别：前者返回新列表，后者原地修改。

## 5. 新手易错点（错误 vs 正确）

### 易错点1：变量名与关键字冲突

```python
# ❌ 错误写法
def add(a, b):
    return a + b

sum = add(1, 2)
print(sum)  # 运行报错：TypeError: 'int' object is not callable
```

```python
# ✅ 正确写法
def add(a, b):
    return a + b

total = add(1, 2)
print(total)  # 预期输出: 3
```

> **为什么错**：`sum` 是内置函数，重新赋值后失去可调用性。  

---

### 易错点2：可变默认参数

```python
# ❌ 错误写法
def append_to_list(value, lst=[]):
    lst.append(value)
    return lst

print(append_to_list(1))  # 预期输出: [1]
print(append_to_list(2))  # 预期输出: [2]，但实际为 [1, 2]
```

```python
# ✅ 正确写法
def append_to_list(value, lst=None):
    if lst is None:
        lst = []
    lst.append(value)
    return lst

print(append_to_list(1))  # 预期输出: [1]
print(append_to_list(2))  # 预期输出: [2]
```

> **为什么错**：默认参数在函数定义时就会被创建，后续调用会复用同一列表。  

---

### 易错点3：忘记 `import` 模块

```python
# ❌ 错误写法
def current_time():
    return datetime.now()

print(current_time())  # 运行报错：NameError: name 'datetime' is not defined
```

```python
# ✅ 正确写法
import datetime

def current_time() -> datetime.datetime:
    return datetime.datetime.now()

print(current_time())  # 预期输出: 当前时间
```

> **为什么错**：`datetime` 未被导入，导致名称未定义。  

---

### 易错点4：使用 `print` 代替 `logging`

```python
# ❌ 错误写法
def process(data):
    print("Processing:", data)

process("sample")  # 仅在控制台输出，无法配置级别或输出文件
```

```python
# ✅ 正确写法
import logging

logging.basicConfig(level=logging.INFO)
def process(data):
    logging.info("Processing: %s", data)

process("sample")  # 可配置日志级别、格式、文件等
```

> **为什么错**：`print` 只能输出到标准输出，缺乏灵活性。  

---

### 易错点5：忘记 `return` 语句

```python
# ❌ 错误写法
def multiply(a, b):
    a * b  # 计算但未返回

result = multiply(2, 3)
print(result)  # 预期输出: 6，实际为 None
```

```python
# ✅ 正确写法
def multiply(a, b):
    return a * b

result = multiply(2, 3)
print(result)  # 预期输出: 6
```

> **为什么错**：函数默认返回 `None`，若不显式 `return`，调用者无法获取结果。

### 练习 2：提取函数

- **目标**：把重复逻辑拆成独立函数。  
- **引导步骤**  
  1. 复制起步代码。  
  2. 将 `calculate_discounted_price` 的核心计算逻辑提取为 `apply_discount`。  
  3. 在主函数中调用 `apply_discount`。  
  4. 运行验证输出。  

```python
# 起步代码
def calculate_discounted_price(price, discount):
    # TODO: 把计算折扣的逻辑提取到 apply_discount 函数
    discounted = price - (price * discount / 100)
    return discounted

print(calculate_discounted_price(200, 15))  # 预期输出: 170.0
```

- **预期输出**  
  ```
  170.0
  ```

```python
# 参考答案
def apply_discount(price, discount):
    """返回折扣后的价格"""
    return price - (price * discount / 100)

def calculate_discounted_price(price, discount):
    return apply_discount(price, discount)

print(calculate_discounted_price(200, 15))  # 预期输出: 170.0
```

## 7. 本课小结  

1. **代码可读性**：命名规范、注释、docstring 能让代码更易理解。  
2. **PEP8**：遵循行宽、空格、命名等规则，保持代码整洁。  
3. **重构**：提取函数、使用列表推导、避免魔法数等，提升可维护性。  
4. **常见错误**：变量冲突、可变默认参数、忘记导入、使用 `print` 代替 `logging`、缺失 `return`。  
5. **实践**：通过练习巩固规范写法，养成良好编码习惯。
