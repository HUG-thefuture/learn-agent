## 二、概念讲解

### 0. 为什么需要"容器"？

前面学过的变量一次只能存**一个**值，比如 `score = 90`。但如果要存全班 30 个人的成绩，难道要写 30 个变量？太痛苦了。容器就是"**一个变量装多个值**"的工具。

可以打一个比方：**变量是一个盒子，容器是一个柜子**——柜子里有很多格子，每个格子放一个东西。

### 1. 列表 list —— 会"排队"的柜子

```python
scores = [85, 92, 78, 60]
```

- **比喻**：一列火车车厢。每节车厢有编号（下标，**从 0 开始**），可以中途换乘客、加挂车厢、摘车厢。
- **特点**：**有序**、**可以修改**、**允许重复**元素。
- **适用场景**：成绩清单、购物清单、待办事项——"一堆同类型的数据"。

### 2. 字典 dict —— 带标签的柜子

```python
student_scores = {'Alice': 90, 'Bob': 85, 'Charlie': 78}
```

- **比喻**：一个带标签的柜子。每个格子有一个标签（键），里面放一个物品（值）。
- **特点**：**键值对**、**键唯一**、**值可以是任意类型**、**支持快速查找**。
- **适用场景**：学生成绩管理、配置文件、键值对存储。

### 3. 集合 set —— 不重复的抽屉

```python
fruits = ['apple', 'banana', 'apple', 'orange']
unique_fruits = set(fruits)
```

- **比喻**：一个不重复的抽屉。放进去相同的物品只会出现一次。
- **特点**：**元素唯一**、**无序**、**支持快速成员测试**。
- **适用场景**：去重处理、成员测试、集合运算。

## 三、3个由浅入深的完整示例

### 示例 1：创建字典和集合并遍历

```python
# 示例 1：创建字典和集合并遍历
student_scores = {'Alice': 90, 'Bob': 85, 'Charlie': 78}
student_sets = {'apple', 'banana', 'cherry'}

print("字典遍历:")
for key, value in student_scores.items():
    print(f"{key}: {value}")

print("\n集合遍历:")
for item in student_sets:
    print(item)
```

**预期输出：**
```text
字典遍历:
Alice: 90
Bob: 85
Charlie: 78

集合遍历:
apple
banana
cherry
```

### 示例 2：字典的增删改查

```python
# 示例 2：字典的增删改查
data = {'name': 'Alice', 'age': 20}

# 查
print("Alice 的年龄:", data.get('age', '未知'))

# 改
data['age'] = 21
print("更新后的年龄:", data['age'])

# 删
del data['age']
print("删除 'age' 后的键值对:", data)

# 增
data['city'] = 'Beijing'
print("新增 'city' 后的键值对:", data)
```

**预期输出：**
```text
Alice 的年龄: 20
更新后的年龄: 21
删除 'age' 后的键值对: {'name': 'Alice'}
新增 'city' 后的键值对: {'name': 'Alice', 'city': 'Beijing'}
```

### 示例 3：集合的增删查

```python
# 示例 3：集合的增删查
fruits = ['apple', 'banana', 'apple', 'orange', 'banana']
unique_fruits = set(fruits)

print("去重后的集合:", unique_fruits)

# 查
print("'apple' 在集合中吗?", 'apple' in unique_fruits)

# 删
unique_fruits.remove('orange')
print("删除了 'orange' 后的集合:", unique_fruits)
```

**预期输出：**
```text
去重后的集合: {'apple', 'banana', 'orange'}
'apple' 在集合中吗? True
删除了 'orange' 后的集合: {'apple', 'banana'}
```

## 五、5个新手易错点

### 易错点1：字典的键必须是可哈希类型

❌ **错误写法**
```python
my_dict = {}
my_dict[[1, 2]] = 'value'   # 用列表当键
print(my_dict)
```
# 运行报错：TypeError: unhashable type: 'list'

✅ **正确写法**
```python
my_dict = {}
my_dict[(1, 2)] = 'value'   # 换成元组（可哈希）当键
print(my_dict)
```
# 预期输出: {(1, 2): 'value'}

**为什么错**：字典的键必须是「可哈希」的不可变类型（字符串、数字、元组等）。列表是可变的、不可哈希，不能当键。

---

### 易错点2：集合里不能放列表

❌ **错误写法**
```python
s = set()
s.add([1, 2, 3])   # 把列表放进集合
print(s)
```
# 运行报错：TypeError: unhashable type: 'list'

✅ **正确写法**
```python
s = set()
s.add((1, 2, 3))   # 换成元组
print(s)
```
# 预期输出: {(1, 2, 3)}

**为什么错**：和字典键一样，集合的元素也必须是可哈希类型。列表不可哈希，所以不能放进集合。

---

### 易错点3：遍历字典时修改它的大小

❌ **错误写法**
```python
d = {'a': 1, 'b': 2, 'c': 3}
for k in d:
    if k == 'b':
        del d[k]   # 边遍历边删除
print(d)
```
# 运行报错：RuntimeError: dictionary changed size during iteration

✅ **正确写法**
```python
d = {'a': 1, 'b': 2, 'c': 3}
for k in list(d):          # 先复制一份键列表，再遍历
    if k == 'b':
        del d[k]
print(d)
```
# 预期输出: {'a': 1, 'c': 3}

**为什么错**：在 `for ... in d` 里增删字典键会改变字典大小，Python 会立刻报错。要先 `list(d)` 复制键列表，或遍历 `list(d.keys())`。

---

### 易错点4：字典推导式解包元素个数不匹配

❌ **错误写法**
```python
items = ['a', 'b', 'c']            # 每个元素是单个字符串，不是「键值对」
d = {k: v for k, v in items}       # 想解包成两个变量
print(d)
```
# 运行报错：ValueError: not enough values to unpack (expected 2, got 1)

✅ **正确写法**
```python
items = [('a', 1), ('b', 2)]       # 每个元素都是「键值对」元组
d = {k: v for k, v in items}
print(d)
```
# 预期输出: {'a': 1, 'b': 2}

**为什么错**：字典推导式 `{k: v for k, v in items}` 要求 `items` 里每个元素都能解包成两个值。单个字符串只能解包出一个字符，所以报错。

---

### 易错点5：`keys()` 返回的不是列表，不能用下标访问

❌ **错误写法**
```python
d = {'a': 1, 'b': 2}
print(d.keys()[0])   # 想用下标取第一个键
```
# 运行报错：TypeError: 'dict_keys' object is not subscriptable

✅ **正确写法**
```python
d = {'a': 1, 'b': 2}
print(list(d.keys())[0])   # 先转成列表，再取下标
```
# 预期输出: a

**为什么错**：`d.keys()` 返回的是 `dict_keys` 视图对象，不是列表，不支持下标访问。要用下标先 `list(d.keys())`。

## 七、本课小结

1. **字典通过键值对存储数据**，键唯一，值可以是任意类型。
2. **集合用于存储不重复的元素**，支持快速成员测试。
3. **字典和集合在数据处理中能大幅减少重复数据的存储和查找时间**。
4. **注意字典的键必须唯一，集合的元素必须可哈希**。
