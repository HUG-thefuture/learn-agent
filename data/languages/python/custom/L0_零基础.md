## 🧠 概念讲解

### 1. 什么是条件语句？

> 📌 **条件语句就像一个“选择题”**，程序会根据条件的真假来决定执行哪段代码。

```python
age = 18
if age >= 18:
    print("你已经成年了！")
else:
    print("你还未成年哦！")
```

- `if` 是“如果”的意思。
- `else` 是“否则”的意思。
- 程序会先判断 `age >= 18` 是否为真，如果是，执行 `print("你已经成年了！")`，否则执行 `print("你还未成年哦！")`。

> ✅ **为什么用条件语句？**  
> 因为现实世界中很多情况是“有多种可能性”，比如判断年龄、成绩、天气等，条件语句能帮助我们处理这些情况。

---

### 2. 什么是循环？

> 📌 **循环就像一个“重复做某件事”的机器**，可以让你的程序重复执行一段代码。

#### 🔄 `for` 循环：固定次数重复

```python
for i in range(5):
    print("这是第", i+1, "次循环")
```

- `range(5)` 生成一个从 0 到 4 的数字序列。
- `i` 依次取这些值，循环 5 次。
- 每次循环都会打印一次“这是第 X 次循环”。

#### 🔄 `while` 循环：只要条件为真就重复

```python
count = 0
while count < 5:
    print("这是第", count+1, "次循环")
    count += 1
```

- `while count < 5` 是循环的条件。
- 只要 `count < 5` 为真，循环就会继续。
- `count += 1` 是关键，它让 `count` 逐渐变大，最终循环会停止。

> ✅ **为什么用循环？**  
> 因为很多任务需要重复执行，比如打印数字、计算总和、遍历列表等，循环能帮我们节省大量重复代码。

## 📌 示例代码（可运行）

### 示例 1：判断成绩等级（`if` 语句）

```python
score = float(input("请输入你的成绩："))
if score >= 90:
    print("你的成绩是 A 级！")
elif score >= 80:
    print("你的成绩是 B 级！")
elif score >= 70:
    print("你的成绩是 C 级！")
elif score >= 60:
    print("你的成绩是 D 级！")
else:
    print("你的成绩是 E 级！")
```

> 📝 **解释**：  
> 程序会根据你输入的成绩，判断属于哪个等级，并输出对应的结果。

---

### 示例 2：打印 1 到 10 的数字（`for` 循环）

```python
for i in range(1, 11):
    print(i)
```

> 📝 **解释**：  
> `range(1, 11)` 生成从 1 到 10 的数字，`i` 依次取这些值，打印出来。

---

### 示例 3：猜数字游戏（`while` 循环）

```python
import random

number = random.randint(1, 10)
guess = int(input("猜一个 1 到 10 之间的数字："))
while guess != number:
    if guess < number:
        print("太小了！")
    else:
        print("太大了！")
    guess = int(input("再猜一次："))
print("恭喜你，猜对了！")
```

> 📝 **解释**：  
> 程序会随机生成一个 1 到 10 的数字，你不断猜测，直到猜对为止。

## 📊 常用函数/调用速查表

| 函数 | 签名 | 用途 | 最小示例 |
|------|------|------|----------|
| `if` | `if 条件:` | 条件判断 | `if age >= 18: print("成年")` |
| `for` | `for 变量 in 可迭代对象:` | 遍历可迭代对象 | `for i in range(5): print(i)` |
| `while` | `while 条件:` | 循环执行 | `while count < 5: print(count)` |
| `range()` | `range(起始, 结束)` | 生成数字序列 | `range(1, 11)` |
| `input()` | `input("提示语")` | 获取用户输入 | `name = input("请输入名字：")` |
| `print()` | `print(内容)` | 输出内容 | `print("Hello, World!")` |

## ⚠️ 新手易错点

| 错误写法 | 正确写法 | 说明 |
|----------|----------|------|
| `if age = 18:` | `if age == 18:` | `=` 是赋值，`==` 是比较 |
| `for i in 1 to 10:` | `for i in range(1, 11):` | Python 没有 `to`，用 `range()` |
| `while True:` | `while count < 5:` | 忘记写退出条件，会导致死循环 |
| `print("Hello")` | `print("Hello")` | 没有错误，但注意缩进 |
| `guess = input("请输入数字：")` | `guess = int(input("请输入数字："))` | `input()` 得到的是字符串，要转换成数字 |

```python
num = float(input("请输入一个数字："))
if num > 0:
    print("这是一个正数。")
elif num < 0:
    print("这是一个负数。")
else:
    print("这是零。")
```

✅ **答案**：如上代码。

### 题目 2：写一个程序，打印 1 到 10 的所有偶数。

```python
for i in range(1, 11):
    if i % 2 == 0:
        print(i)
```

✅ **答案**：如上代码。

## 📚 总结

- 通过条件语句和循环，我们可以编写更复杂的程序，比如判断成绩、打印数字、猜数字游戏等。
