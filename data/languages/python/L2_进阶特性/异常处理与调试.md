## 🧠 概念讲解

### 1. 什么是异常？

在编程中，**异常**是指程序运行过程中出现的错误或意外情况。例如：

- 除以零（ZeroDivisionError）
- 访问不存在的键（KeyError）
- 文件找不到（FileNotFoundError）

Python 提供了 `try-except` 语句来捕获和处理这些异常，避免程序直接崩溃。

### 2. 异常处理结构

```python
try:
    # 可能引发异常的代码
    result = 10 / 0
except ZeroDivisionError:
    # 捕获特定异常
    print("不能除以零！")
finally:
    # 不管是否发生异常，都会执行的代码
    print("异常处理完成")
```

- `try`：尝试执行的代码块
- `except`：捕获特定类型的异常
- `else`：如果没有异常发生，执行该块（可选）
- `finally`：无论是否发生异常，都会执行的代码（可选）

### 3. 调试技巧

调试是找出程序错误的过程。常用方法包括：

- **打印调试**：使用 `print()` 输出变量值
- **断言调试**：使用 `assert` 检查条件是否为真
- **调试器**：使用 `pdb` 模块逐步执行代码

## 📊 常用函数/调用速查表

| 函数 | 签名 | 用途 | 最小示例 |
|------|------|------|----------|
| `try` | `try:` | 开始异常处理块 | `try: ...` |

## ⚠️ 新手易错点

### 易错点1：忘记捕获所有异常

```python
# 错误写法：只捕获特定异常，未处理其他错误
try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零！")
```

**预期报错**：
```
# 运行报错：ZeroDivisionError: division by zero
```

✅ **正确写法**：

```python
# 正确写法：捕获所有异常，避免程序崩溃
try:
    result = 10 / 0
except Exception as e:
    print(f"发生错误：{e}")
```

**预期输出**：
```
发生错误：division by zero
```

**为什么错**：未捕获所有可能的异常，导致程序崩溃。

---

### 易错点2：在 `except` 中未处理异常

```python
# 错误写法：捕获异常但未处理
try:
    result = 10 / 0
except ZeroDivisionError:
    pass
```

**预期报错**：
```
# 运行报错：ZeroDivisionError: division by zero
```

✅ **正确写法**：

```python
# 正确写法：捕获异常并处理
try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零！")
```

**预期输出**：
```
不能除以零！
```

**为什么错**：未在 `except` 块中处理异常，导致程序崩溃。

---

### 易错点3：在 `finally` 中执行敏感操作

```python
# 错误写法：在 finally 中执行可能引发异常的操作
try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零！")
finally:
    print(1 / 0)
```

**预期报错**：
```
# 运行报错：ZeroDivisionError: division by zero
```

✅ **正确写法**：

```python
# 正确写法：在 finally 中执行安全操作
try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零！")
finally:
    print("异常处理完成")
```

**预期输出**：
```
不能除以零！
异常处理完成
```

**为什么错**：`finally` 块中执行了可能引发异常的操作，导致程序崩溃。

---

### 易错点4：未使用 `else` 块处理正常流程

```python
# 错误写法：未使用 else 块处理正常流程
```

---

### 易错点5：在 `except` 中未使用 `as` 捕获异常

```python
# 错误写法：未使用 as 捕获异常
```

```python

```


**为什么错**：未使用 `as` 捕获异常，导致无法获取异常信息。
