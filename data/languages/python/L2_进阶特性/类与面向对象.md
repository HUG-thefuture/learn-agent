## 2. 概念讲解

### 2.1 为什么需要“类”？

以前你可能会这样表示一个学生：

```python
student = {"name": "小明", "score": 85}
```

然后写函数处理：

```python
def is_pass(student):
    return student["score"] >= 60
```

这没问题，但数据和行为是分开的。  
如果学生很多，函数也很多，代码会越来越散。

**类**就像一张“图纸”或“模具”，它把：

- 数据：名字、分数、年龄……
- 行为：打印信息、判断是否及格、过生日……

打包在一起。  
以后每个具体的学生，都是根据这张图纸造出来的“实例”。

> 比方：  
> `class Student` 是“学生图纸”；  
> `Student("小明", 85)` 是按图纸造出来的“具体学生小明”。

---

### 2.2 类与实例

```python
class Dog:
    pass

dog1 = Dog()
dog2 = Dog()
```

- `Dog` 是类。
- `dog1`、`dog2` 是实例。
- 一个类可以创建很多实例，它们互不干扰。

---

### 2.3 `__init__` 和 `self`

创建实例时，Python 会自动调用 `__init__` 方法，用来做“出厂设置”。

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

- `__init__`：初始化方法，创建对象时自动执行。
- `self`：表示“当前这个实例自己”，类似“我的”。
- `self.name = name`：把参数 `name` 存到“我的名字”里。

> 比方：  
> `self` 就像每个人说“我的名字是……”。  
> 小明说“我的名字是小明”，小白说“我的名字是小白”，互不影响。

调用时不用手动传 `self`：

```python
dog = Dog("旺财", 3)
```

Python 会自动把 `dog` 传给 `self`。

---

### 2.4 方法：对象会做什么

定义在类里面的函数叫“方法”。  
方法第一个参数通常都是 `self`。

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(f"{self.name} 汪汪叫！")
```

调用：

```python
dog = Dog("旺财")
dog.bark()   # 旺财 汪汪叫！
```

---

### 2.5 继承：复用父类代码

如果多个类有共同点，可以写一个父类，让子类继承。

```python
class Animal:
    def speak(self):
        print("动物发出声音")

class Dog(Animal):
    def speak(self):
        print("狗汪汪叫")
```

- `class Dog(Animal):` 表示 `Dog` 继承 `Animal`。
- 子类可以重写父类方法。
- 子类也可以用 `super()` 调用父类方法。

> 比方：  
> 父亲会做饭，儿子继承了这个手艺；儿子还可以改进菜谱，做出自己的版本。

---

### 2.6 多态：同一个动作，不同表现

同样是 `speak()`：

- 狗调用时汪汪叫；
- 猫调用时喵喵叫。

调用者不用关心具体是什么动物，只要它会 `speak()` 就行。

```python
for animal in [Dog(), Cat()]:
    animal.speak()
```

---

### 2.7 文件读写与资源释放

类里也可以操作文件。  
文件读写一定要用 `with open(...)`，它会自动关闭文件，避免资源泄漏。

```python
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("hello")
```

离开 `with` 代码块后，文件自动关闭。

## 3. 三个由浅入深的完整示例

### 示例 1：最简单的类——Dog

```python
class Dog:
    # 类属性：所有狗共享
    species = "犬科动物"

    def __init__(self, name, age):
        # 实例属性：每只狗自己的数据
        self.name = name
        self.age = age

    def bark(self):
        print(f"{self.name} 汪汪叫！")

    def birthday(self):
        self.age += 1
        print(f"{self.name} 过生日啦，现在 {self.age} 岁。")


# 创建两个实例
dog1 = Dog("旺财", 3)
dog2 = Dog("小白", 1)

dog1.bark()       # 旺财 汪汪叫！
dog2.bark()       # 小白 汪汪叫！

dog1.birthday()   # 旺财 过生日啦，现在 4 岁。

print(dog1.name, dog1.age)  # 旺财 4
print(dog2.name, dog2.age)  # 小白 1

print(Dog.species)          # 犬科动物
```

**重点：**

- `__init__` 创建对象时自动调用。
- `self.name`、`self.age` 是每个实例自己的属性。
- `species` 是类属性，所有实例共享。

---

### 示例 2：继承与多态——动物叫声

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} 发出声音")


class Dog(Animal):
    def speak(self):
        print(f"{self.name} 汪汪叫")


class Cat(Animal):
    def speak(self):
        print(f"{self.name} 喵喵叫")


class GuideDog(Dog):
    def __init__(self, name, owner):
        # 调用父类的初始化方法
        super().__init__(name)
        self.owner = owner

    def speak(self):
        # 先调用父类 Dog 的 speak
        super().speak()
        print(f"{self.name} 是 {self.owner} 的导盲犬")


# 多态：同一个 speak()，不同对象有不同表现
animals = [
    Dog("旺财"),
    Cat("咪咪"),
    GuideDog("阿黄", "小明")
]

for animal in animals:
    animal.speak()
```

**输出：**

```text
旺财 汪汪叫
咪咪 喵喵叫
阿黄 汪汪叫
阿黄 是 小明的导盲犬
```

**重点：**

- `class Dog(Animal):` 表示继承。
- `super().__init__(name)` 调用父类初始化。
- `super().speak()` 调用父类方法。
- 子类重写 `speak()`，实现多态。

### 示例 3：综合——学生成绩管理器（含文件读写）

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_pass(self):
        return self.score >= 60

    def __str__(self):
        # print(对象) 时会自动调用这个方法
        return f"{self.name}: {self.score}"


class GradeBook:
    def __init__(self):
        self.students = []

    def add(self, student):
        self.students.append(student)

    def average(self):
        if not self.students:
            return 0
        total = 0
        for s in self.students:
            total += s.score
        return total / len(self.students)

    def save(self, filename):
        # with open 会自动关闭文件，避免资源泄漏
        with open(filename, "w", encoding="utf-8") as f:
            for s in self.students:
                f.write(f"{s.name},{s.score}\n")

    def load(self, filename):
        self.students.clear()
        try:
            # with open 会自动关闭文件
            with open(filename, "r", encoding="utf-8") as f:
                for line in f:
                    line = line.strip()
                    if not line:
                        continue
                    name, score = line.split(",")
                    self.students.append(Student(name, int(score)))
        except FileNotFoundError:
            print(f"文件 {filename} 不存在，先添加学生吧。")


if __name__ == "__main__":
    book = GradeBook()
    book.add(Student("小明", 85))
    book.add(Student("小红", 58))

    book.save("students.txt")
    print("平均分:", book.average())

    for s in book.students:
        print(s, "及格" if s.is_pass() else "不及格")

    # 重新加载文件，验证保存成功
    new_book = GradeBook()
    new_book.load("students.txt")
    print("重新加载后：")
    for s in new_book.students:
        print(s)
```

**重点：**

- `Student` 类封装学生数据和行为。
- `GradeBook` 类管理多个学生。
- `__str__` 让 `print(对象)` 更友好。
- 文件读写使用 `with open`，自动释放资源。

## 4. 常用函数/调用速查表

| 函数/语法 | 签名/写法 | 用途 | 最小示例 |
|---|---|---|---|
| `class` | `class 类名:` | 定义类 | `class Dog: pass` |
| `__init__` | `def __init__(self, 参数...):` | 初始化实例属性 | `def __init__(self, name): self.name = name` |
| `self` | `self.属性` / `self.方法()` | 指向当前实例 | `self.name = name` |
| 实例化 | `变量 = 类名(参数)` | 创建实例 | `d = Dog("旺财")` |
| 方法调用 | `实例.方法(参数)` | 执行对象行为 | `d.bark()` |
| `super()` | `super().方法(参数)` | 调用父类方法 | `super().__init__(name)` |
| `isinstance` | `isinstance(对象, 类)` | 判断对象是否属于类 | `isinstance(d, Dog)` |
| `type` | `type(对象)` | 查看对象类型 | `type(d)` |
| `__str__` | `def __str__(self):` | 定义 `print(对象)` 的显示 | `return f"{self.name}"` |
| 类属性 | `类名.属性` | 所有实例共享 | `Dog.species = "犬科"` |
| 实例属性 | `self.属性` | 每个实例独有 | `self.name = name` |

## 5. 五个新手易错点

### 易错点 1：忘记写 `self`

**错误写法：**

```python
class Dog:
    def bark():
        print("汪汪")
```

**正确写法：**

```python
class Dog:
    def bark(self):
        print("汪汪")
```

方法第一个参数必须是 `self`。

---

### 易错点 2：`__init__` 拼写错误

**错误写法：**

```python
class Dog:
    def __int__(self, name):
        self.name = name
```

**正确写法：**

```python
class Dog:
    def __init__(self, name):
        self.name = name
```

是 `__init__`，不是 `__int__`。

---

### 易错点 3：方法里访问属性忘记 `self`

**错误写法：**

```python
class Student:
    def __init__(self, name):
        self.name = name

    def info(self):
        return f"姓名：{name}"
```

```python
s = Student("小明")
print(s.info())
# 运行报错：NameError: name 'name' is not defined
```

**正确写法：**

```python
class Student:
    def __init__(self, name):
        self.name = name

    def info(self):
        return f"姓名：{self.name}"
```

```python
s = Student("小明")
print(s.info())
# 预期输出：姓名：小明
```

方法里访问实例属性要写 `self.属性名`。

---

### 易错点 4：调用方法时多传了 `self`

**错误写法：**

```python
class Dog:
    def bark(self):
        print("汪汪")

dog = Dog()
dog.bark(dog)   # 多传了一个参数
# 运行报错：TypeError: Dog.bark() takes 1 positional argument but 2 were given
```

**正确写法：**

```python
class Dog:
    def bark(self):
        print("汪汪")

dog = Dog()
dog.bark()   # 不用手动传 self
# 预期输出：汪汪
```

Python 会自动把 `dog` 传给 `self`，调用时不用手动传。

---

### 易错点 5：继承时忘记调用父类 `__init__`

**错误写法：**

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, age):
        # 没有调用 super().__init__(name)，self.name 永远不会被赋值
        self.age = age

d = Dog("旺财", 3)
print(d.name)   # 访问不到 name
# 运行报错：AttributeError: 'Dog' object has no attribute 'name'
```

**正确写法：**

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, age):
        super().__init__(name)   # 先初始化父类部分
        self.age = age

d = Dog("旺财", 3)
print(d.name)   # 旺财
print(d.age)    # 3
```

子类如果重写了 `__init__`，通常要用 `super().__init__(...)` 初始化父类部分。

## 6. 本课小练习

### 练习 1：定义 `Book` 类

要求：

1. 属性：`title`、`author`、`price`。
2. 方法 `info()`，返回字符串：`《书名》 by 作者, 价格: 价格 元`。
3. 创建一个实例并打印 `info()`。

**参考答案：**

```python
class Book:
    def __init__(self, title, author, price):
        self.title = title
        self.author = author
        self.price = price

    def info(self):
        return f"《{self.title}》 by {self.author}, 价格: {self.price} 元"


book = Book("Python入门", "张三", 59.9)
print(book.info())
```

---

### 练习 2：继承 `Vehicle`

要求：

1. 父类 `Vehicle`：
   - `__init__(self, brand)` 保存品牌。
   - `move()` 打印 `"{brand} 在移动"`。
2. 子类 `Car` 继承 `Vehicle`：
   - `__init__(self, brand, doors)`，用 `super().__init__(brand)` 初始化品牌，再保存车门数。
   - 重写 `move()`，打印 `"{brand} 汽车有 {doors} 个门，在公路上行驶"`。
3. 创建 `Car` 实例并调用 `move()`。

**参考答案：**

```python
class Vehicle:
    def __init__(self, brand):
        self.brand = brand

    def move(self):
        print(f"{self.brand} 在移动")


class Car(Vehicle):
    def __init__(self, brand, doors):
        super().__init__(brand)
        self.doors = doors

    def move(self):
        print(f"{self.brand} 汽车有 {self.doors} 个门，在公路上行驶")


car = Car("比亚迪", 4)
car.move()
```

## 本课小结

- 类 = 图纸，实例 = 按图纸造出来的具体对象。
- `__init__` 做初始化，`self` 表示当前实例。
- 方法就是对象会做的动作。
- 继承可以复用父类代码，`super()` 调用父类方法。
- 文件读写用 `with open`，自动释放资源。
