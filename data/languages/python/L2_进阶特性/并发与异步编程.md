## 二、概念讲解

### 1. 先打个比方：为什么需要"并发"？

想象你是一个餐厅老板，只有你一个人（单线程）：

- 你接电话订餐 → 挂电话 → 去厨房做菜 → 做完 → 再接下一个电话
- 如果电话一直响，你只能一个个处理，后面的客人等很久

现在你雇了三个员工（多线程/多进程/协程）：

- 一个接电话、一个做菜、一个送外卖——同时干活，效率翻倍

**但注意**：Python 有个特殊机制叫 **GIL（全局解释器锁）**，它让"同一时刻只有一个线程在跑 Python 代码"。所以：

- **IO 密集**（等网络、等磁盘）：线程/协程能提速，因为等待时不占 CPU
- **CPU 密集**（大量计算）：线程没用，要用多进程（每个进程有独立 GIL）

### 2. 三种并发方式对比

| 方式 | 适合场景 | 特点 | 类比 |
|------|---------|------|------|
| **线程** `threading` | IO 密集 | 共享内存，需加锁 | 多个服务员共用一张订单本 |
| **多进程** `multiprocessing` | CPU 密集 | 独立内存，进程间通信麻烦 | 多个独立厨房，各自做菜 |
| **异步** `asyncio` | 高并发 IO | 单线程内切换，最轻量 | 一个超级服务员，记下所有订单，挨个催 |

### 3. 异步的核心：事件循环

想象一个"待办事项清单"：

```
事件循环（老板）：
  1. 看到任务A在等网络 → 记下来"等好了叫我"
  2. 看到任务B在等磁盘 → 记下来"等好了叫我"
  3. 自己闲着 → 检查清单，谁好了就继续谁
```

这就是 `asyncio` 的工作方式：**单线程内不断切换任务**，谁在等待就切走，谁好了就切回来。

## 三、完整示例

### 示例 1：线程——同时下载两个文件（模拟）

```python
import threading
import time

def download(name, seconds):
    """模拟下载文件，耗时 seconds 秒"""
    print(f"开始下载 {name}...")
    time.sleep(seconds)  # 模拟网络等待
    print(f"{name} 下载完成！")

# 创建两个线程
t1 = threading.Thread(target=download, args=("文件A", 2))
t2 = threading.Thread(target=download, args=("文件B", 3))

# 启动线程
t1.start()
t2.start()

# 等待两个线程都结束
t1.join()
t2.join()

print("所有下载任务完成！")

# 预期输出（顺序可能略有不同）：
# 开始下载 文件A...
# 开始下载 文件B...
# 文件A 下载完成！
# 文件B 下载完成！
# 所有下载任务完成！
```

### 示例 2：多进程——并行计算（CPU 密集）

```python
from multiprocessing import Process
import time

def calculate_square(n):
    """计算 n 的平方，模拟 CPU 密集任务"""
    result = 0
    for i in range(n):
        result += i * i  # 大量计算
    print(f"计算 {n} 的平方和 = {result}")

if __name__ == "__main__":
    start = time.time()
    
    # 创建两个进程
    p1 = Process(target=calculate_square, args=(1000000,))
    p2 = Process(target=calculate_square, args=(1000000,))
    
    p1.start()
    p2.start()
    p1.join()
    p2.join()
    
    print(f"总耗时：{time.time() - start:.2f} 秒")

# 预期输出（耗时因机器而异，但两个进程并行执行）：
# 计算 1000000 的平方和 = 333332833333500000
# 计算 1000000 的平方和 = 333332833333500000
# 总耗时：约 earth 0.5-1 秒（比串行快）
```

### 示例 3：异步——并发发起多个网络请求（模拟）

```python
import asyncio

async def fetch_data(url, delay):
    """模拟异步获取网页数据"""
    print(f"开始请求 {url}")
    await asyncio.sleep(delay)  # 模拟网络延迟
    print(f"完成请求 {url}，返回数据")
    return f"{url} 的数据"

async def main():
    print("主程序开始")
    
    # 并发执行三个任务
    tasks = [
        fetch_data("https://api.example.com/users", 2),
        fetch_data("https://api.example.com/posts", 1),
        fetch_data("https://api.example.com/comments", 3),
    ]
    
    # gather 会等待所有任务完成，返回结果列表
    results = await asyncio.gather(*tasks)
    
    print("所有请求完成！")
    for r in results:
        print(f"拿到：{r}")

# 运行异步主函数
asyncio.run(main())

# 预期输出（注意：三个请求几乎同时开始，但完成顺序不同）：
# 主程序开始
# 开始请求 https://api.example.com/users
# 开始请求 https://api.example.com/posts
# 开始请求 https://api.example.com/comments
# 完成请求 https://api.example.com/posts，返回数据
# 完成请求 https://api.example.com/users，返回数据
# 完成请求 https://api.example.com/comments，返回数据
# 所有请求完成！
# 拿到：https://api.example.com/users 的数据
# 拿到：https://api.example.com/posts 的数据
# 拿到：https://api.example.com/comments 的数据
```

## 四、常用函数/调用速查表

| 函数/语法 | 签名 | 用途 | 最小示例 |
|-----------|------|------|----------|
| `threading.Thread` | `Thread(target=func, args=(...))` | 创建线程 | `t = Thread(target=f); t.start()` |
| `thread.join()` | `join(timeout=None)` | 等待线程结束 | `t.join()` |
| `threading.Lock` | `Lock()` | 创建锁 | `lock = Lock(); lock.acquire()` |
| `multiprocessing.Process` | `Process(target=func, args=(...))` | 创建进程 | `p = Process(target=f); p.start()` |
| `asyncio.run` | `run(coro)` | 运行异步主函数 | `asyncio.run(main())` |
| `asyncio.gather` | `gather(*coros)` | 并发等待多个协程 | `await gather(t1, t2)` |
| `async def` | `async def func():` | 定义协程函数 | `async def f(): await sleep(1)` |
| `await` | `await coro` | 等待协程完成 | `await asyncio.sleep(1)` |

## 五、5个新手易错点

### 易错点1：在同步代码里调用 `await`

❌ **错误写法**（运行报错：SyntaxError）

```python
import asyncio

async def say_hello():
    await asyncio.sleep(1)
    return "你好"

# 错误：在普通函数里用 await
def main():
    result = await say_hello()  # 运行报错：SyntaxError: 'await' outside async function
    print(result)

main()
```

✅ **正确写法**

```python
import asyncio

async def say_hello():
    await asyncio.sleep(1)
    return "你好"

async def main():
    result = await say_hello()
    print(result)

# 用 asyncio.run 启动
asyncio.run(main())
# 预期输出：你好
```

**为什么错**：`await` 只能在 `async def` 定义的协程函数里使用。普通函数没有事件循环，无法挂起等待。

---

### 易错点2：忘记 `join()` 导致主线程提前退出

❌ **错误写法**（运行不报错，但输出不完整）

```python
import threading
import time

def work():
    time.sleep(1)
    print("工作完成")

t = threading.Thread(target=work)
t.start()
# 忘记 join()，主线程直接结束
print("主线程结束")

# 预期输出（可能只有）：
# 主线程结束
# （"工作完成" 可能没打印出来，因为程序已退出）
```

✅ **正确写法**

```python
import threading
import time

def work():
    time.sleep(1)
    print("工作完成")

t = threading.Thread(target=work)
t.start()
t.join()  # 等待子线程结束
print("主线程结束")

# 预期输出：
# 工作完成
# 主线程结束
```

**为什么错**：主线程不会自动等待子线程。`join()` 告诉主线程"等这个子线程干完再继续"。

---

### 易错点3：多线程共享变量不加锁

❌ **错误写法**（运行结果不确定，可能小于 100000）

```python
import threading

counter = 0

def increment():
    global counter
    for _ in range(100000):
        counter += 1  # 不是原子操作！多个线程同时读写会出错

threads = []
for _ in range(10):
    t = threading.Thread(target=increment)
    threads.append(t)
    t.start()

for t in threads:
    t.join()

print(f"计数器值：{counter}")  # 预期 1000000，实际可能小于这个数
```

✅ **正确写法**

```python
import threading

counter = 0
lock = threading.Lock()  # 创建锁

def increment():
    global counter
    for _ in range(100000):
        with lock:  # 加锁保护
            counter += 1

threads = []
for _ in range(10):
    t = threading.Thread(target=increment)
    threads.append(t)
    t.start()

for t in threads:
    t.join()

print(f"计数器值：{counter}")  # 预期输出：计数器值：1000000
```

**为什么错**：`counter += 1` 在底层是"读-改-写"三步，多个线程同时操作会互相覆盖。加锁保证同一时刻只有一个线程能改。

### 易错点4：多进程代码忘记 `if __name__ == "__main__"`

❌ **错误写法**（Windows 上运行报错）

```python
from multiprocessing import Process

def worker():
    print("子进程工作")

# 错误：没有保护主模块
p = Process(target=worker)
p.start()
p.join()
# Windows 上运行报错：RuntimeError: An attempt has been made to start a new process...
```

✅ **正确写法**

```python
from multiprocessing import Process

def worker():
    print("子进程工作")

if __name__ == "__main__":  # 必须加这个保护
    p = Process(target=worker)
    p.start()
    p.join()
    # 预期输出：子进程工作
```

**为什么错**：多进程会重新导入主模块，没有保护会导致无限递归创建进程。`if __name__ == "__main__"` 确保只在主进程执行创建逻辑。

### 易错点5：在异步代码里用 `time.sleep` 阻塞事件循环

❌ **错误写法**（运行耗时 4 秒，没有并发效果）

```python
import asyncio
import time

async def task(name, delay):
    print(f"开始 {name}")
    time.sleep(delay)  # 错误：阻塞了整个事件循环！
    print(f"完成 {name}")

async def main():
    await asyncio.gather(
        task("A", 2),
        task("B", 2),
    )

asyncio.run(main())
# 预期输出（耗时约 4 秒，两个任务串行）：
# 开始 A
# 完成 A
# 开始 B
# 完成 B
```

✅ **正确写法**

```python
import asyncio

async def task(name, delay):
    print(f"开始 {name}")
    await asyncio.sleep(delay)  # 正确：让出控制权
    print(f"完成 {name}")

async def main():
    await asyncio.gather(
        task("A", 2),
        task("B", 2),
    )

asyncio.run(main())
# 预期输出（耗时约 2 秒，两个任务并发）：
# 开始 A
# 开始 B
# 完成 A
# 完成 B
```

**为什么错**：`time.sleep` 是同步阻塞，会卡住整个事件循环。必须用 `await asyncio.sleep` 才能让出控制权给其他协程。

## 七、本课小结

1. **三种并发方式各有适用场景**：IO 密集用 `asyncio` 或线程，CPU 密集用多进程
2. **`asyncio` 是单线程内的协作式调度**，靠 `await` 让出控制权，适合高并发 IO
3. **线程共享内存要加锁**，多进程内存独立但通信麻烦
4. **`asyncio.run(main())` 是异步程序的入口**，`await` 只能在 `async def` 里用
5. **多进程代码必须加 `if __name__ == "__main__"`** 保护
