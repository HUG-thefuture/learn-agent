## 2. 概念讲解

### 2.1 一切皆对象，函数也是！

在Python中，函数和整数、字符串一样，都是“对象”。这意味着你可以：
- 把函数赋值给一个变量
- 把函数作为参数传给另一个函数
- 在函数内部定义一个新函数并返回它

这是理解闭包和装饰器的基石。

### 2.2 闭包：函数“记住”了它的出生地

想象一个“计数器”工厂。你要求工厂生产一个计数器，这个计数器每次被调用就加1。关键在于，这个计数器必须“记住”它自己的初始值。这个“记住”的能力，就是闭包。

```python
def make_counter(start):
    count = start  # 这是外部函数的局部变量
    def counter():  # 内部函数
        nonlocal count  # 声明我们要修改外部的 count
        count += 1
        return count
    return counter  # 返回内部函数

my_counter = make_counter(10)
print(my_counter())  # 11
print(my_counter())  # 12
```

**为什么能记住？** 因为 `counter` 函数在定义时，捕获了 `count` 这个变量的引用。即使 `make_counter` 已经执行完毕，`count` 的内存空间依然被 `counter` 引用着，不会释放。这就是闭包。

### 2.3 装饰器：给函数“贴贴纸”

装饰器本质上就是一个函数，它接收一个函数作为参数，并返回一个新函数（通常是包装后的函数）。这个新函数会“包裹”原函数，在调用前后执行额外的代码。

**为什么用 `@` 语法？** 它只是一个语法糖，让代码更简洁、可读性更高。`@decorator` 放在函数定义前，等价于 `func = decorator(func)`。

## 3. 三个由浅入深的完整示例

### 示例1：最简单的装饰器——打印问候语

这个例子帮你理解装饰器的基本结构：接收函数，返回新函数。

```python
def say_hello_decorator(func):
    """这个装饰器在调用原函数前打印一句问候。"""
    def wrapper():
        print("你好！我是装饰器。")
        func()  # 调用原函数
    return wrapper

@say_hello_decorator
def greet():
    print("我是原始函数 greet。")

greet()

# 预期输出：
# 你好！我是装饰器。
# 我是原始函数 greet。
```

### 示例2：带参数的函数——记录日志

原函数有参数，装饰器需要能处理。这里使用 `*args` 和 `**kwargs` 来接收任意参数。

```python
def log_decorator(func):
    """打印函数的调用日志。"""
    def wrapper(*args, **kwargs):
        print(f"调用函数 {func.__name__}，参数是 {args} {kwargs}")
        result = func(*args, **kwargs)
        print(f"函数 {func.__name__} 返回 {result}")
        return result
    return wrapper

@log_decorator
def add(a, b):
    return a + b

@log_decorator
def greet(name, greeting="你好"):
    return f"{greeting}，{name}！"

print(add(3, 5))
print(greet("小明", greeting="早上好"))

# 预期输出：
# 调用函数 add，参数是 (3, 5) {}
# 函数 add 返回 8
# 8
# 调用函数 greet，参数是 ('小明',) {'greeting': '早上好'}
# 函数 greet 返回 早上好，小明！
# 早上好，小明！
```

### 示例3：带参数的装饰器——控制重复次数

装饰器本身也可以带参数，这需要再包一层函数。这个例子实现一个“重复执行”的装饰器。

```python
def repeat(times):
    """这个装饰器工厂接收一个次数参数，返回一个装饰器。"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result  # 返回最后一次的结果
        return wrapper
    return decorator

@repeat(times=3)
def say_hello():
    print("Hello!")

say_hello()

# 预期输出：
# Hello!
# Hello!
# Hello!
```

## 4. 常用函数/调用速查表

| 函数/语法 | 签名/用途 | 最小示例 |
| :--- | :--- | :--- |
| `def wrapper(*args, **kwargs)` | 在装饰器内部定义包装函数，接收任意参数 | `def wrapper(*args, **kwargs): return func(*args, **kwargs)` |
| `@decorator_name` | 语法糖，等价于 `func = decorator_name(func)` | `@my_decorator` 放在函数定义前 |
| `functools.wraps(func)` | 保留原函数的元信息（如 `__name__`），推荐使用 | `@functools.wraps(func)` 放在 `wrapper` 定义前 |
| `nonlocal` | 在嵌套函数中声明变量属于外部函数，用于修改闭包变量 | `nonlocal count` |

## 5. 五个新手易错点

### 易错点1：忘记返回 `wrapper` 函数

❌ **错误写法**

```python
def bad_decorator(func):
    def wrapper():
        print("装饰器生效")
        func()
    # 忘记 return wrapper

@bad_decorator
def hello():
    print("Hello")

hello()
# 运行报错：TypeError: 'NoneType' object is not callable
```

✅ **正确写法**

```python
def good_decorator(func):
    def wrapper():
        print("装饰器生效")
        func()
    return wrapper  # 必须返回 wrapper

@good_decorator
def hello():
    print("Hello")

hello()
# 预期输出：
# 装饰器生效
# Hello
```

**为什么错**：装饰器必须返回一个函数，否则 `@bad_decorator` 会把 `hello` 变成 `None`，调用时就会报错。

### 易错点2：装饰器内的 `wrapper` 没有接收参数

❌ **错误写法**

```python
def bad_decorator(func):
    def wrapper():  # 没有 *args, **kwargs
        print("调用前")
        return func()
    return wrapper

@bad_decorator
def add(a, b):
    return a + b

print(add(1, 2))
# 运行报错：TypeError: wrapper() takes 0 positional arguments but 2 were given
```

✅ **正确写法**

```python
def good_decorator(func):
    def wrapper(*args, **kwargs):  # 接收任意参数
        print("调用前")
        return func(*args, **kwargs)
    return wrapper

@good_decorator
def add(a, b):
    return a + b

print(add(1, 2))
# 预期输出：
# 调用前
# 3
```

**为什么错**：原函数 `add` 需要两个参数，但 `wrapper` 不接受任何参数，导致调用失败。

### 易错点3：在闭包中修改外部变量时忘记 `nonlocal`

❌ **错误写法**

```python
def make_counter():
    count = 0
    def counter():
        count += 1  # 这里会报错
        return count
    return counter

c = make_counter()
print(c())
# 运行报错：UnboundLocalError: local variable 'count' referenced before assignment
```

✅ **正确写法**

```python
def make_counter():
    count = 0
    def counter():
        nonlocal count  # 声明 count 是外部函数的变量
        count += 1
        return count
    return counter

c = make_counter()
print(c())  # 1
print(c())  # 2
```

**为什么错**：在 `counter` 内部给 `count` 赋值，Python 会认为 `count` 是 `counter` 的局部变量，但你又想读取它，就冲突了。`nonlocal` 告诉 Python：“这个变量不是本地的，去外层找。”

### 易错点4：装饰器丢失了原函数的元信息（如 `__name__`）

❌ **错误写法**

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def add(a, b):
    """这是一个加法函数"""
    return a + b

print(add.__name__)  # 输出 wrapper，而不是 add
```

✅ **正确写法**

```python
import functools

def my_decorator(func):
    @functools.wraps(func)  # 保留原函数信息
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def add(a, b):
    """这是一个加法函数"""
    return a + b

print(add.__name__)  # 输出 add
print(add.__doc__)   # 输出 这是一个加法函数
```

**为什么错**：不保留元信息会导致调试困难，比如查看文档字符串或函数名时得到的是 `wrapper` 而不是原函数。

### 易错点5：装饰器带参数时，忘记多包一层函数

❌ **错误写法**

```python
def repeat(times, func):
    # 把「接收次数」和「接收函数」合并到了同一层，少包了一层
    def wrapper(*args, **kwargs):
        for _ in range(times):
            result = func(*args, **kwargs)
        return result
    return wrapper

@repeat(3)  # 只传了一个参数，func 缺位
def say_hi():
    print("Hi")

say_hi()
# 运行报错：TypeError: repeat() missing 1 required positional argument: 'func'
```

✅ **正确写法**

```python
def repeat(times):
    """最外层接收次数参数"""
    def decorator(func):  # 第二层接收函数
        def wrapper(*args, **kwargs):  # 第三层接收函数参数
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def say_hi():
    print("Hi")

say_hi()
# 预期输出：
# Hi
# Hi
# Hi
```

**为什么错**：带参数的装饰器需要三层嵌套：最外层接收装饰器参数，第二层接收函数，第三层接收函数参数。你少了一层，导致参数传递错乱。

- **目标**：掌握装饰器如何检查函数参数。
- **引导步骤**：
  1. 定义一个装饰器 `type_check`，它接收一个期望的类型 `expected_type`。

  3. 如果是，正常调用原函数。

def type_check(expected_type):

@type_check(int)

### 练习2：使用闭包创建一个“缓存”函数

- **目标**：理解闭包如何保存状态。
- **引导步骤**：
  1. 定义一个函数 `make_cache`，它内部有一个空字典 `cache`。
  2. 返回一个内部函数 `get_or_compute(key, compute_func)`，如果 `key` 在 `cache` 中，直接返回缓存值；否则调用 `compute_func` 计算结果，存入 `cache` 并返回。
- **起步代码**：

```python
def make_cache():
    cache = {}
    def get_or_compute(key, compute_func):
        # TODO: 如果 key 在 cache 中，返回 cache[key]
        # 否则，计算结果，存入 cache，并返回结果
        pass
    return get_or_compute

cache = make_cache()
print(cache("name", lambda: "Alice"))  # 第一次计算，输出 Alice
print(cache("name", lambda: "Bob"))    # 第二次应该直接返回缓存，输出 Alice
```

- **预期输出**：
  ```
  Alice
  Alice
  ```

<details><summary>👉 先自己试试，再点开看参考答案</summary>

```python
def make_cache():
    cache = {}
    def get_or_compute(key, compute_func):
        if key not in cache:
            cache[key] = compute_func()
        return cache[key]
    return get_or_compute

cache = make_cache()
print(cache("name", lambda: "Alice"))  # Alice
print(cache("name", lambda: "Bob"))    # Alice (缓存生效)
```

### 练习3：用装饰器给函数增加“重试”功能

- **目标**：综合运用装饰器和异常处理。
- **引导步骤**：
  1. 定义一个装饰器 `retry`，它接收一个参数 `attempts`（重试次数）。
  2. 在 `wrapper` 中，用 `for` 循环尝试调用原函数，如果抛出异常，继续尝试，直到成功或次数用尽。
  3. 如果最终失败，抛出最后一个异常。
- **起步代码**：

```python
def retry(attempts):
    def decorator(func):
        def wrapper(*args, **kwargs):
            # TODO: 循环 attempts 次，尝试调用 func
            # 如果成功，返回结果
            # 如果失败，继续尝试
            # 如果全部失败，抛出最后一个异常
            pass
        return wrapper
    return decorator

@retry(attempts=3)
def unstable_function():
    import random
    if random.random() < 0.5:
        raise ValueError("随机失败")
    return "成功"

print(unstable_function())
```

- **预期输出**：可能输出 `成功`，或者如果运气不好，会抛出 `ValueError`。多运行几次，应该能看到成功的情况。

<details><summary>👉 先自己试试，再点开看参考答案</summary>

```python
def retry(attempts):
    def decorator(func):
        def wrapper(*args, **kwargs):
            last_exception = None
            for _ in range(attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last_exception = e
                    print(f"尝试失败: {e}")
            raise last_exception
        return wrapper
    return decorator

@retry(attempts=3)
def unstable_function():
    import random
    if random.random() < 0.5:
        raise ValueError("随机失败")
    return "成功"

print(unstable_function())
# 预期输出：可能打印 "尝试失败: 随机失败" 几次，然后输出 "成功" 或抛出异常
```

</details>
