# L5 前端协同：模板渲染与前后端联调

## 1. 本课目标

- 能说清“模板 + 数据 → HTML”的模板渲染过程，并理解它和 JSON API 的区别。
- 能写出安全的模板填充函数：用 `html.escape(str(value))` 防止用户输入破坏页面。
- 能用 Python 标准库模拟一次前后端联调：看状态码、`Content-Type`、解析 JSON、处理 404。

## 2. 概念讲解

### 2.1 模板渲染：给 HTML“填空题”

**模板**就是一张带空位的 HTML 骨架，例如：

```text
<h1>你好，{{ name }}</h1>
```

这里的 `{{ name }}` 就是空位。**数据**可以是一个字典：

```text
{"name": "小明"}
```

**渲染**就是把这些空位替换成真实数据，得到最终 HTML：

```text
<h1>你好，小明</h1>
```

你可以把模板想成一张信纸，数据是姓名、地址、正文；渲染就是“把信息填进信纸，再交给浏览器”。

真实项目里：

- Flask 常用 `render_template("users.html", users=users)`。
- FastAPI 常用 `Jinja2Templates`。
- 模板语言里常见 `{{ 变量 }}`、`{% for ... %}`、`{% if ... %}`。

下面为了让你在网页沙箱里直接运行，我们用 Python 标准库写“迷你模板引擎”，原理与真实模板引擎一致，不依赖第三方包。

### 2.2 为什么用户输入必须转义

如果用户输入：

```html
<script>alert('xss')</script>
```

你直接把它拼进 HTML，浏览器会把它当成**代码**执行，而不是普通文字。这就是 XSS。

正确做法是先把用户内容变成“普通文本”，再放进 HTML。Python 的 `html.escape` 会把：

- `&` 变成 `&amp;`
- `<` 变成 `&lt;`
- `>` 变成 `&gt;`
- 引号也会被转义

比喻：用户输入是“信里的内容”，不能让它变成“信封上的指令”。显示文字就只显示文字。

注意：数据可能是数字、布尔值、`None`，所以要先 `str(value)`，再 `html.escape(...)`。

### 2.3 前后端联调到底在核对什么

前后端联调不是“随便请求一下看看”，而是核对一份**接口契约**：

| 检查项 | 例子 | 作用 |
|---|---|---|
| URL 与 HTTP 方法 | `GET /api/users` | 确认请求打到正确入口 |
| 状态码 | `200`、`404`、`500` | 区分成功与失败 |
| `Content-Type` | `application/json`、`text/html` | 决定前端怎么解析 |
| JSON 字段 | `id`、`name`、`active` | 确认字段名和类型一致 |
| 错误格式 | `{"error": "Not Found"}` | 让前端能统一处理错误 |

常见坑：

- 页面接口返回 HTML，却被前端当 JSON 解析。
- 前后端字段名不一致，例如前端要 `userName`，后端给 `user_name`。
- 开发时前端在 `localhost:3000`，后端在 `localhost:8000`，浏览器同源策略会拦截跨域请求；开发环境可用 CORS，生产环境要限制具体域名。

本课先抓住最核心的：**先看状态码和 Content-Type，再决定怎么解析响应体**。

## 3. 三个由浅入深的完整示例

### 示例 1：最小模板渲染 + 转义用户输入

```python
import html
import re

def render(template, context):
    """把模板中的 {{ key }} 替换为 context[key]，并做 HTML 转义。"""
    def replace(match):
        key = match.group(1).strip()
        raw_value = context[key]            # 缺字段会抛 KeyError
        return html.escape(str(raw_value))  # 先转字符串，再转义

    return re.sub(r"{{\s*(\w+)\s*}}", replace, template)

template = "<h1>你好，{{ name }}</h1><p>简介：{{ bio }}</p>"
data = {
    "name": "小明<script>alert(1)</script>",
    "bio": "喜欢 Python & Web"
}

page = render(template, data)
print(page)

# 预期输出：
# <h1>你好，小明&lt;script&gt;alert(1)&lt;/script&gt;</h1><p>简介：喜欢 Python &amp; Web</p>
```

### 示例 2：循环 + 条件，渲染用户列表

真实模板引擎用 `{% for %}`、`{% if %}`；这里用 Python 的 `for` 和条件表达式模拟同样的思路。

```python
import html

def render_user_row(user):
    status = "在线" if user["active"] else "离线"
    safe_name = html.escape(str(user["name"]))
    return (
        f"<tr><td>{user['id']}</td>"
        f"<td>{safe_name}</td>"
        f"<td>{status}</td></tr>"
    )

def render_users_page(users):
    rows = "\n".join(render_user_row(user) for user in users)
    return f"""<!doctype html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>用户列表</title></head>
<body>
  <h1>用户列表</h1>
  <table border="1">
    <tr><th>ID</th><th>姓名</th><th>状态</th></tr>
    {rows}
  </table>
</body>
</html>"""

users = [
    {"id": 1, "name": "Alice", "active": True},
    {"id": 2, "name": "<b>Bob</b>", "active": False},
]

print(render_users_page(users))

# 预期输出：
# 打印一段完整 HTML。
# 关键片段包含：<td>Alice</td><td>在线</td>
# 以及：<td>&lt;b&gt;Bob&lt;/b&gt;</td><td>离线</td>
# 注意 Bob 的 <b> 被转义成 &lt;b&gt;，不会变成粗体标签。
```

### 示例 3：本地 HTTP 服务 + 客户端请求，模拟前后端联调

这个例子同时提供：

- `GET /`：返回服务端渲染的 HTML 页面。
- `GET /api/users`：返回 JSON 数据。
- `GET /missing`：返回 404 JSON 错误。

客户端用 `urllib` 请求并检查状态码、`Content-Type`、响应体。

```python
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.request import urlopen
from urllib.error import HTTPError
import html
import json
import threading

USERS = [
    {"id": 1, "name": "Alice", "active": True},
    {"id": 2, "name": "Bob", "active": False},
]

def render_page(users):
    rows = []
    for user in users:
        status = "在线" if user["active"] else "离线"
        rows.append(
            f"<tr><td>{user['id']}</td>"
            f"<td>{html.escape(user['name'])}</td>"
            f"<td>{status}</td></tr>"
        )
    return (
        "<!doctype html><html><head><meta charset='utf-8'>"
        "<title>用户列表</title></head><body>"
        "<h1>用户列表</h1><table>"
        + "".join(rows)
        + "</table></body></html>"
    )

class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        if self.path == "/":
            body = render_page(USERS).encode("utf-8")
            self.send_response(200)
            self.send_header("Content-Type", "text/html; charset=utf-8")
            self.end_headers()
            self.wfile.write(body)
        elif self.path == "/api/users":
            body = json.dumps(USERS, ensure_ascii=False).encode("utf-8")
            self.send_response(200)
            self.send_header("Content-Type", "application/json; charset=utf-8")
            self.end_headers()
            self.wfile.write(body)
        else:
            body = json.dumps({"error": "Not Found"}, ensure_ascii=False).encode("utf-8")
            self.send_response(404)
            self.send_header("Content-Type", "application/json; charset=utf-8")
            self.end_headers()
            self.wfile.write(body)

    def log_message(self, format, *args):
        pass

server = ThreadingHTTPServer(("127.0.0.1", 0), Handler)
port = server.server_address[1]
threading.Thread(target=server.serve_forever, daemon=True).start()
base = f"http://127.0.0.1:{port}"

try:
    with urlopen(base + "/") as resp:
        page_text = resp.read().decode("utf-8")
        print("页面状态码:", resp.status)
        print("页面 Content-Type:", resp.headers.get("Content-Type"))
        print("页面是否含表格:", "<table>" in page_text)

    with urlopen(base + "/api/users") as resp:
        api_text = resp.read().decode("utf-8")
        users = json.loads(api_text)
        print("接口状态码:", resp.status)
        print("接口 Content-Type:", resp.headers.get("Content-Type"))
        print("接口数据:", users)

    try:
        urlopen(base + "/missing")
    except HTTPError as e:
        error_data = json.loads(e.read().decode("utf-8"))
        print("错误状态码:", e.code)
        print("错误数据:", error_data)
        e.close()
finally:
    server.shutdown()
    server.server_close()

# 预期输出：
# 页面状态码: 200
# 页面 Content-Type: text/html; charset=utf-8
# 页面是否含表格: True
# 接口状态码: 200
# 接口 Content-Type: application/json; charset=utf-8
# 接口数据: [{'id': 1, 'name': 'Alice', 'active': True}, {'id': 2, 'name': 'Bob', 'active': False}]
# 错误状态码: 404
# 错误数据: {'error': 'Not Found'}
```

## 4. 常用函数/调用速查表

| 函数/方法 | 签名 | 用途 | 最小示例 |
|---|---|---|---|
| `html.escape` | `html.escape(s, quote=True)` | 转义 HTML 特殊字符，防 XSS | `html.escape("<b>")` → `&lt;b&gt;` |
| `json.dumps` | `json.dumps(obj, ensure_ascii=False)` | Python 对象转 JSON 字符串 | `json.dumps({"ok": True})` → `'{"ok": true}'` |
| `json.loads` | `json.loads(text)` | JSON 字符串转 Python 对象 | `json.loads('{"ok": true}')` → `{'ok': True}` |
| `urlopen` | `urllib.request.urlopen(url)` | 发起 HTTP 请求 | `urlopen("http://127.0.0.1:8000/api")` |
| `response.read` | `response.read().decode("utf-8")` | 读取响应体文本 | `response.read().decode("utf-8")` |
| `headers.get` | `response.headers.get("Content-Type")` | 查看响应类型 | `response.headers.get("Content-Type")` |
| `urlencode` | `urllib.parse.urlencode(dict)` | 字典转查询参数 | `urlencode({"q": "python web"})` → `q=python+web` |
| `quote` | `urllib.parse.quote(s)` | 对 URL 中的单个值编码 | `quote("a b")` → `a%20b` |
| `re.sub` | `re.sub(pattern, repl, text)` | 替换模板占位符 | `re.sub(r"x", "y", "xx")` → `yy` |
| `send_response` | `self.send_response(status)` | 服务端发送状态码 | `self.send_response(200)` |
| `send_header` | `self.send_header(name, value)` | 服务端发送响应头 | `self.send_header("Content-Type", "application/json")` |
| `end_headers` | `self.end_headers()` | 结束响应头 | `self.end_headers()` |

## 5. 五个新手易错点

### 易错点1：模板里有占位符，但数据里没给字段

❌ **错误写法**

```python
import re

def render(template, context):
    def replace(match):
        key = match.group(1)
        return context[key]  # 缺少键会 KeyError
    return re.sub(r"{{\s*(\w+)\s*}}", replace, template)

page = render("<h1>{{ title }}</h1><p>{{ author }}</p>", {"title": "文章"})
print(page)
# 运行报错：KeyError: 'author'
```

✅ **正确写法**

```python
import html
import re

def render(template, context):
    def replace(match):
        key = match.group(1).strip()
        value = context.get(key, "（未填写）")  # 有默认值
        return html.escape(str(value))
    return re.sub(r"{{\s*(\w+)\s*}}", replace, template)

page = render("你好，{{ name }}！备注：{{ note }}", {"name": "小明"})
print(page)
# 预期输出：你好，小明！备注：（未填写）
```

**为什么错**：模板字段必须和传入数据对齐；缺字段时应该用 `get` 给默认值，或者先校验并返回明确错误，不能把裸 `KeyError` 直接丢给用户。

### 易错点2：转义前忘了把数字转成字符串

❌ **错误写法**

```python
import html

def render_age(age):
    return f"<span>{html.escape(age)}</span>"

print(render_age(18))
# 运行报错：AttributeError: 'int' object has no attribute 'replace'
```

✅ **正确写法**

```python
import html

def render_age(age):
    return f"<span>{html.escape(str(age))}</span>"

print(render_age(18))
# 预期输出：<span>18</span>
```

**为什么错**：模板数据可能是数字、布尔值或 `None`，而 `html.escape` 期待字符串；先 `str(value)` 再转义。

### 易错点3：用 `str.format` 渲染带 CSS 的 HTML

❌ **错误写法**

```python
template = "<style>body { color: red; }</style><h1>{name}</h1>"
page = template.format(name="小明")
print(page)
# 运行报错：KeyError: ' color'
```

✅ **正确写法**

```python
template = "<style>body {{ color: red; }}</style><h1>{name}</h1>"
page = template.format(name="小明")
print(page)
# 预期输出：<style>body { color: red; }</style><h1>小明</h1>
```

**为什么错**：`str.format` 会把 CSS 里的 `{ color: red; }` 当占位符；要么把字面花括号写成 `{{ }}`，要么使用更合适的模板引擎。

### 易错点4：把 HTML 响应当 JSON 解析

❌ **错误写法**

```python
import json

html_response = "<h1>用户列表</h1><p>正常页面</p>"
data = json.loads(html_response)
print(data)
# 运行报错：json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)
```

✅ **正确写法**

```python
import json

def parse_json_response(content_type, text):
    if "application/json" not in content_type:
        raise ValueError("这不是 JSON 响应，先检查 URL 或 Content-Type")
    return json.loads(text)

content_type = "text/html; charset=utf-8"
try:
    parse_json_response(content_type, "<h1>用户列表</h1>")
except ValueError as e:
    print("提示:", e)
# 预期输出：提示: 这不是 JSON 响应，先检查 URL 或 Content-Type
```

**为什么错**：联调时先看状态码和 `Content-Type`，确认是 JSON 再用 `json.loads`；不能拿到什么文本都直接当 JSON 解析。

### 易错点5：把 `set` 直接塞进 JSON

❌ **错误写法**

```python
import json

data = {"name": "小明", "tags": {"python", "web"}}
text = json.dumps(data, ensure_ascii=False)
print(text)
# 运行报错：TypeError: Object of type set is not JSON serializable
```

✅ **正确写法**

```python
import json

tags = sorted({"python", "web", "python"})
data = {"name": "小明", "tags": tags}
text = json.dumps(data, ensure_ascii=False)
print(text)
# 预期输出：{"name": "小明", "tags": ["python", "web"]}
```

**为什么错**：JSON 只支持对象、数组、字符串、数字、布尔值和 `null`；`set` 要先转成 `list` 或排序后的列表，再交给 `json.dumps`。

  3. 其他情况当作 HTML 文本返回。

```python
import json

def handle_response(status, content_type, body_text):
    if status >= 400:
        return ("错误", body_text)
    if "application/json" in content_type:
        return ("JSON", json.loads(body_text))
    return ("HTML", body_text)

print(handle_response(200, "application/json; charset=utf-8", '{"ok": true, "count": 2}'))
print(handle_response(404, "application/json; charset=utf-8", '{"error": "Not Found"}'))
print(handle_response(200, "text/html; charset=utf-8", "<h1>首页</h1>"))

# 预期输出：
# ('JSON', {'ok': True, 'count': 2})
# ('错误', '{"error": "Not Found"}')
# ('HTML', '<h1>首页</h1>')
```

</details>

## 7. 本课小结

- 模板渲染 = 模板 + 数据 → HTML；真实项目常用 Jinja2，本课用标准库模拟同样原理。
- 用户输入进入 HTML 前必须 `html.escape(str(value))`，否则可能触发 XSS。
- 模板字段要和数据对齐；缺字段应使用默认值或明确校验，不要直接漏出 `KeyError`。
- 前后端联调先看 URL、方法、状态码、`Content-Type`，再决定解析 HTML 还是 JSON。
- JSON 只支持有限类型；`set` 要先转 `list`，HTML 响应不能直接 `json.loads`。
